**开发环境**：`http://localhost:8080`

**生产环境**：需要配置为实际的后端服务器地址

**配置位置**：`src/config/index.js`

```javascript
const production = {
  baseURL: 'https://api.yourdomain.com',  // 改为实际地址
  wsURL: 'wss://api.yourdomain.com/ws',
  uploadURL: 'https://api.yourdomain.com/v1/upload'
}
```

**环境切换**：
```javascript
// 开发环境
NODE_ENV=development npm run dev:mp-weixin

// 生产环境
NODE_ENV=production npm run build:mp-weixin
```

### 4. 服务器域名配置（上线必须）

**配置位置**：微信公众平台

**步骤**：
1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 开发 → 开发管理 → 开发设置 → 服务器域名
3. 点击"修改"，添加以下域名：

**域名列表**：
```
request合法域名：
https://api.yourdomain.com

socket合法域名：
wss://api.yourdomain.com

uploadFile合法域名：
https://api.yourdomain.com

downloadFile合法域名：
https://api.yourdomain.com
```

**重要要求**：
- ✅ 必须使用 HTTPS 协议
- ✅ 域名必须已完成 ICP 备案
- ✅ SSL 证书必须有效且未过期
- ✅ 域名不能包含端口号
- ✅ 域名不能是 IP 地址

**获取SSL证书**：
- 阿里云：[SSL证书服务](https://www.aliyun.com/product/cas)（有免费证书）
- 腾讯云：[SSL证书服务](https://cloud.tencent.com/product/ssl)
- Let's Encrypt：[免费SSL证书](https://letsencrypt.org/)

## 🎯 重要配置（P1）

### 1. 微信登录（可选）

**已实现**：`src/utils/wechat.js`

**后端接口需求**：
```
POST /v1/user/wechat-login
Request: { code: string }
Response: { token: string, userInfo: object }

POST /v1/user/phone
Request: { encryptedData: string, iv: string }
Response: { phoneNumber: string }
```

**页面使用示例**：
```vue
<template>
  <button
    open-type="getPhoneNumber"
    @getphonenumber="handleGetPhoneNumber"
  >
    微信快捷登录
  </button>
</template>

<script setup>
import { getPhoneNumber } from '@/utils/wechat'

const handleGetPhoneNumber = (e) => {
  getPhoneNumber(e).then(phone => {
    console.log('手机号:', phone)
  })
}
</script>
```

### 2. 微信支付（可选）

**已实现**：`src/utils/wechat.js` 的 `wechatPay`

**后端接口需求**：
```
POST /v1/payment/wechat/prepay
Request: { orderId: string, orderNo: string, amount: number }
Response: { timeStamp, nonceStr, package, signType, paySign }
```

**使用示例**：
```javascript
import { wechatPay } from '@/utils/wechat'

// 发起支付
wechatPay({
  orderId: '123',
  orderNo: 'ORDER20260319001',
  amount: 58.00
}).then(result => {
  if (result.success) {
    uni.showToast({ title: '支付成功' })
  } else if (result.cancelled) {
    uni.showToast({ title: '取消支付', icon: 'none' })
  }
})
```

**配置要求**：
- 需要申请微信商户号
- 需要配置支付密钥
- 需要在商户平台关联小程序

## 🔐 权限配置

### 小程序权限列表

已配置在 `manifest.json` 中：

```json
{
  "mp-weixin": {
    "permission": {
      "scope.userLocation": {
        "desc": "您的位置信息将用于推荐附近商家"
      }
    },
    "requiredPrivateInfos": [
      "getLocation",
      "chooseLocation",
      "chooseAddress"
    ]
  }
}
```

**权限说明**：
- `getLocation` - 获取用户位置
- `chooseLocation` - 选择位置
- `chooseAddress` - 选择收货地址

## 🚀 开发与部署

### 开发环境配置

**1. 本地开发**

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev:mp-weixin
```

**2. 微信开发者工具配置**

- 打开微信开发者工具
- 导入项目 → 选择 `dist/dev/mp-weixin` 目录
- AppID 选择"测试号"或填写实际AppID
- 本地设置：
  - ✅ 不校验合法域名（开发时）
  - ✅ 启用ES6转ES5
  - ✅ 启用增强编译

---

### 生产环境部署

**1. 构建生产版本**

```bash
# 构建小程序
npm run build:mp-weixin
```

**2. 上传代码**

使用微信开发者工具：
- 点击"上传"按钮
- 填写版本号（如：1.0.0）
- 填写项目备注

**3. 提交审核**

登录微信公众平台：
- 版本管理 → 开发版本
- 点击"提交审核"
- 填写审核信息：
  - 测试账号（如需要登录）
  - 功能页面列表
  - 用户身份（学生/教职工）
  - 服务类目（餐饮→外卖）

**4. 发布上线**

审核通过后：
- 版本管理 → 审核版本
- 点击"发布"

## 🔍 常见问题

### Q1: 开发时请求失败？

**检查**：
1. 后端服务是否启动（localhost:8080）
2. 微信开发者工具是否开启"不校验合法域名"
3. 查看控制台错误信息

---

### Q2: 图标不显示？

**原因**：图标文件是空的（0字节）

**解决**：准备实际的图标文件并替换

---

### Q3: 上传后提示"不在合法域名列表"？

**原因**：生产环境必须配置HTTPS域名

**解决**：
1. 配置HTTPS服务器
2. 在微信公众平台添加域名
3. 等待域名配置生效（约10分钟）

---

### Q4: 审核不通过？

**常见原因**：
- 域名未备案
- SSL证书无效
- 隐私协议不完整
- 功能未实现
- 测试账号无法登录

**解决**：
1. 查看具体驳回原因
2. 修改后重新提交
3. 确保所有功能正常

---

### Q5: 如何切换开发/生产环境？

**方式一：环境变量**
```bash
NODE_ENV=development npm run dev:mp-weixin
NODE_ENV=production npm run build:mp-weixin
```

**方式二：修改配置文件**
编辑 `src/config/index.js`，修改对应环境的配置
