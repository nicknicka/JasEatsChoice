## 项目介绍

基于uni-app开发的佳食宜选餐饮下单系统小程序端，提供用户点单、食谱推荐、AI助手、即时通讯、支付、评价等功能。

## 技术栈
- uni-app
- Vue 3 (Composition API)
- Vite
- Pinia (状态管理)

## 主要功能

### 用户端

## 开发注意事项
1. 确保已安装HBuilderX或微信开发者工具
2. 配置正确的后端API地址
3. 微信小程序需要在开发者工具中配置appid
4. 遵守uni-app开发规范
5. 使用Vue 3 Composition API语法
6. API调用统一使用 `src/api/modules/` 下的模块
