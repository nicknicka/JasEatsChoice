## 🎯 文档规范

### 文件命名规范

1. **主文档** - 直接放在根目录
   - README.md
   - TODO功能清单与实施计划.md
   - API对接文档.md
   - 配置指南.md

2. **进度报告** - 格式：`项目进度报告-{百分比}.md`
   - ✅ 项目进度报告-57percent.md
   - ❌ 项目进度报告-50percent.md（已移至history）

3. **模块总结** - 格式：`{模块名}模块完成总结.md`
   - 心愿单模块完成总结.md
   - 菜品管理与群订单模块完成总结.md
   - 通知与评价模块完成总结.md

4. **历史文档** - 移至 `docs/history/`

### 文档更新流程

1. **新模块完成时**
   - 创建 `docs/modules/{模块名}模块完成总结.md`
   - 更新 `TODO功能清单与实施计划.md`
   - 更新 `docs/项目进度报告-{百分比}.md`
   - 更新 `docs/README.md`

2. **进度更新时**
   - 更新主进度报告（如50% → 57%）
   - 将旧报告移至 `docs/history/`
   - 更新根目录 `README.md`

3. **文档维护**
   - 定期清理过时文档
   - 保持文档索引更新
   - 确保链接有效
