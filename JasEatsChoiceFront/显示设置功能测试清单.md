显示设置功能包括：

## ✅ 字体大小功能（已实现）

### 当前状态
- ✅ **主要内容区域**：聊天消息、表单、按钮、对话框等可以正常缩放
- ✅ **批量转换完成**：155 个文件，1,618 处字体已转换为 rem 单位
- ⚠️ **待优化**：侧边栏菜单文字暂时无法响应字体大小变化

### 测试步骤

1. **进入设置页面**
   - 用户端：设置 → 显示设置 → 字体大小

2. **切换字体大小**
   - 选择 **"小"** (12px)
   - 选择 **"中"** (14px) - 默认
   - 选择 **"大"** (16px)
   - 选择 **"超大"** (18px)

3. **检查效果（应该有变化的区域）**
   - ✅ 聊天消息文字
   - ✅ 表单输入框文字
   - ✅ 按钮文字
   - ✅ 对话框标题和内容
   - ✅ 卡片标题和内容
   - ✅ 页面标题和段落文字

4. **已知的限制**
   - ⚠️ 侧边栏菜单文字（首页、AI饮食助手等）- 不会变化
   - 原因：Element Plus 菜单组件的内联样式优先级过高

## 💡 优化建议

### 如果需要改进侧边栏字体缩放

**方案 1：使用 CSS Transform（简单但可能模糊）**
```javascript
const updateSidebarFontSize = () => {
  const sidebar = document.querySelector('.sidebar-menu')
  const scale = fontSize === 'large' ? 1.1 : fontSize === 'small' ? 0.9 : 1
  if (sidebar) {
    sidebar.style.transform = `scale(${scale})`
    sidebar.style.transformOrigin = 'top left'
  }
}
```

**方案 2：JavaScript 直接修改菜单文字（较复杂）**
```javascript
const updateMenuFontSize = () => {
  const sizes = { small: '12px', medium: '14px', large: '16px', 'extra-large': '18px' }
  const menuItems = document.querySelectorAll('.el-menu-item span')
  menuItems.forEach(item => {
    item.style.fontSize = sizes[fontSize.value]
  })
}
```
