## 🎬 可用动画类名

### 1. 基础入场动画

| 类名 | 效果 | 使用场景 |
|------|------|----------|
| `fade-in` | 简单淡入 | 所有需要淡入的元素 |
| `fade-in-up` | 从下向上淡入 | 卡片、列表项、内容块 |
| `slide-in-left` | 从左向右滑入 | 侧边栏内容、导航菜单 |
| `slide-in-right` | 从右向左滑入 | 详情页、对话框 |
| `scale-in` | 缩放淡入 | 重要卡片、弹窗、图标 |
| `bounce-in` | 弹性缩放 | 强调元素、按钮、徽章 |
| `rotate-in` | 旋转淡入 | 特殊装饰元素 |
| `flip-in` | 翻转淡入 | 卡片翻转效果 |
| `pulse-in` | 脉冲淡入 | 新消息提示、重要通知 |

### 2. 延迟动画类

用于创建交错动画效果：

```html
<!-- 延迟 100ms -->
<div class="fade-in-up delay-100">...</div>

<!-- 延迟 200ms -->
<div class="fade-in-up delay-200">...</div>

<!-- 支持的延迟时间：100-1000ms，步长100ms -->
```

### 3. 列表交错动画

为列表项自动添加依次出现的动画效果：

```html
<div class="list-item stagger-item">项目 1</div>
<div class="list-item stagger-item">项目 2</div>
<div class="list-item stagger-item">项目 3</div>
<!-- 最多支持10个子元素 -->
```

### 4. 卡片动画

```html
<!-- 卡片入场动画 -->
<div class="card-animate">...</div>

<!-- 卡片悬停效果 -->
<div class="card-hover-effect">...</div>
```

### 5. 特殊效果动画

| 类名 | 效果 | 使用场景 |
|------|------|----------|
| `number-scroll` | 数字滚动 | 统计数字、计数器 |
| `highlight-flash` | 高亮闪烁 | 新消息、重要更新 |
| `skeleton-animate` | 骨架屏加载 | 加载占位符 |
| `float-continuous` | 持续悬浮 | 装饰元素、图标 |
| `breathing` | 呼吸效果 | 提示图标、状态指示 |

## 💡 使用示例

### 示例 1：卡片列表交错动画

```vue
<template>
  <div class="card-list">
    <div
      v-for="(item, index) in items"
      :key="item.id"
      class="card-item stagger-item card-hover-effect"
    >
      <!-- 卡片内容 -->
    </div>
  </div>
</template>
```

### 示例 2：分阶段入场动画

```vue
<template>
  <div class="page-container">
    <!-- 第1阶段：标题淡入 -->
    <h2 class="page-title fade-in-up">页面标题</h2>

    <!-- 第2阶段：工具栏延迟100ms淡入 -->
    <div class="toolbar fade-in-up delay-100">
      <!-- 工具栏内容 -->
    </div>

    <!-- 第3阶段：筛选面板从左滑入 -->
    <div class="filter-panel slide-in-left delay-200">
      <!-- 筛选内容 -->
    </div>

    <!-- 第4阶段：内容区域延迟300ms淡入 -->
    <div class="content-area fade-in-up delay-300">
      <!-- 内容 -->
    </div>
  </div>
</template>
```

### 示例 3：数字滚动效果

```vue
<template>
  <div class="stat-card">
    <div class="stat-label">今日订单</div>
    <div class="stat-value number-scroll">{{ orderCount }}</div>
  </div>
</template>
```

### 示例 4：使用 Composable 实现滚动触发动画

```vue
<script setup>
import { useAnimations } from '@/composables/useAnimations'

const { animateOnScroll } = useAnimations()

// 当元素滚动到视口时触发动画
animateOnScroll('.lazy-load-item', 'fade-in-up')
</script>

<template>
  <div class="lazy-load-item">
    <!-- 只有滚动到这里才会显示动画 -->
  </div>
</template>
```

### 示例 5：批量添加动画

```vue
<script setup>
import { useAnimations } from '@/composables/useAnimations'

const { batchAnimate } = useAnimations()

// 批量为多个元素添加动画
batchAnimate([
  { selector: '.header', animationClass: 'fade-in-up', delay: 0 },
  { selector: '.toolbar', animationClass: 'slide-in-left', delay: 100 },
  { selector: '.content', animationClass: 'fade-in-up', delay: 200 },
  { selector: '.footer', animationClass: 'fade-in-up', delay: 300 }
])
</script>
```

## 🎯 动画选择建议

### 按页面类型选择

| 页面类型 | 推荐动画 | 说明 |
|----------|----------|------|
| **首页/概览页** | `fade-in-up` + 延迟 | 依次加载各区块 |
| **列表页** | `stagger-item` | 列表项交错出现 |
| **详情页** | `slide-in-right` | 从右滑入，表示层级深入 |
| **表单页** | `fade-in-up` | 简单淡入，不分散注意力 |
| **弹窗/对话框** | `scale-in` | 缩放淡入，突出重点 |
| **通知/提示** | `bounce-in` 或 `pulse-in` | 弹性效果，吸引注意 |

### 按元素类型选择

| 元素类型 | 推荐动画 | 说明 |
|----------|----------|------|
| **标题/头部** | `fade-in-up` | 简单淡入 |
| **卡片** | `card-animate` + `card-hover-effect` | 卡片专用动画+悬停效果 |
| **列表项** | `stagger-item` | 自动交错动画 |
| **图标/徽章** | `scale-in` 或 `bounce-in` | 强调元素 |
| **统计数据** | `number-scroll` | 数字滚动效果 |
| **装饰元素** | `float-continuous` 或 `breathing` | 持续动画 |

## ⚙️ 最佳实践

### 1. 动画时长控制

- **入场动画**：300-600ms
- **交互动画**：200-300ms
- **持续动画**：2-3s 循环

### 2. 性能优化

```vue
<!-- ✅ 推荐：简单的transform动画 -->
<div class="card-animate">...</div>

<!-- ❌ 不推荐：过多复杂动画 -->
<div class="rotate-in flip-in bounce-in">...</div>
```

### 3. 无障碍访问

项目已内置 `prefers-reduced-motion` 支持，当用户开启"减少动态效果"时，动画会自动禁用。

### 4. 动画组合建议

```vue
<!-- 推荐：一种入场动画 + 适当延迟 -->
<div class="fade-in-up delay-100">...</div>

<!-- 推荐：入场动画 + 悬停效果 -->
<div class="card-animate card-hover-effect">...</div>

<!-- 不推荐：多个入场动画叠加 -->
<div class="fade-in-up slide-in-left scale-in">...</div>
```

## 🔧 自定义动画

如果需要添加新的动画效果，可以在 `component-animations.css` 中添加：

```css
/* 添加新的动画 */
.my-custom-animation {
  animation: myCustomAnimation 0.6s ease-out forwards;
  opacity: 0;
}

@keyframes myCustomAnimation {
  from {
    opacity: 0;
    transform: translateY(50px) rotate(-5deg);
  }
  to {
    opacity: 1;
    transform: translateY(0) rotate(0);
  }
}
```
