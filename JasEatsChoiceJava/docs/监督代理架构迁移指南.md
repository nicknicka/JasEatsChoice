# 监督代理架构迁移指南

## 概述

本文档指导如何将现有的 Agent 架构从 `AiServices` 升级到 `AgenticServices`，实现完整的监督代理模式。

## 迁移背景

### 升级前（0.36.2）

```java
// 使用 AiServices.builder()
@Bean
public NutritionAiAgent nutritionAiAgent(ChatLanguageModel chatModel, ChatMemory chatMemory) {
    return AiServices.builder(NutritionAiAgent.class)
            .chatLanguageModel(chatModel)  // 旧API
            .chatMemory(chatMemory)
            .tools(nutritionTools)
            .build();
}
```

### 升级后（1.12.1）

```java
// 使用 AgenticServices.agentBuilder()
@Bean
public NutritionGuideAgent nutritionGuideAgent(ChatModel chatModel, ChatMemory chatMemory) {
    return AgenticServices.agentBuilder(NutritionGuideAgent.class)
            .chatModel(chatModel)  // 新API
            .chatMemory(chatMemory)
            .tools(nutritionTools)
            .outputKey("nutritionInfo")  // 状态共享
            .build();
}
```

## 迁移步骤

### 第一步：依赖升级

**修改 `pom.xml`**

```xml
<properties>
    <langchain4j.version>1.12.1</langchain4j.version>
</properties>

<dependencies>
    <!-- LangChain4j核心 -->
    <dependency>
        <groupId>dev.langchain4j</groupId>
        <artifactId>langchain4j</artifactId>
        <version>${langchain4j.version}</version>
    </dependency>

    <!-- Agentic模块 -->
    <dependency>
        <groupId>dev.langchain4j</groupId>
        <artifactId>langchain4j-agentic</artifactId>
        <version>1.12.1-beta21</version>
    </dependency>

    <!-- 智谱AI集成 -->
    <dependency>
        <groupId>dev.langchain4j</groupId>
        <artifactId>langchain4j-community-zhipu-ai</artifactId>
        <version>1.12.1-beta21</version>
    </dependency>
</dependencies>
```

**执行依赖解析**：

```bash
./mvnw dependency:resolve
```

---

### 第二步：API 迁移

#### 2.1 ChatModel API 变更

**旧 API**:
```java
import dev.langchain4j.model.chat.ChatLanguageModel;
import dev.langchain4j.model.zhipu.ZhipuAiChatModel;

ChatLanguageModel chatModel = ZhipuAiChatModel.builder()...
```

**新 API**:
```java
import dev.langchain4j.model.chat.ChatModel;
import dev.langchain4j.community.model.zhipu.ZhipuAiChatModel;

ChatModel chatModel = ZhipuAiChatModel.builder()...
```

#### 2.2 流式输出 API 变更

**旧 API**:
```java
tokenStream.onNext(token -> {...})
           .onComplete(response -> {...});
```

**新 API**:
```java
tokenStream.onPartialResponse(token -> {...})
           .onCompleteResponse(response -> {...});
```

#### 2.3 ChatModel 方法变更

**旧 API**:
```java
String response = chatModel.generate(prompt);
```

**新 API**:
```java
String response = chatModel.chat(prompt);
```

---

### 第三步：配置类迁移

#### 3.1 L1 Agent 配置

**迁移前**:
```java
@Bean
public UserPreferenceAgent userPreferenceAgent(ChatLanguageModel chatModel, ChatMemory chatMemory) {
    return AiServices.builder(UserPreferenceAgent.class)
            .chatLanguageModel(chatModel)
            .chatMemory(chatMemory)
            .tools(userProfileTools)
            .build();
}
```

**迁移后**:
```java
@Bean
public UserPreferenceAgent userPreferenceAgent(ChatModel chatModel, ChatMemory chatMemory) {
    return AgenticServices.agentBuilder(UserPreferenceAgent.class)
            .chatModel(chatModel)
            .chatMemory(chatMemory)
            .tools(userProfileTools)
            .outputKey("userPreferences")  // 状态共享
            .build();
}
```

**关键变更**:
- `AiServices.builder()` → `AgenticServices.agentBuilder()`
- `.chatLanguageModel()` → `.chatModel()`
- 添加 `.outputKey()` 用于状态共享

#### 3.2 L2 Agent 配置

**迁移前**:
```java
@Bean
public SmartRecommendationAgent smartRecommendationAgent(ChatLanguageModel chatModel, ChatMemory chatMemory) {
    return AiServices.builder(SmartRecommendationAgent.class)
            .chatLanguageModel(chatModel)
            .chatMemory(chatMemory)
            .tools(recommendationTools, nutritionTools)
            .build();
}
```

**迁移后**:
```java
@Bean
public SmartRecommendationAgent smartRecommendationAgent(ChatModel chatModel, ChatMemory chatMemory) {
    return AiServices.builder(SmartRecommendationAgent.class)
            .chatModel(chatModel)
            .chatMemory(chatMemory)
            .tools(recommendationTools, nutritionTools)
            .build();
}
```

**注意**: L2 Agent 可以继续使用 `AiServices.builder()`，无需强制使用 `AgenticServices`。

#### 3.3 L3 SupervisorAgent 配置（新增）

```java
@Bean
public SupervisorAgent supervisorAgent(ChatModel chatModel, ChatMemory chatMemory) {
    return AgenticServices
            .supervisorBuilder(SupervisorAgent.class)
            .chatModel(chatModel)
            .chatMemoryProvider(memoryId -> chatMemory)
            .name("SupervisorAgent")
            .supervisorContext("""
                # 角色定义
                你是一个智能监督代理...
                """)
            .contextGenerationStrategy(
                SupervisorContextStrategy.CHAT_MEMORY_AND_SUMMARIZATION
            )
            .responseStrategy(SupervisorResponseStrategy.SCORED)
            .maxAgentsInvocations(10)
            .build();
}
```

### 第四步：Controller 适配

#### 4.1 注入 SupervisorAgent

```java
@RestController
@RequestMapping("/api/agent/supervisor")
public class SupervisorAgentController {

    @Resource
    private SupervisorAgent supervisorAgent;

    @PostMapping("/chat")
    public ResponseResult<String> chat(@RequestBody ChatRequest request) {
        String response = supervisorAgent.chat(request.getMessage());
        return ResponseResult.success(response);
    }
}
```

#### 4.2 统一响应格式

使用 `ResponseResult` 而非自定义类型：

```java
// 成功响应
return ResponseResult.success(data);

// 失败响应
return ResponseResult.fail("500", "错误信息");
```

## 常见问题

### Q1: 编译错误 "找不到符号 ChatLanguageModel"

**解决方案**:

```bash
# 1. 清理缓存
./mvnw clean

# 2. 重新编译
./mvnw compile

# 3. 如果仍然失败，删除本地仓库缓存
rm -rf ~/.m2/repository/dev/langchain4j
./mvnw dependency:resolve
```

### Q2: Zhipu AI 包导入错误

**解决方案**:

```java
// 错误的导入
import dev.langchain4j.model.zhipu.ZhipuAiChatModel;

// 正确的导入
import dev.langchain4j.community.model.zhipu.ZhipuAiChatModel;
```

### Q3: 流式输出 API 不兼容

**解决方案**:

```java
// 旧代码
tokenStream.onNext(token -> {...})
           .onComplete(response -> {...});

// 新代码
tokenStream.onPartialResponse(token -> {...})
           .onCompleteResponse(response -> {...});
```

### Q4: SupervisorAgent 构建失败

**解决方案**:

```java
// 确保 ChatMemoryProvider 使用正确的语法
.chatMemoryProvider(memoryId -> chatMemory)

// 而不是
.chatMemoryProvider(ChatMemoryProvider.withChatMemory(chatMemory))
```

### Q5: ResponseResult.error() 方法不存在

**解决方案**:

```java
// 使用 fail() 方法代替 error()
return ResponseResult.fail("500", "错误信息");
```

## 回滚方案

如果迁移失败，执行以下回滚步骤：

### 1. 回退依赖版本

```xml
<properties>
    <langchain4j.version>0.36.2</langchain4j.version>
</properties>
```

### 2. 回退配置类

使用 Git 回退到迁移前的版本：

```bash
git checkout HEAD~1 src/main/java/.../agent/config/
```

### 3. 重新编译

```bash
./mvnw clean compile
```

## 最佳实践

### 1. 分阶段迁移

建议按以下顺序迁移：

1. **阶段1**: 依赖升级 + API迁移
2. **阶段2**: L1 Agent迁移
3. **阶段3**: L2 Agent迁移（可选）
4. **阶段4**: SupervisorAgent实现
5. **阶段5**: Controller适配
