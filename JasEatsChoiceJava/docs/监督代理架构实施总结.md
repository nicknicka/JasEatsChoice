## 技术架构

### 三层架构

```
┌─────────────────────────────────────────────────┐
│           SupervisorAgent (L3 监督代理)         │
│   智能调度 + 协调 + 综合 + 错误处理              │
│   • AgenticServices.supervisorBuilder()         │
│   • CHAT_MEMORY_AND_SUMMARIZATION 策略          │
│   • SCORED 响应策略                            │
└────────────────┬────────────────────────────────┘
                 │
    ┌────────────┼────────────┬────────────┐
    ▼            ▼            ▼            ▼
┌────────┐  ┌─────────┐  ┌──────────┐  ┌──────────┐
│ 推荐Agent│  │健康Agent│  │订单Agent  │  │助手Agent │
│  (L2)   │  │  (L2)   │  │  (L2)    │  │  (L2)    │
└────────┘  └─────────┘  └──────────┘  └──────────┘
    │            │            │            │
    └────────────┴────────────┴────────────┘
                 │
    ┌────────────┼────────────┬────────────┐
    ▼            ▼            ▼            ▼
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│用户偏好   │ │营养指导   │ │菜品推荐   │ │商家信息   │
│ (L1)     │ │ (L1)     │ │ (L1)     │ │ (L1)     │
│outputKey:│ │outputKey:│ │outputKey:│ │outputKey:│
│preferences│ │nutritionInfo│ │recommendations│ │merchantInfo│
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```
