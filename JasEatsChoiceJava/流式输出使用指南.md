## 功能概述

### 什么是流式输出？

流式输出（Streaming Output）是一种实时传输AI生成内容的技术，类似于ChatGPT的打字机效果：

- **传统方式**: 等待完整回复 → 一次性显示全部内容
- **流式方式**: 逐字生成 → 逐字显示 → 实时反馈

### 优势

1. **更好的用户体验**
   - 即时反馈，减少等待焦虑
   - 类似真人对话的自然感
   - 可以提前阅读已生成内容

2. **更快的首字响应**
   - 无需等待完整回复
   - 首字时间 < 1秒
   - 总体感知速度更快

3. **支持长文本输出**
   - 不受超时限制
   - 可以生成更长的回复
   - 更适合复杂场景

### 对比

| 特性 | 传统输出 | 流式输出 |
|------|----------|----------|
| 响应方式 | 等待完整回复 | 逐字实时推送 |
| 首字时间 | 3-5秒 | < 1秒 |
| 用户体验 | 等待焦虑 | 实时反馈 |
| 长文本支持 | 受超时限制 | 无限制 |
| 实现复杂度 | 简单 | 中等 |

## 后端实现

### 1. 流式Agent接口

**文件**: `StreamingIntelligentAssistantAgent.java`

```java
public interface StreamingIntelligentAssistantAgent {
    @SystemMessage("...")
    TokenStream chat(@UserMessage String userMessage);

```

**关键点**:
- 返回类型是`TokenStream`而不是`String`
- 使用`@SystemMessage`定义Agent行为
- 使用`@UserMessage`接收用户输入

```java
                .tools(...)
                .build();

```

**关键点**:
- 使用`ZhipuAiStreamingChatModel`而不是普通模型
- 配置流式ChatLanguageModel
- 创建独立的ChatMemory

### 3. 流式Service

**文件**: `StreamingAgentService.java`

```java
@Service
public class StreamingAgentService {

    public void chatStream(String userMessage, TokenHandler tokenHandler) {
        TokenStream tokenStream = agent.chat(userMessage);

        tokenStream.onNext(token -> {
            tokenHandler.onToken(token);
        })
        .onComplete(response -> {
            tokenHandler.onComplete();
        })
        .onError(error -> {
            tokenHandler.onError(error);
        })
        .start();
    }
}
```

**关键点**:
- 使用`TokenStream`处理流式响应
- 三个回调：`onNext`, `onComplete`, `onError`
- 必须调用`start()`启动流式处理

### 4. 流式Controller

**文件**: `StreamingAgentController.java`

```java
@RestController
@RequestMapping("/api/agent/stream")
public class StreamingAgentController {

    @PostMapping(value = "/chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public SseEmitter chatStream(@RequestBody String message) {
        SseEmitter emitter = new SseEmitter(30000L);

        streamingAgentService.chatStream(message, new TokenHandler() {
            @Override
            public void onToken(String token) throws IOException {
                emitter.send(SseEmitter.event().data(token).name("message"));
            }

            @Override
            public void onComplete() throws IOException {
                emitter.send(SseEmitter.event().data("[DONE]").name("done"));
                emitter.complete();
            }

            @Override
            public void onError(Throwable error) throws IOException {
                emitter.send(SseEmitter.event().data(error.getMessage()).name("error"));
                emitter.completeWithError(error);
            }
        });

        return emitter;
    }
}
```

**关键点**:
- 返回类型是`SseEmitter`
- 使用`MediaType.TEXT_EVENT_STREAM_VALUE`
- 每个token通过SSE事件发送
- 发送`[DONE]`标记结束
- 处理错误情况

## 前端集成

### Vue 3 示例

```vue
<template>
  <div class="chat-container">
    <div class="messages">
      <div v-for="(msg, index) in messages" :key="index" class="message">
        <div class="message-content">{{ msg.content }}</div>
      </div>
    </div>

    <div class="input-area">
      <input
        v-model="userInput"
        @keyup.enter="sendMessage"
        placeholder="输入消息..."
        :disabled="isLoading"
      />
      <button @click="sendMessage" :disabled="isLoading">
        {{ isLoading ? '发送中...' : '发送' }}
      </button>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import { fetchEventSource } from '@microsoft/fetch-event-source';

const messages = ref([]);
const userInput = ref('');
const isLoading = ref(false);

async function sendMessage() {
  if (!userInput.value.trim() || isLoading.value) return;

  const userMessage = userInput.value;
  messages.value.push({ role: 'user', content: userMessage });
  userInput.value = '';
  isLoading.value = true;

  // 创建AI消息占位
  const aiMessageIndex = messages.value.length;
  messages.value.push({ role: 'ai', content: '' });

  try {
    await fetchEventSource('/api/agent/stream/chat', {
      method: 'POST',
      headers: {
        'Content-Type': 'text/plain',
      },
      body: userMessage,
      onmessage(msg) {
        if (msg.event === 'message') {
          // 追加内容
          messages.value[aiMessageIndex].content += msg.data;
        } else if (msg.event === 'done') {
          console.log('流式输出完成');
        } else if (msg.event === 'error') {
          console.error('错误:', msg.data);
        }
      },
      onerror(err) {
        console.error('SSE错误:', err);
        isLoading.value = false;
      },
      onclose() {
        isLoading.value = false;
      }
    });
  } catch (error) {
    console.error('请求失败:', error);
    isLoading.value = false;
  }
}
</script>
```

### React 示例

```jsx
import React, { useState } from 'react';
import { fetchEventSource } from '@microsoft/fetch-event-source';

function ChatComponent() {
  const [messages, setMessages] = useState([]);
  const [input, setInput] = useState('');
  const [isLoading, setIsLoading] = useState(false);

  const sendMessage = async () => {
    if (!input.trim() || isLoading) return;

    const userMessage = input;
    setMessages(prev => [...prev, { role: 'user', content: userMessage }]);
    setInput('');
    setIsLoading(true);

    const aiMessageIndex = messages.length + 1;
    setMessages(prev => [...prev, { role: 'ai', content: '' }]);

    try {
      await fetchEventSource('/api/agent/stream/chat', {
        method: 'POST',
        headers: {
          'Content-Type': 'text/plain',
        },
        body: userMessage,
        onmessage(msg) {
          if (msg.event === 'message') {
            setMessages(prev => {
              const newMessages = [...prev];
              newMessages[aiMessageIndex].content += msg.data;
              return newMessages;
            });
          }
        },
        onclose() {
          setIsLoading(false);
        }
      });
    } catch (error) {
      console.error('请求失败:', error);
      setIsLoading(false);
    }
  };

  return (
    <div className="chat-container">
      <div className="messages">
        {messages.map((msg, index) => (
          <div key={index} className="message">
            {msg.content}
          </div>
        ))}
      </div>
      <input
        value={input}
        onChange={(e) => setInput(e.target.value)}
        onKeyPress={(e) => e.key === 'Enter' && sendMessage()}
        disabled={isLoading}
      />
      <button onClick={sendMessage} disabled={isLoading}>
        发送
      </button>
    </div>
  );
}
```

```
data: 食
```

**事件类型**:

```python
import requests
import sseclient

def stream_chat(message):
    response = requests.post(
        'http://localhost:8080/api/agent/stream/chat',
        data=message,
        stream=True
    )

    client = sseclient.SSEClient(response)
    for event in client.events():
        if event.event == 'message':
            print(event.data, end='', flush=True)
        elif event.event == 'done':
            print('\n完成')
            break
        elif event.event == 'error':
            print(f'错误: {event.data}')
            break
```

## 性能优化

### 1. 减少延迟

**后端优化**:
- 使用连接池复用HTTP连接
- 减少中间处理层数
- 异步非阻塞处理

**前端优化**:

## 故障排查

### 问题1: SSE连接断开

**症状**: 连接经常中断

**原因**:
- 超时设置过短
- 网络不稳定
- 服务器负载过高

**解决**:
```java
// 增加超时时间
SseEmitter emitter = new SseEmitter(60000L); // 60秒

// 添加心跳
@Scheduled(fixedRate = 15000)
public void sendHeartbeat() {
    emitter.send(SseEmitter.event().comment("heartbeat"));
}
```

### 问题2: Token显示乱码

**症状**: 中文字符显示异常

**原因**: 编码问题

**解决**:
```java
// 确保UTF-8编码
@Bean
public Charset charset() {
    return StandardCharsets.UTF_8;
}

// 前端也要设置UTF-8
headers: {
  'Content-Type': 'text/plain; charset=UTF-8'
}
```

### 问题3: 流式输出卡顿

**症状**: 输出不流畅

**原因**:
- LLM响应慢
- 网络延迟
- 处理阻塞

**解决**:
- 使用更快的模型
- 优化网络
- 异步处理

### 问题4: 内存泄漏

**症状**: 内存持续增长

**原因**:
- ChatMemory无限增长
- SSE连接未关闭
- 缓存未清理

**解决**:
```java
// 限制ChatMemory大小
MessageWindowChatMemory.withMaxMessages(20);

// 确保连接关闭
emitter.onCompletion(() -> {
    cleanup();
});

emitter.onTimeout(() -> {
    cleanup();
});
```
