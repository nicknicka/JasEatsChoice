# 佳食宜选

佳食宜选是一个围绕“点餐 + 营养管理 + 社交互动 + AI 助手”构建的多端餐饮系统仓库，当前包含桌面端前端、后端服务、小程序端和一套 Playwright 自动化测试工程。

## 仓库结构

- `JasEatsChoiceJava`
  Spring Boot 后端，负责认证、订单、推荐、钱包、聊天、AI、商家管理、管理员管理等业务接口。
- `JasEatsChoiceFront`
  Electron + Vue 3 桌面端前端，包含用户端、商家端、管理员端界面。
- `JasEatsChoiceUniApp`
  UniApp 小程序端代码。
- `tests`
  Playwright 自动化测试、测试夹具、测试报告和进度台账。
- `docs`
  当前仍在参考的专题文档。
- `archive`、`memory`
  历史分析、阶段性总结和归档资料，不默认作为“当前状态”依据。
