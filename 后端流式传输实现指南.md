## 后端需要实现的功能

### 1. 控制器修改

需要修改AI聊天接口，返回SSE（Server-Sent Events）格式的流式响应。

#### 修改前（普通响应）
```java
@PostMapping("/v1/ai/chat")
public Result<ChatResponse> chat(@RequestBody ChatRequest request) {
    String response = aiService.chat(request.getMessage());
    return Result.success(new ChatResponse(response));
}
```

#### 修改后（流式响应）
```java
@PostMapping(value = "/v1/ai/chat", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter chat(@RequestBody ChatRequest request) {
    // 创建超时时间为30秒的SseEmitter
    SseEmitter emitter = new SseEmitter(30000L);

    // 在异步线程中处理AI响应
    ExecutorService executor = Executors.newSingleThreadExecutor();
    executor.execute(() -> {
        try {
            // 调用AI服务获取流式响应
            String aiResponse = aiService.chatStream(request.getMessage(), (chunk) -> {
                try {
                    // 发送每个数据块
                    emitter.send(SseEmitter.event()
                        .data("{\"content\":\"" + chunk + "\"}")
                        .build());
                } catch (IOException e) {
                    logger.error("发送流式数据失败", e);
                    emitter.completeWithError(e);
                }
            });

            // 发送完成标记
            emitter.send(SseEmitter.event().data("[DONE]").build());
            emitter.complete();

        } catch (Exception e) {
            logger.error("AI聊天处理失败", e);
            emitter.completeWithError(e);
        } finally {
            executor.shutdown();
        }
    });

    return emitter;
}
```

### 2. AI服务层修改

需要修改AI服务，支持流式回调。

#### 示例实现
```java
public String chatStream(String message, Consumer<String> callback) {
    // 调用智谱AI或其他AI服务的流式接口
    // 示例：使用智谱AI SDK

    ChatCompletionRequest chatRequest = ChatCompletionRequest.builder()
        .messages(Arrays.asList(Message.builder()
            .role(Role.USER.value())
            .content(message)
            .build()))
        .stream(true)  // 启用流式输出
        .build();

    // 流式处理响应
    ModelApi.streamChatCompletion(chatRequest, new ResultSubscriber<ChatCompletion>() {
        @Override
        public void onEvent(ChatCompletion event) {
            if (event.getChoices() != null && !event.getChoices().isEmpty()) {
                Delta delta = event.getChoices().get(0).getDelta();
                if (delta != null && delta.getContent() != null) {
                    // 通过回调发送每个token
                    callback.accept(delta.getContent());
                }
            }
        }

        @Override
        public void onComplete() {
            logger.info("AI流式响应完成");
        }

        @Override
        public void onError(Throwable error) {
            logger.error("AI流式响应出错", error);
        }
    });

    return "success";
}
```

### 4. SSE数据格式说明

前端期望接收的数据格式（SSE格式）：

```
data: {"content":"你好"}
data: {"content":"，我是"}
data: {"content":"AI助手"}
data: [DONE]
```

每行格式：
- `data:` 开头
- 后面跟JSON数据或`[DONE]`标记
- 以`\n\n`结尾

## 注意事项

1. **超时处理**：AI响应时间较长，建议设置合理的超时时间（30-60秒）
2. **错误处理**：流式传输中断时需要正确关闭emitter
3. **资源管理**：使用线程池处理异步任务，避免创建过多线程
4. **CORS配置**：如果前后端分离，需要配置CORS允许SSE
5. **Nginx配置**：如果使用Nginx代理，需要配置支持SSE：

```nginx
location /api {
    proxy_pass http://backend:8080;
    proxy_set_header Connection '';
    proxy_http_version 1.1;
    chunked_transfer_encoding on;
    proxy_buffering off;  # 关闭缓冲，启用流式传输
}
```

## 智谱AI流式调用示例

如果使用智谱AI SDK，流式调用方式：

```java
import com.zhipu.ai.model.ChatCompletionRequest;
import com.zhipu.ai.model.ChatCompletion;
import com.zhipu.ai.model.Delta;
import com.zhipu.ai.model.Message;
import com.zhipu.ai.model.Role;
import com.zhipu.ai.util.ResultSubscriber;

// 构建请求
ChatCompletionRequest request = ChatCompletionRequest.builder()
    .model("glm-4")  // 或其他模型
    .stream(true)
    .messages(Arrays.asList(
        Message.builder()
            .role(Role.USER.value())
            .content(userMessage)
            .build()
    ))
    .build();

// 流式处理
ModelApi.streamChatCompletion(request, new ResultSubscriber<ChatCompletion>() {
    @Override
    public void onEvent(ChatCompletion event) {
        Delta delta = event.getChoices().get(0).getDelta();
        String content = delta.getContent();
        if (content != null) {
            // 发送到前端
            callback.accept(content);
        }
    }

    @Override
    public void onComplete() {
        // 流式传输完成
        emitter.complete();
    }

    @Override
    public void onError(Throwable error) {
        // 错误处理
        emitter.completeWithError(error);
    }
});
```

## 完整工作流程

1. 前端发送请求到后端
2. 后端创建SseEmitter并立即返回
3. 后端在异步线程中调用AI服务
4. AI服务通过回调函数逐个返回token
5. 每个token通过SSE发送到前端
6. 前端实时显示接收到的内容
7. 发送完成后，后端发送`[DONE]`标记
8. 前端接收`[DONE]`后完成显示
