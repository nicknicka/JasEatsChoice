# 佳食宜选毕设附件打包说明

## 目的

本说明用于生成适合毕业设计提交的项目附件压缩包。附件内容以项目源码、核心项目文档、数据库脚本和论文支撑材料为主，不包含依赖安装目录、构建产物、运行缓存和上传数据。

## 打包原则

1. 保留可复现项目的核心源码与配置文件。
2. 保留论文撰写和答辩需要的关键说明文档。
3. 排除 `node_modules`、`target`、`dist`、`out`、`unpackage`、`uploads` 等大体积生成内容。
4. 排除 `.git`、`.idea`、`.vscode`、`.claude`、`.DS_Store` 等与提交无关的环境文件。
5. 对附件副本中的本地开发配置进行脱敏处理，避免直接携带 `API Key`、`JWT` 密钥、邮箱授权码、微信 `appid` 或默认口令。

## 附件目录

- `00-附件说明`
  包含本说明文件。
- `01-项目源码`
  包含后端、桌面端前端、小程序端、测试工程、数据库脚本、部署配置和辅助脚本。
- `02-项目文档`
  包含项目概述、需求文档、接口文档、实现与测试说明等核心材料。
- `03-论文材料`
  包含论文初稿、图示文档和指导记录等支撑材料。

## 输出位置

执行脚本后，会在 `output/thesis-package/` 目录下生成：

- 一个整理后的附件目录
- 一个可直接上传的 `.zip` 压缩包

为提升教务系统、网盘和不同解压环境下的兼容性，输出目录名和压缩包文件名统一使用英文命名，文档内容仍保持中文。

## 执行方式

```bash
zsh scripts/package_thesis_attachment.sh
```

## 说明

如果后续需要重新生成附件，直接再次执行脚本即可，脚本会覆盖同日期的旧打包结果。

附件中的相关密钥和配置值已替换为占位符。如果评审老师需要本地运行项目，可按源码目录中的说明文件自行补充数据库、地图服务、微信小程序和部署参数。
