## 二、主要工作

### （一）系统架构搭建

学生完成了三端分离的系统架构设计与搭建：

- **后端服务（JasEatsChoiceJava）**：基于SpringBoot 3.2.5 + MyBatis-Plus + MySQL 8.0 + Redis 7 + Netty，实现了RESTful API接口服务，集成Spring Security + JWT身份认证，采用Netty构建WebSocket实时通信服务；
- **桌面管理端（JasEatsChoiceFront）**：基于Electron + Vue 3 + Element Plus，实现了管理员端、商家端和用户端三套界面，共72个功能页面；
- **移动端小程序（JasEatsChoiceUniApp）**：基于UniApp框架开发，实现了用户端和商家端双角色小程序，覆盖30余个用户端页面和9个商家端页面目录。

三端统一对接后端API，数据层采用MySQL持久化 + Redis缓存的双层存储方案，部署层编写了Docker Compose容器化编排配置（含Nginx、Spring Boot、MySQL、Redis、Certbot五个服务）。

### （二）用户端核心功能开发

学生已完成任务书中用户端的全部核心功能模块：

1. **个性化饮食推荐**：实现了基于地理位置、天气、时间和用户偏好的多维度推荐，集成了定位API和天气API，支持推荐拒绝行为记录与权重调整；
2. **卡路里精准管理**：实现了每日卡路里摄入计算、实时剩余展示和周/月摄入趋势分析，用户可查看菜品级卡路里明细；
3. **全链路订单管理**：完成了"选菜-定制-支付-追踪-评价"完整订单流程，支持菜品备注、口味定制、再来一单、订单状态实时追踪；
4. **社交互动功能**：基于Netty WebSocket实现了单聊和群聊功能，支持群订单协同、菜品分享、多人分摊支付和加菜流程；
5. **AI饮食助手**：基于LangChain4j框架集成智谱AI大模型，实现了Supervisor模式的多Agent协作架构，支持流式对话输出、菜品推荐、商家查询等工具调用，并实现了用户对话隔离和内容提取功能；
6. **个人中心与设置**：实现了用户注册/登录（含图形验证码和短信验证码）、地址管理、钱包管理、收藏、食谱管理、消息中心等功能。

### （三）商家端核心功能开发

学生已完成任务书中商家端的全部核心功能模块：

1. **订单管理**：实现了今日订单列表、订单接单、菜品步骤状态更新（备菜-预处理-烹饪-摆盘-上菜）和订单完成确认；
2. **菜品精细化管理**：实现了菜品发布、上下架、分类管理、标签设置（招牌菜/推荐菜/季节限定）、烹饪步骤配置和营养信息管理；
3. **菜单管理**：支持多菜单配置和菜单编辑功能；
4. **营业统计**：实现了订单量统计和营收分析功能；
5. **评价中心**：实现了评价查看、回复和管理功能；
6. **想吃列表审核**：支持用户共创菜品的审核流程；
7. **消息与聊天**：实现了客服聊天和系统通知功能。
