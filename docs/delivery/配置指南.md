# 配置指南

## 必装软件

建议安装以下软件后再运行项目：

- JDK 21。
- Maven 3.9 或以上。
- Node.js 18 或 20，建议同时安装 npm。
- MySQL 8.0。
- Redis 7.x。
- Docker Desktop 或 Docker Engine + Docker Compose，可选，用于容器化运行。
- 微信开发者工具，可选，用于运行小程序端。

## 环境变量

### 后端常用环境变量

后端默认会读取 `apps/server/src/main/resources/application.yml` 和对应环境配置。生产环境建议通过环境变量覆盖敏感配置：

```bash
export SPRING_PROFILES_ACTIVE=prod
export DB_URL='jdbc:mysql://localhost:3306/jia_shi_yi_xuan?useUnicode=true&characterEncoding=UTF-8&serverTimezone=GMT%2B8&allowPublicKeyRetrieval=true'
export DB_USERNAME='root'
export DB_PASSWORD='与 deploy/.env 中的 DB_PASSWORD 一致'
export REDIS_HOST='localhost'
export REDIS_PORT='6379'
export REDIS_PASSWORD=''
export JWT_SECRET='请替换为32位以上随机字符串'
export AI_API_KEY='请替换为自己的智谱AI密钥'
export FILE_UPLOAD_PATH='./uploads/'
export FILE_SERVER_URL='http://localhost:7777/api'
```

本地开发时也可以直接使用 `application-local.yml` 的默认配置：

- 数据库名：`jia_shi_yi_xuan`
- 数据库账号：`root`
- 数据库密码：见 `deploy/.env` 的 `DB_PASSWORD`
- Redis 地址：`localhost:6379`

### 桌面端环境变量

桌面端配置文件位于 `apps/client/.env.local` 和 `apps/client/.env.production`。

本地开发推荐配置：

```bash
VITE_API_BASE_URL=http://localhost:7777/api
VITE_WS_URL=ws://localhost:11277/ws
VITE_WS_CHAT_URL=ws://localhost:11277/ws/chat
VITE_UPLOAD_URL=http://localhost:7777/api/v1/upload
VITE_IMAGE_CDN=
VITE_AMAP_KEY=请替换为自己的高德地图Key
VITE_AMAP_SECURITY_JS_CODE=请替换为自己的高德安全密钥
```

### 小程序端配置

小程序端主要配置文件：

- `apps/miniapp/src/config/index.js`
- `apps/miniapp/src/manifest.json`
- `apps/miniapp/project.config.json`

需要按自己的环境修改：

- 后端接口地址。
- WebSocket 地址。
- 上传地址。
- 微信小程序 AppID。
- 小程序后台的合法请求域名、合法上传域名和合法 WebSocket 域名。

## 数据库初始化

1. 创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS jia_shi_yi_xuan
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

2. 启动后端，让 Flyway 执行迁移：

后端启动时会从 classpath 下的 `db/migration` 依次执行 `V1~V9` 迁移，生成表结构并导入种子数据，无需手动导入 `db/init` 下的来源脚本。

```bash
make up
```

3. `db/migrations` 是历史迁移脚本归档，仅作追溯，不参与启动，也不要手动执行。

## 第三方服务配置

以下服务不是启动基础流程的强制项，但对应功能需要配置后才能完整使用：

- 智谱 AI：AI 助手、菜品识别、内容理解。
- 高德地图或腾讯地图：定位、天气、附近商家。
- 邮箱 SMTP：邮箱验证码。
- 微信小程序 AppID：小程序登录与发布。

交付包中第三方密钥均已替换为占位符，接收方需要自行申请并填写。
