# 佳食宜选项目说明

## 项目简介

佳食宜选是一套面向校园餐饮场景的多端系统，围绕点餐、营养管理、商家经营、社交互动和 AI 饮食助手构建。项目包含 Spring Boot 后端、Electron + Vue 3 桌面端、UniApp 小程序端、数据库脚本、Docker 部署配置和自动化测试工程。

## 技术栈

- 后端：Spring Boot 3.2.5、MyBatis-Plus、MySQL 8、Redis 7、Netty、SpringDoc、LangChain4j、智谱 AI 接口。
- 桌面端：Electron、Vue 3、Element Plus、Pinia、Vue Router、Axios、ECharts。
- 小程序端：UniApp、Vue 3、Pinia、uni-ui。
- 测试：Playwright。
- 部署：Docker、Docker Compose、Nginx。

## 核心功能

- 用户端：注册登录、首页推荐、商家浏览、菜品详情、下单支付、订单管理、饮食记录、卡路里管理、收藏、钱包、聊天、AI 饮食助手、地址管理、教程内容。
- 商家端：商家入驻、菜单管理、菜品管理、订单处理、经营统计、评价中心、消息聊天、AI 经营辅助。
- 管理端：用户管理、商家审核、菜品审核、订单与退款、财务管理、系统配置。
- 小程序端：覆盖用户与商家常用移动端流程。

## 默认运行地址

- 后端接口：http://localhost:7777/api
- 后端健康检查：http://localhost:7777/api/actuator/health
- Netty WebSocket：ws://localhost:11277/ws
- 桌面端开发服务：由 `npm run dev` 自动启动 Electron。
- 小程序开发服务：由 `npm run dev:mp-weixin` 生成微信小程序构建目录。
