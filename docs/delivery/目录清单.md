# 目录清单

## 交付包目录

- `00_delivery_docs`：交付说明文档，包含项目说明、配置指南、部署和使用说明、系统需求分析。
- `01_source_code`：项目源码，包含后端、桌面端、小程序端、测试工程、Docker 配置和辅助脚本。
- `02_project_docs`：现有项目文档，包括需求、接口、测试报告等。
- `03_database_scripts`：数据库完整备份、迁移脚本和营养数据脚本。

## 源码目录

- `01_source_code/JasEatsChoiceJava`：Spring Boot 后端。
- `01_source_code/JasEatsChoiceJava/src/main/java/com/xx/jaseatschoicejava/controller`：后端接口控制器。
- `01_source_code/JasEatsChoiceJava/src/main/java/com/xx/jaseatschoicejava/service`：业务服务层。
- `01_source_code/JasEatsChoiceJava/src/main/java/com/xx/jaseatschoicejava/mapper`：MyBatis-Plus 数据访问层。
- `01_source_code/JasEatsChoiceJava/src/main/java/com/xx/jaseatschoicejava/entity`：数据库实体。
- `01_source_code/JasEatsChoiceJava/src/main/java/com/xx/jaseatschoicejava/netty`：即时通信相关服务。
- `01_source_code/JasEatsChoiceJava/src/main/resources`：后端配置、映射文件和 SQL 资源。
- `01_source_code/JasEatsChoiceFront`：Electron + Vue 3 桌面端。
- `01_source_code/JasEatsChoiceFront/src/renderer/src/views`：桌面端用户、商家、管理员页面。
- `01_source_code/JasEatsChoiceFront/src/renderer/src/components`：桌面端公共组件。
- `01_source_code/JasEatsChoiceFront/src/renderer/src/api`：桌面端接口封装。
- `01_source_code/JasEatsChoiceFront/src/renderer/src/config`：桌面端运行配置。
- `01_source_code/JasEatsChoiceUniApp`：UniApp 小程序端。
- `01_source_code/JasEatsChoiceUniApp/src/pages-user`：小程序用户端页面。
- `01_source_code/JasEatsChoiceUniApp/src/pages-merchant`：小程序商家端页面。
- `01_source_code/JasEatsChoiceUniApp/src/api`：小程序接口封装。
- `01_source_code/JasEatsChoiceUniApp/src/config`：小程序运行配置。
- `01_source_code/tests`：Playwright 自动化测试。
- `01_source_code/docker`：Docker Compose 和 Nginx 配置。

## 数据库脚本目录

- `03_database_scripts/full-database-backup.sql`：完整数据库备份脚本，优先用于本地初始化。
- `03_database_scripts/migrations`：增量数据库迁移脚本。
- `03_database_scripts/java-sql`：后端模块附带 SQL。
- `03_database_scripts/nutrition`：营养成分相关 SQL。

## 自动生成清单

打包脚本会额外生成 `00_delivery_docs/自动生成目录清单.txt`，该文件记录压缩包内的完整文件列表。
