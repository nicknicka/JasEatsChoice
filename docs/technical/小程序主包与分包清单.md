# 小程序主包与分包清单

本文档以 `JasEatsChoiceUniApp/src/pages.json` 为准，说明当前小程序页面的实际打包边界。

## 主包页面

- `pages/splash/index`
- `pages/role-select/index`
- `pages/login/index`
- `pages/register/index`
- `pages/forgot-password/index`
- `pages/home/index/index`
- `pages/recipe/index`
- `pages/ai/index`
- `pages/message/index`
- `pages/profile/user-center/index`

主包职责：

- 启动和鉴权入口
- TabBar 一级页面
- 首次加载必须可达的核心页面

## 用户端分包 `pages-user`

已注册的用户端二级页面包括：

- 搜索、商家详情、菜品详情、菜品列表
- 购物车、订单确认、订单详情、订单进度、订单列表
- 评价列表、提交评价
- 我的食谱、食谱详情
- AI 高级分析、内容提取
- 设置、编辑资料
- 地址列表、地址编辑
- 收藏、历史、优惠券、钱包、交易明细
- 消息列表、系统通知、通知详情
- 帮助、反馈、卡路里模块
- 商家列表、个人积分、关于页、性能演示
- 群订单：列表、创建、详情、选菜、结算、分享

分包职责：

- 登录后的用户侧功能页
- 非首屏必需的二级业务页

## 商家端分包 `pages-merchant`

已注册的商家端页面包括：

- 商家首页、统计、分析
- 订单列表、订单详情、处理、今日订单
- 菜品管理、菜单管理
- 评论、心愿单、商家聊天
- 商家资料、店铺、财务、提现、设置、教程

## 公共分包 `pages-common`

已注册的公共页面包括：

- 会话列表
- 聊天室
- 支付页
- 支付结果页
- WebView 页面

## 维护规则

- 页面是否有效，先看 `src/pages.json` 是否注册，不以目录是否存在为准。
- 主包只放启动、登录、TabBar 一级页面。
- 用户二级功能页优先放 `pages-user`。
- 商家功能页优先放 `pages-merchant`。
- 目录中仍存在部分未注册的历史页面文件，这些文件不能作为新功能入口继续引用。
