# 商家设置（merchant/13-settings）

- 截图：output/web-screenshots/merchant/13-settings.png
- URL：/merchant/home/settings
- 评审人：review-merchant

## 这页在讲什么
这页负责让商家修改账号资料、字体大小、通知与隐私开关；当前所有设置被塞进一张超高白卡，四类设置只有一条细分割线相隔，四类之间没有可跳转的分区结构。

## 主角 / 主动作
主角是各设置项本身，主动作是“修改”与开关切换。标题“设置”只是页面左上角一段纯文字，没有任何标题容器或层级装饰，与全站其它页面头部都不一致，页面像未加载完样式。

## 层级与构图
- 标题“设置”字号约 28px、左对齐在 y≈84，直接落在米色背景上；下方卡片从 y≈130 开始一直延伸到视口底部，没有可见的页尾。
- 卡内四段：🤖用户设置、🔍显示设置、🔔通知设置、👻隐私设置，各段标题 16px 加粗、段间用 1px 灰线分隔，分隔线起到分组作用但组标题与内容的左右缩进关系不明确。
- 用户设置列为三行“头像/手机号/邮箱/密码”，标签右对齐、值左对齐，右侧固定一个蓝色“修改/更换头像”文字按钮；“更换头像”是蓝色实心按钮，与“修改”文字链接两种样式混用。
- 字体大小一行用四个单选（小/中/大/超大），圆点样式默认，与全站 Element Plus 风格不同。
- 建议：给页面加与其它页一致的标题容器；把四段拆成可定位的分区（左侧锚点或顶部 Tab）；统一“修改”类操作的样式为一种。

## 色彩与字体
- 卡片大面积白底，正文灰黑，蓝色只出现在“修改/更换头像”与开关上；开关统一使用蓝色，与全站品牌橙、订单页绿色、统计页绿色都不一致。
- 字段标签用灰色 14px、值用深色 15px，层级可用；邮箱值为空时只显示输入框占位，和“手机号 173****2222”这种有值状态并排，看不出是“未绑定”还是“读取失败”。
- 段标题前全部使用 emoji（🤖🔍🔔👻），其中“用户设置”用机器人、“隐私设置”用幽灵，与设置语义无关。
- 建议：开关与“修改”统一为全站主色；空邮箱给出“未绑定，点击绑定”的明确状态文字；替换 emoji 为线性图标或直接去掉。

## 留白与节奏
- 表单控件集中在卡片左半部分，右侧约 500px 宽从“用户设置”到“隐私设置”全程空白，是页面最大的一块死区。
- 各段之间的分隔线间距均匀，段内行距也稳定；问题是所有段都无法在同屏内看完，滚动时容易失去所在分组的位置。
- 建议：把表单栏宽限制到合理阅读宽度后整体居中，或采用“左分区导航 + 右内容”的两栏布局，让右侧空白变成可用空间与定位线索。

## 动效与交互反馈
- 静态截图无法验证修改弹窗、开关切换与保存。所有开关看起来默认开启且没有保存入口，用户不知道改动是否即时生效。
- 建议：开关切换给 160ms 过渡并即时保存；修改手机号/邮箱/密码弹出统一表单弹窗；切换字体大小的单选后页面文字实时预览。

## 与相邻页的一致性
- 本页是全部页面中唯一没有标题卡/标题条的页面，头部语言落差最大，应优先统一。
- 开关的蓝色、按钮的蓝色与 09 聊天气泡、12 刷新按钮的蓝色同源，但都与侧栏品牌橙不一致，需要收敛为统一主色。
- 单选、开关、文字按钮三种控件都使用默认形态，与 06/08 表单控件的圆角与描边风格不同。

## 改造建议
- P0 必改：补上与其它页一致的标题容器；把表单收窄居中或改为左右分区，收回右侧大面积空白。
- P1 建议：统一按钮与开关到全站主色，明确空邮箱与保存状态，替换 emoji 段标题。
- P2 可选：加入开关即时保存反馈、修改弹窗与字体大小实时预览。
