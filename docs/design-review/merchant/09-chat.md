# 商家聊天（merchant/09-chat）

- 截图：output/web-screenshots/merchant/09-chat.png
- URL：/merchant/home/chat
- 评审人：review-merchant

## 这页在讲什么
这页负责让商家在左侧会话列表里选人、在右侧完成对话；当前画面结构清楚，能一眼看出“谁在跟我说话、我被说过什么、我回了什么”。

## 主角 / 主动作
主角是右侧当前会话，主动作是输入并发送消息。页面结构把会话列表和消息面板左右分开，方向正确；但左侧搜索框与“仅显示未读”是列表的辅助功能，却被放在页面顶部一条独立的宽卡里，占掉一条与内容无关的横向空间。

## 层级与构图
- 页面标题“【商家消息】”与侧栏菜单项“商家聊天”名称不一致，同一功能出现两个叫法。
- 顶部“搜索会话…/仅显示未读”被包在一条横跨整页的卡里，搜索属于会话列表却不与列表同一列，视线需要横向跨过整个页面再回到左边。
- 会话列表项高度约 82px，包含头像、名字、最后一条消息与时间，信息完整；选中项用左侧绿色条加浅色底标记，识别度足够。
- 右侧消息面板只在左半部分有内容，气泡宽度约为面板的三分之一，右侧与下方留白极大；这属于“消息少”的正常表现，但气泡没有被约束到合适的阅读行宽，长消息会撑得很宽。
- 建议：把搜索与未读筛选移入左栏顶部，与列表同宽；统一标题与侧栏命名；给消息气泡设最大宽度约 60%–70%，并让对话区在有更多消息时保持贴底滚动。

## 色彩与字体
- 左侧绿色选中条 + 浅绿底起到状态指示作用，和全站品牌橙不同，但与 05 消息中心的绿色头部一致。
- 对方气泡使用浅绿、我方气泡使用浅蓝，两者都用描边加浅底；常用约定是“我方用品牌强调色、对方用中性色”，当前配色把双方都做成同权。
- 会话列表里头像统一为灰底单字，名字 14px 加粗、末条消息 13px 灰色，时间 12px，层级可用；输入框 placeholder“输入消息内容…”与正文灰度接近。
- 建议：我方气泡改用品牌色实底或明确强调描边，对方气泡保持中性；“发送”按钮在输入为空时给明显的禁用态。→ 当前“发送”按钮已是灰底，与输入为空的判断一致，可保留但需补 hover/可用态区分。

## 留白与节奏
- 顶部搜索卡约 70px，会话列表卡与聊天卡各占满剩余高度，整体三段式节奏稳定。
- 左栏宽度约 260px，头像+三行文字挤得较紧；右栏 900px 里只有两个气泡，留白集中在右下方而不是围绕内容。
- 建议：把顶部搜索并回左栏，让左栏高度全部用于列表；右栏消息区从面板顶部开始贴底排列，减少“内容悬空”。

## 动效与交互反馈
- 静态截图无法验证发送、滚动加载与未读切换。底部提示“按 Enter 发送，Shift + Enter 换行”是良好的辅助说明。
- 建议：发送后气泡以 160–200ms 淡入并自动滚到底；新消息到达时列表项短暂高亮；未读徽标（当前为红色“10”）在已读后原位消失。

## 与相邻页的一致性
- 与 05“消息管理”同为消息类页面，但 05 用深绿标题条、09 用无容器粗体标题，两页头部与命名都需要统一。
- 会话气泡的浅绿/浅蓝与 05 的分类色、12 的 KPI 色同属一套浅色系，可收敛到统一的语义色表。
- 输入框、发送按钮的形态可作为全站文本输入规范的基础，与 16“AI 经营助手”的输入区应对齐圆角、高度与按钮样式。

## 改造建议
- P0 必改：统一页面标题与侧栏命名；把搜索/未读筛选并回左栏，让出顶部独立卡。
- P1 建议：区分己方/对方气泡的强调关系，给消息气泡设最大宽度。
- P2 可选：加入发送淡入、自动滚底与新消息高亮反馈。
