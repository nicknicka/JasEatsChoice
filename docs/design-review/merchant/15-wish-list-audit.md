# 想吃列表审核（merchant/15-wish-list-audit）

- URL：/merchant/home/wish-list-audit

## 这页在讲什么
这页负责让商家按状态审核想吃条目并处理通过/拒绝；当前三张全为 0 的统计卡和一行 Tab 之后，页面用一张居中的空状态收尾，页面结构清楚、没有多余装饰。

## 主角 / 主动作
主角是审核列表，主动作是“通过/拒绝”。列表为空时，主动作退化为确认或刷新；右上角“刷新”按钮目前是唯一的页面级动作，位置与层级合适。

## 层级与构图
- 标题“想吃列表审核”是页面左上角纯文字，右侧“刷新”是灰色描边小按钮，头部没有任何卡片容器，与 04/07/10 的白色标题卡不同。
- 三张统计卡等宽并排：待审核 0、今日已通过 0、今日已拒绝 0，纯白底、黑色 36px 数值、灰色标签居中，无图标无彩色；三张卡高约 100px，信息密度合理。
- 统计卡下是一行 Tab：全部（蓝色下划线选中）、待审核、已通过、已拒绝、申诉中；Tab 与统计卡表达同一组状态，但一个用于计数、一个用于筛选，职责尚能区分。
- 空状态插图为浅灰纸箱，位于可视区域中部（约 y≈440），文案“暂无审核项目”在 y≈490，位置比 03/05 的空状态更合理。
- 建议：给页面补上统一的标题容器；保留当前统计卡 + Tab + 居中空状态的骨架，作为其它空列表页的参照。

## 色彩与字体
- 全页面积最大的是米色背景与白色卡片，强调色只有选中 Tab 的蓝色下划线和侧栏品牌橙，色彩克制、对比清晰。
- 三张统计卡的数值使用纯黑 36px、标签 13px 灰色居中，层级清楚，但三张卡完全同色，无法一眼区分“待审核”与“今日已通过/已拒绝”。
- 空状态插图为浅灰线稿风格，与 03/05 的蓝灰纸箱插图风格接近。
- 建议：保持中性基调，仅给“待审核”数值加一处品牌强调色（有值时），用于提示需要行动；避免再引入独立色系。

## 留白与节奏
- 标题行约 70px、统计卡约 100px、Tab 约 55px，三段紧凑地压在页面顶部约 280px 内，节奏偏快。
- 空状态从 y≈440 开始向下留出约 400px 背景，居中的位置让页面平衡，但 Tab 与空状态之间约 200px 的空白略空。
- 建议：把空状态上移到 Tab 下方约 80px 处，或在空白区补充“如何获得想吃条目”的一句说明。

## 动效与交互反馈
- 静态截图无法验证 Tab 切换与审核动作。空状态没有说明“为什么为空”或下一步。
- 建议：Tab 切换 160ms 过渡并在有数据时原位切换列表；空状态淡入 180–220ms；审核通过/拒绝后该条以 200ms 淡出，统计数字同步更新。

## 与相邻页的一致性
- 本页的统计卡（纯白、黑数字、无图标）与 05（五张彩色 KPI）、12（四张彩色 KPI）、14（四块满铺色）四种样式并存，统计组件必须统一。
- 空状态插图与 03/05 同源，位置居中更优，可作为统一空状态规范。
- 标题无容器的写法与 13“设置”相同，是跨页头部不统一的另一处证据。

## 改造建议
- P0 必改：统一统计卡样式与全站一致，给“待审核”一处行动强调色。
- P1 建议：补统一标题容器，适当上移空状态或补充说明文案。
- P2 可选：加入 Tab 切换、空状态淡入与审核后原位淡出动效。
