# 教程管理（merchant/14-tutorials）

- 截图：output/web-screenshots/merchant/14-tutorials.png
- URL：/merchant/home/tutorials
- 评审人：review-merchant

## 这页在讲什么
这页负责让商家创建教程并查看草稿、待审核、已发布的数量；当前四块高饱和实色统计块占据了页面顶部，而“有哪些教程”这一本页核心内容完全没有出现，只剩下一片空白。

## 主角 / 主动作
主角应是教程列表，主动作是“创建教程”。蓝色“+创建教程”按钮在标题行右侧，方向正确；但四块全为 0 的统计块抢走了全部注意力，列表为空时也没有任何空状态承接。

## 层级与构图
- 标题“我的教程”为白卡内粗体文字，右上角蓝色“+创建教程”按钮；标题卡高约 80px，是页面上唯一一处中性色区域。
- 四块统计块等宽并排、无圆角间隙、直接贴在一起：总计 0（深绿）、草稿 0（红）、待审核 0（土黄）、已发布 0（深绿）。它们是全页最强、最重的视觉元素。
- 统计块下方紧跟一行 Tab（全部教程/草稿/待审核/已发布），Tabs 与统计块几乎贴在一起，且这行 Tab 与上方统计块表达的是同一组分类，信息重复。
- 统计块以下的整个视口（约 y≈400–900）为纯空白背景，既没有列表也没有“暂无教程”的空状态，页面像加载失败。
- 建议：把四块实色统计压缩为一行轻量 KPI（浅底 + 语义色数字）；统计分类与 Tab 合并为同一组筛选；列表为空时补上与 05/15 一致的居中空状态与“创建第一个教程”动作。

## 色彩与字体
- 四块用深绿/红/土黄/深绿四种满铺实色，白字数值 40px；红色“草稿”块会被读成错误或危险，而草稿是正常状态。
- “总计”与“已发布”使用完全相同的深绿，两块并排时无法区分，颜色没有承担区分职责。
- 数值 40px、标签 14px 层级清楚，但在满铺色块上白字对比度虽高，颜色本身的信息价值低于它的视觉噪声。
- 建议：统一改用浅色底卡 + 语义色数字，只有“待审核”等需要行动的状态才用强调色；总计与已发布不可同色。

## 留白与节奏
- 统计块与标题卡之间约 20px，统计块与 Tab 之间几乎无间距，Tab 以下为大面积空白，节奏被压在上三分之一。
- 统计块在有值时也只用数字变化表达，高度与视觉重量不变，页面下半部将长期依赖列表撑满。
- 建议：压缩统计区高度到约 90px，把省下的空间给列表首屏；Tab 与统计块之间补足间距，避免两种分类表达粘连。

## 动效与交互反馈
- 静态截图无法验证创建、Tab 切换与列表加载。空列表没有任何反馈，用户无法判断是“没有教程”还是“还在加载”。
- 建议：补空状态并用 180–220ms 淡入；创建成功后新教程以 200ms 插入列表首位；Tab 切换保持统计块不变、列表原位切换并显示轻量 loading。

## 与相邻页的一致性
- 与 05/12 一样是“统计块 + 列表”页面，但 05/12 用浅色卡、本页用满铺实色块，三种统计组件完全不统一。
- 与 15“想吃列表审核”同样存在大块空白但无空状态的问题，两页应共享同一个空状态组件。
- 蓝色“+创建教程”按钮与 07“新增菜品”的浅绿、04“新增菜单”的绿色实心按钮三种样式并存，需统一主操作样式。

## 改造建议
- P0 必改：补列表空状态与创建入口承接；把四块实色统计改为浅底轻量卡并消除同色。
- P1 建议：合并统计分类与 Tab，统一“创建”主按钮样式与 04/07 对齐。
- P2 可选：加入空状态淡入、创建后插入与 Tab 切换 loading 反馈。
