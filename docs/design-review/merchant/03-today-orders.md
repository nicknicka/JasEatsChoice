# 商家今日订单（merchant/03-today-orders）

- 截图：output/web-screenshots/merchant/03-today-orders.png
- URL：/merchant/home/today-orders
- 评审人：review-merchant

## 这页在讲什么
这页应在选定日期下告诉商家“今天有没有单、这些单处于什么状态、现在该做什么”；当前页面把大量零值统计和筛选项保留在首屏，却把“今日无订单”放在很远的页面下部。

## 主角 / 主动作
主角是当天的订单集合，主动作是查看或处理当天订单。当天订单为 0 时，主动作应变成“确认日期/刷新/查看历史订单”；当前最显眼的是绿色页头和五个零值统计块，空状态不是主角。

## 层级与构图
- 标题中的日期 `2026-11-05` 只是小胶囊，和“返回”按钮、刷新按钮一起挤在绿色页头，日期作为筛选条件的可操作性不明显。
- KPI 同样采用 4+1 布局，第五张“已完成”孤立在第二行，和 02 一样造成横向断裂。
- 状态筛选和搜索框在 0 单时仍全部展示，所有 chip 都是零；此刻它们是无效选项，却占掉首屏约 170px。
- 空状态插图出现在约 y=730，下面仍有大面积米色背景，既不紧凑也不居中；应把空状态放到筛选区下方的剩余视觉中心，或直接压缩为一条明确的“今日无订单”提示。
- 建议把日期做成明显可点击的日期选择器，零单时收起状态筛选，只保留刷新与历史入口。

## 色彩与字体
- 页头绿色、KPI 蓝/橙/黄/绿、空状态浅灰，颜色层级完整但没有主次，零值卡片反而比空状态更有视觉重量。
- 空状态文字“暂无订单数据”字号较小、对比偏低，插图也接近背景色，用户容易先看到统计数字而没有意识到没有订单。
- 字体层级目前主要靠字号，缺少“空状态标题 + 解释 + 下一步动作”的排版分组。

## 留白与节奏
- 上半部分被 KPI 和筛选密集占据，下半部分从筛选到插图之间出现长距离空白，节奏是“重上轻下”。
- 页头、KPI、筛选、计数条的垂直间距稳定，但在零数据状态下没有随内容缩减，造成空页面仍像满数据页一样重。
- 建议在 0 单时合并筛选和计数条，把空状态上移，并给出“查看全部订单”或刷新日期动作。

## 动效与交互反馈
- 静态截图只能确认首帧，无法验证日期切换、筛选、刷新和空状态过渡。
- 建议：日期切换后 KPI 数字和列表用 220–280ms 淡出/更新；刷新按钮在请求期间旋转；空状态从筛选区下方以 180–220ms 淡入，不改变页面高度时避免布局跳动。
- 0 单时筛选 chip 应有明确 disabled 状态和原因，不要只把数字变成 0。

## 与相邻页的一致性
- 本页与“全部订单”共享标题条、KPI 和筛选模板，这是优点；但两页的第五张 KPI 都失衡，应一起修正。
- 订单状态色与 02 基本一致，仍需和订单详情页统一“已完成”的颜色。
- 空状态插图与其他页面的空状态风格相近，但位置、卡片承载和文案层级没有统一规范。

## 改造建议
- P0 必改：0 单时收起无效筛选，把“今日无订单”上移并给出明确下一步；修复 KPI 4+1 的失衡。
- P1 建议：把日期改为可识别的日期选择器，统一空状态组件和状态色。
- P2 可选：加入日期切换/KPI 更新过渡和刷新旋转反馈。
