# 地址管理（user/26-address）

- 截图：output/web-screenshots/user/26-address.png
- URL：/user/home/address
- 评审人：review-user

## 这页在讲什么

页面用于查看、选择和编辑收货地址，并通过默认标记区分主要地址。

## 主角 / 主动作

主角是地址卡，主动作是选择或编辑地址；右侧标题“管理地址”和左侧返回同时出现，首屏的首/末方向混乱。

## 层级与构图

- 返回按钮和页面标题分居左右，标题没有和左侧导航形成统一的页头规则。
- 两列地址卡并列，但首卡绿色边框、其余蓝色边框，默认态和普通态表达不一致。
- 演示地址重复出现，卡片内容难以分辨真实状态和示例数据。

## 色彩与字体

- 绿色和蓝色边框用于表达状态，却没有统一图例或标签；和全站橙色主色关系弱。
- 地址、收件人和电话字号接近，默认地址标识又只是边框，不够显眼。

## 留白与节奏

- 每张地址卡内部留白偏大，重复内容却较多。
- 页面上方标题与卡片区域之间缺少明显的操作工具栏，编辑入口分散在卡片内。

## 动效与交互反馈

- 静态截图无法验证动效；新增、编辑、设为默认和删除后需要原地更新并给出确认。
- 默认地址切换应明确提示不会影响其他地址。

## 与相邻页的一致性

- 与订单确认页相比，地址格式、默认标记和手机号脱敏规则不一致。
- 与支付密码设置相比，表单和操作页的返回路径没有统一。

## 改造建议

- P0 必改：移除重复标题或统一到左侧页头；用明确的“默认”标签替代绿色/蓝色边框，并统一普通地址的卡片样式。
- P1 建议：清理重复演示数据，压缩卡片高度；把新增地址和编辑操作集中到同一工具栏。
- P2 可选：为新增、设为默认、删除和校验失败增加反馈。
