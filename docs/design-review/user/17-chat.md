# 消息中心（user/17-chat）

- 截图：output/web-screenshots/user/17-chat.png
- URL：/user/home/chat
- 评审人：review-user

## 这页在讲什么

页面用左侧会话列表和右侧聊天区承载用户与商家、联系人的沟通。

## 主角 / 主动作

主角是聊天内容，主动作是在右侧输入并发送消息；左侧列表、空白会话区和浮动购物车分散了注意力。

## 层级与构图

- 左侧会话列表和右侧聊天区的分栏明确，但当前会话没有内容，右区形成大面积空白。
- 多处头像加载失败，会话条目只能靠文字辨认。
- 浮动购物车压在聊天区域，遮挡输入或消息的可能性很高。

## 色彩与字体

- 聊天输入区禁用态对比度过低，用户看不清输入框和发送按钮的可用性。
- 头像回退、消息气泡和系统提示缺少统一色阶，蓝灰与橙色主题混杂。

## 留白与节奏

- 右区空状态没有说明如何开始对话，空白面积远大于左侧列表。
- 列表条目之间的间距偏紧，输入区与消息区缺少安全分隔。

## 动效与交互反馈

- 静态截图无法验证动效；发送中、发送成功、失败重试和对方正在输入都需要可见状态。
- 新消息到达时应提示但不强制抢占滚动位置。

## 与相邻页的一致性

- 与通讯录相比，头像和选中态没有复用统一规则。
- 与消息中心相比，会话入口、未读计数和通知类型没有统一。

## 改造建议

- P0 必改：移除聊天页上的浮动购物车；为无会话状态提供开始聊天入口，并补充头像失败回退和输入区可读性。
- P1 建议：统一会话列表的未读、时间、最后一条消息结构；把聊天输入固定在右栏底部并保持安全边距。
- P2 可选：为发送状态、失败重试、新消息提示和输入中状态增加动效。
