# 制作教程与指南（user/30-tutorials）

- 截图：output/web-screenshots/user/30-tutorials.png
- URL：/user/home/tutorials
- 评审人：review-user

## 这页在讲什么

页面用教程统计、搜索筛选和三列教程卡帮助用户浏览可学习的美食教程。

## 主角 / 主动作

主角是教程卡，主动作是打开教程；顶部五张统计卡和每张卡的多枚标签分散了浏览路径。

## 层级与构图

- hero 右侧同时出现返回、我的教程、发布教程三个按钮，页面入口多于当前浏览任务。
- 五张统计卡横跨首屏，数字 10/0/0/0/10 不构成下一步行动。
- 教程卡内同时出现视频/图文、AI/审核、难度、评分、时长和浏览数，标签数量过多。

## 色彩与字体

- 粉色、橙色、绿色、黄色标签与暖棕 hero 各占一块，缺少统一的标签语义。
- 教程标题字号偏小，评分药丸使用高饱和黄色，注意力落在评分而不是内容标题。

## 留白与节奏

- hero、统计卡、筛选栏连续堆叠，首张教程卡被推到页面约一半位置。
- 卡片正文区高度统一，但标签行和标题行之间的空白不一致。

## 动效与交互反馈

- 静态截图无法验证动效；筛选、打开教程、发布教程和收藏需要不同层级的反馈。
- 卡片悬停应只强化可点击区域，不应同时放大多个标签。

## 与相邻页的一致性

- 与教程详情相比，列表页的标签、评分、时长格式没有直接继承。
- 与我的教程相比，同样是教程卡，状态色和操作完全不同。

## 改造建议

- P0 必改：把统计卡收缩为一条摘要或移出首屏，让教程卡成为首屏主角；删减卡片标签，只保留类型、难度和一项评分。
- P1 建议：统一 hero 的操作按钮层级，筛选栏与卡片区的分组更清楚；降低黄色评分的饱和度。
- P2 可选：为筛选、打开教程和发布入口增加轻量反馈。
