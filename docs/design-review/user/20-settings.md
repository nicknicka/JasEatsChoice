# 设置（user/20-settings）

- 截图：output/web-screenshots/user/20-settings.png
- URL：/user/home/settings
- 评审人：review-user

## 这页在讲什么

页面把用户资料、显示、通知和隐私偏好收拢到一张宽白卡中。

## 主角 / 主动作

主角是设置项列表，主动作是修改某一项偏好；当前用户资料、显示、通知、隐私之间没有清晰的主次，整卡过宽导致操作集中在左侧。

## 层级与构图

- 单张白卡从内容区左侧延伸到右侧，表单控件和开关都贴左排列，右侧留下大块空区。
- 用户资料、显示设置、通知开关和隐私操作连续分段，但各段首尾没有明显的分隔线或标题节奏。
- emoji 作为 section 图标，尺寸和语义层级与页面字体不一致。

## 色彩与字体

- 橙色用户资料区和系统蓝开关同时存在，开关的蓝与页面主色分裂。
- 段落标题、说明和控件文字字号过于接近，设置项之间缺少扫描锚点。

## 留白与节奏

- 宽卡内左右留白不平衡，左列信息密度高、右列空白大。
- 各设置段之间的垂直距离相近，但没有卡片或标题造成的呼吸点。

## 动效与交互反馈

- 静态截图无法验证动效；开关切换、保存和失败回滚需要即时状态反馈。
- 危险操作与普通设置需要使用不同的确认层级。

## 与相邻页的一致性

- 与个人中心相比，用户资料区没有复用同一套头像、昵称和状态组件。
- 与钱包安全页相比，通知、隐私和安全等级的组件规范不统一。

## 改造建议

- P0 必改：把设置卡限制到可读宽度，按“账号、显示、通知、隐私、安全”拆分独立分组；统一开关和按钮的主色。
- P1 建议：删除 emoji section 图标，改用统一的线性图标或纯标题层级；为每段增加说明和分隔。
- P2 可选：为开关、保存、失败回滚和危险操作增加反馈。
