# 系统通知（user/16-system-notification）

- 截图：output/web-screenshots/user/16-system-notification.png
- URL：/user/home/system-notification
- 评审人：review-user

## 这页在讲什么

页面集中展示系统通知，让用户读取平台公告并管理通知状态。

## 主角 / 主动作

主角是系统通知列表，主动作是阅读并标记已读；当前页面与消息中心高度重复，标题说明和灰色 tab 没有提供额外价值。

## 层级与构图

- 标题和说明占据一整个白色头部，随后又出现灰色 tab，列表首屏被连续工具占据。
- 系统通知和普通消息的卡片、图标、删除动作高度重复，用户无法感知这是另一个渠道。
- 通知内容只有标题和摘要，缺少时间分组或优先级。

## 色彩与字体

- 灰色 tab 与页面暖色主色相比明显偏弱，选中态也不清晰。
- 标题、摘要和操作图标没有明确字号阶梯，删除图标抢眼但不表达业务状态。

## 留白与节奏

- 头部说明区留白偏大，列表内容密度却很高。
- 同一天的通知没有分组，时间线缺少节奏。

## 动效与交互反馈

- 静态截图无法验证动效；标记已读、删除和批量清理需要实时状态反馈。
- 通知更新时不应造成列表内容和滚动位置跳动。

## 与相邻页的一致性

- 与消息中心共用相似的 tab 和卡片结构，但命名和操作没有统一定义。
- 与应用内聊天的通知入口没有可见的关联路径。

## 改造建议

- P0 必改：把系统通知并回统一消息框架，或明确只保留“平台公告”一类内容；删除重复的灰色 tab。
- P1 建议：为通知增加日期分组、未读标记和清晰的主操作；压缩标题说明区。
- P2 可选：为已读、删除、批量操作增加过渡、撤销和空状态。
