# 联系客服（user/27-contact）

- 截图：output/web-screenshots/user/27-contact.png
- URL：/user/home/contact
- 评审人：review-user

## 这页在讲什么

页面把联系方式与在线反馈合并到一张白卡中，让用户选择客服渠道并提交问题。

## 主角 / 主动作

主角是在线反馈表单，主动作是提交问题；联系方式、表单和说明没有分段，蓝色主按钮和 emoji 标题让操作入口不够稳定。

## 层级与构图

- 单张白卡同时承载联系方式和在线反馈，两个模块只靠文字标题分隔。
- “在线反馈”标题使用 emoji，和全站图标体系不一致。
- 表单主按钮使用蓝色，与暖橙 accent 冲突，且页面信息密度低、留白无节奏。

## 色彩与字体

- 蓝色按钮、emoji 标题和橙色页面主色混合，缺少统一的客服强调色。
- 联系方式和表单标签字号接近，用户可能忽略必填项与错误提示。

## 留白与节奏

- 白卡内部上半部较松，表单区域又缺少明确的输入间距。
- 页面信息很少但垂直留白过大，滚动时没有形成段落感。

## 动效与交互反馈

- 静态截图无法验证动效；提交状态、校验错误和客服联系方式复制都需要即时反馈。
- 表单按钮应有 loading 和防重复提交状态。

## 与相邻页的一致性

- 与设置页相比，表单控件、标题和卡片宽度没有复用。
- 与订单相关页面相比，客服入口没有形成统一的帮助链接位置。

## 改造建议

- P0 必改：把页面拆为“选择联系方式”和“提交反馈”两个明确区块，主按钮统一为页面主色并固定在表单末尾。
- P1 建议：移除 emoji 作为标题图标；统一输入框、标签和错误提示的间距与字号。
- P2 可选：为复制联系方式、提交反馈、校验和成功结果增加轻量反馈。
