## 这页在讲什么

页面用收藏统计、搜索筛选和多类型卡片管理用户收藏的菜品、商家与文章。

## 主角 / 主动作

主角是收藏卡片，主动作是查看详情；当前卡片的橙色、灰色、绿色缩略图和蓝色按钮没有统一内容语义，删除和清空操作又抢眼。

## 层级与构图

- 标题栏同时出现返回、收藏总数和刷新按钮，筛选栏又包含搜索、类型、排序、重置和清空全部，工具密度过高。
- 三列卡片高度不一致，中间卡被抬高，卡片起点和操作按钮无法对齐。
- 缩略图分别是大色块、灰色“点击查看”和绿色图标，不能稳定表达收藏类型。

## 色彩与字体

- 橙色、灰绿色缩略图与蓝色详情按钮形成多套强调，和全站暖橙主色不一致。
- “文章 2022500857018429442”和“test”直接显示原始数据，标题层级被无意义文本占满。

## 留白与节奏

- 卡片之间横向间距正常，纵向高度差导致网格错位。
- 卡片内部图片、正文、时间和按钮之间留白不均，信息碎片感明显。

## 动效与交互反馈

- 静态截图无法验证动效；取消收藏、清空和重新收藏都应有撤销入口。
- 清空全部需要二次确认，并说明是否可恢复。

## 与相邻页的一致性

- 与“想吃列表”都是卡片收藏场景，但卡片高度、按钮和状态标签完全不同。
- 与“我的食谱”“教程广场”的卡片字段没有形成统一收藏模型。

## 改造建议

- P0 必改：统一收藏卡的高度、图片比例和详情按钮颜色；清理测试文本和原始长 ID，按菜品、商家、文章分别定义摘要字段。
- P1 建议：压缩筛选工具栏，把删除和清空降为次级/危险操作；统一卡片类型标签与状态色。
- P2 可选：为取消收藏、清空和空状态切换加入过渡与撤销。
