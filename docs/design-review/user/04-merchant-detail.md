## 这页在讲什么

页面以商家身份、分类和菜单为主，目标是让用户选菜并进入购物车。

## 主角 / 主动作

主角是菜品列表，主动作是加入购物车；顶部商家图标和右下浮动购物车都在抢视线，且购物车会遮住内容。

## 层级与构图

- 顶部蓝色商家图标与全站橙色强调色冲突，用户会把它误认为独立功能入口。
- 分类标签图标残缺，菜品图片全部是灰色占位，无法判断菜品差异。
- 浮动购物车贴在右下角，压在菜品内容上，没有独立安全边距。

## 色彩与字体

- 蓝色商家图标、橙色分类标签和灰色图片同时出现，缺少统一的商家详情色彩层级。
- 菜品名称和价格的对比度尚可，但分类标签的文字太小，状态色也没有说明。

## 留白与节奏

- 菜单条目之间的间距较均匀，分类栏与菜品区之间缺少清晰的分组留白。
- 图片占位块高度过大，导致单道菜占据过多垂直空间。

## 动效与交互反馈

- 静态截图无法验证动效；加入购物车后需要显示数量、动画和短暂确认，不能让用户猜是否成功。
- 分类切换应保留当前滚动位置，并给出选中态。

## 与相邻页的一致性

- 与商家查找卡相比，这里没有复用商家头像、评分和营业状态。
- 与订单确认相比，菜品行项目缺少统一的价格、数量和备注结构。

## 改造建议

- P0 必改：修复菜品图片和分类图标；把浮动购物车移出内容热区，或在底部建立固定购物车栏，避免遮挡菜单。
- P1 建议：将商家顶部区域改为中性背景，统一橙色强调和灰色辅助层级；压缩菜品图片高度并统一行项目网格。
- P2 可选：为加入购物车、分类切换和数量变化添加轻量反馈。
