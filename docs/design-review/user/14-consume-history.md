# 消费记录（user/14-consume-history）

- 截图：output/web-screenshots/user/14-consume-history.png
- URL：/user/home/consume-history
- 评审人：review-user

## 这页在讲什么

页面用统计摘要、筛选栏和交易列表展示账户消费流水。

## 主角 / 主动作

主角是交易列表，主动作是查找某笔消费；三张 emoji 统计卡和红绿蓝金额颜色增加了噪音。

## 层级与构图

- 三张 emoji 统计卡位于筛选之前，但统计周期和口径不清楚。
- 交易列表和统计卡使用不同信息结构，用户需要重新学习字段。
- 金额同时使用红、绿、蓝，没有统一的收入/支出/退款语义。

## 色彩与字体

- emoji 与表单控件、表格字体混用，视觉体系像多个组件拼在一起。
- 数字是关键信息，但颜色承担了过多含义，缺少图标或文字辅助。

## 留白与节奏

- 页面顶部统计区密度高，交易列表行距偏紧。
- 列表末端的空白没有分组或分页提示，滚动结束感不足。

## 动效与交互反馈

- 静态截图无法验证动效；筛选变化、分页和详情打开应有加载与回到顶部反馈。
- 金额正负变化需要在数值本身而非仅靠颜色表达。

## 与相邻页的一致性

- 与“钱包交易记录”展示同类数据，却使用不同的卡片、图标和统计布局。
- 与“我的订单”相比，筛选控件和列表行样式也没有统一。

## 改造建议

- P0 必改：把收入、支出、退款统一为一套带符号和文字含义的交易行；金额颜色只保留一种主语义，不靠红绿蓝同时编码。
- P1 建议：替换 emoji 统计图标，统一统计卡和交易列表的字号、间距、筛选控件。
- P2 可选：为筛选、分页和交易详情打开增加反馈。
