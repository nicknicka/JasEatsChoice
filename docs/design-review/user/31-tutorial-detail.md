## 这页在讲什么

页面用媒体封面、审核标签、标题和正文展示一篇已通过审核的教程。

## 主角 / 主动作

主角是教程正文和媒体内容，主动作是播放视频或继续阅读；当前大块渐变媒体没有任何播放/封面信息，页面视觉重心落在一个空壳上。

## 层级与构图

- 返回按钮独立悬在左上方，媒体卡与页面主体没有形成统一的文章容器。
- 媒体区从橙色渐变到蓝色，占首屏最大面积，但没有任何图片、视频标题或播放按钮。
- 标题、元信息和“内容”之间的层级清晰，但正文首屏只露出开头，阅读路径被大媒体压后。

## 色彩与字体

- 橙蓝渐变、绿色审核标签和红色分隔线同时出现，和暖橙教程设定不一致。
- 标题字重明显，元信息使用灰色弱化，但红色横线抢走了“内容”标题的层级。

## 留白与节奏

- 媒体卡下方到标签之间距离偏小，标签到标题又突然拉开。
- 正文下方留白很大，首屏信息密度不均衡。

## 动效与交互反馈

- 静态截图无法验证动效；视频播放、加载失败和正文目录切换都需要反馈。
- 媒体加载应先占位再淡入，不能让空渐变替代加载状态。

## 与相邻页的一致性

- 与教程广场相比，卡片中的类型、评分、作者字段没有在详情页保持同一位置。
- 与我的教程相比，审核和难度标签的颜色语义不一致。

## 改造建议

- P0 必改：为媒体区提供真实封面/视频播放器或明确空状态；让正文标题成为首屏第二个视觉锚点。
- P1 建议：去掉抢眼的红色分隔线，统一标签和正文标题的层级；调整媒体与标题的距离。
- P2 可选：为媒体加载、播放和正文目录切换增加过渡。
