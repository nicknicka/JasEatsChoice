## 这页在讲什么

页面用余额 banner、筛选栏、三指标卡和交易列表展示钱包资金变化。

## 主角 / 主动作

主角是交易列表，主动作是核对一笔资金变化；余额 banner、筛选、三张指标卡连续堆叠，列表被推到首屏之后。

## 层级与构图

- 余额 banner、筛选栏、三指标卡和交易列表形成四层结构，入口层级过多。
- 交易图标与消费记录重复但布局和统计卡不同，两个页面无法互换理解。
- 金额颜色仍使用红、绿、蓝多种编码，缺少收入/支出/退款的图文说明。

## 色彩与字体

- 余额 banner 与三指标卡使用相近的白色/橙色层级，数字的权重大于交易正文。
- 交易状态与金额没有固定字号关系，用户需要逐行寻找变化。

## 留白与节奏

- 顶部四层信息占据大量垂直空间，交易列表行距偏紧。
- 指标卡横排间距统一，但与筛选栏之间的分组不明确。

## 动效与交互反馈

- 静态截图无法验证动效；筛选、分页和交易详情打开都需要加载与位置保持。
- 金额变化应通过符号和文字辅助，不只靠颜色。

## 与相邻页的一致性

- 与消费记录是同一数据的不同呈现，但统计卡、图标和筛选规则没有统一。
- 与钱包管理页相比，余额的格式和快捷入口不一致。

## 改造建议

- P0 必改：把顶部四层收敛为“余额摘要 + 一个筛选工具栏”，交易列表提前进入首屏；统一收入/支出/退款的行项目结构。
- P1 建议：让金额颜色只承担一种主语义，其他状态使用标签或图标；统一与消费记录的数字格式。
- P2 可选：为筛选、分页、详情打开和余额刷新增加反馈。
