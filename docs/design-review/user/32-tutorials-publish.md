## 这页在讲什么

页面用快速模板、基本信息、详细信息和右侧预览完成教程发布前的编辑。

## 主角 / 主动作

主角是发布表单，主动作是发布教程；当前首屏只有取消按钮，没有可见的保存或发布主操作。

## 层级与构图

- 橙色到蓝色的 hero 很高，右侧只有蓝色“取消”按钮，用户看不到如何完成发布。
- 左侧表单和右侧预览形成两列，但预览卡中的标题、难度和内容框层级都比表单更抢眼。
- 基本信息中的标签、输入框、按钮和预览没有统一对齐线，选项行宽度不一致。

## 色彩与字体

- 蓝色选中 tab、绿色难度、橙蓝渐变 hero 和粉色模板图标同时出现，强调色过多。
- 表单标签和预览文字字号接近，错误提示与必填项没有形成单独的视觉规则。

## 留白与节奏

- 左侧表单和右侧预览的顶部没有对齐，右栏卡高度过长。
- 首屏内容被 hero 占据较多，表单需要滚动才能看到完整字段。

## 动效与交互反馈

- 静态截图无法验证动效；自动保存、字段校验、图片上传和发布失败都需要状态反馈。
- 右侧预览应随输入实时更新，不能静态复制表单内容。

## 与相邻页的一致性

- 与教程详情相比，预览字段和最终详情排版不一致。
- 与教程广场相比，类型、难度、来源的标签颜色没有统一。

## 改造建议

- P0 必改：在页头或底部固定“保存草稿/发布教程”主操作，并显示当前完成度；删除只保留取消的空白首屏。
- P1 建议：统一表单控件宽度、标签位置和左右栏对齐；让预览复用教程详情的真实排版。
- P2 可选：为自动保存、实时预览、校验和发布结果增加反馈。
