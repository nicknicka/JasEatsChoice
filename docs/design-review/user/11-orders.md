# 我的订单（user/11-orders）

- 截图：output/web-screenshots/user/11-orders.png
- URL：/user/home/orders
- 评审人：review-user

## 这页在讲什么

页面用搜索、状态筛选和订单卡帮助用户找到并处理历史订单。

## 主角 / 主动作

主角是订单卡，主动作是查看详情或继续支付；蓝色筛选胶囊和通用商品图标把视觉注意力从订单状态和操作上移开。

## 层级与构图

- 返回/刷新、宽搜索框和蓝色筛选胶囊连续堆叠，订单卡被推到首屏下半部。
- 商品缩略图统一使用通用图片图标，无法识别买了什么。
- 蓝色边框与橙色主色分裂，订单状态和下一步操作不突出。

## 色彩与字体

- 筛选选中态使用高饱和蓝色，订单金额、状态和按钮却没有同等明确的语义色。
- 订单号、商家名和商品名使用相近字重，卡片缺少扫描顺序。

## 留白与节奏

- 工具区占高偏大，订单卡之间间距正常但内容内部较拥挤。
- 空图片区没有占位说明，长列表会反复出现同一种灰色块。

## 动效与交互反馈

- 静态截图无法验证动效；筛选切换和刷新应显示加载状态，支付/取消后卡片状态要原地更新。
- 订单卡可点击区域需要覆盖整卡，不能只依赖文字链接。

## 与相邻页的一致性

- 与订单详情相比，列表中的状态、金额和操作按钮没有统一顺序。
- 与“商家查找”相比，蓝色筛选和棕色按钮各自成体系，缺少共享控件规则。

## 改造建议

- P0 必改：统一订单卡字段：商家、商品摘要、订单号、状态、金额、主操作；修复商品缩略图，并把蓝色筛选改为与页面主色一致的状态筛选。
- P1 建议：压缩搜索和筛选区，增加订单数量或当前筛选摘要；让状态色只承担状态语义。
- P2 可选：为刷新、筛选、支付和取消加入加载与结果反馈。
