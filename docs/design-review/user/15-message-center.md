# 消息中心（user/15-message-center）

- 截图：output/web-screenshots/user/15-message-center.png
- URL：/user/home/message-center
- 评审人：review-user

## 这页在讲什么

页面用分类标签和消息卡片集中展示优惠、订单、互动和系统信息。

## 主角 / 主动作

主角是消息列表，主动作是打开或处理一条消息；所有消息都标成“优惠活动”，分类标签本身失效。

## 层级与构图

- 四个 tab 与消息卡并列，但卡片标签全部是“优惠活动”，实际内容却是订单状态更新。
- 每张消息卡的结构完全相同，未读状态、消息类型和处理动作无法靠视觉区分。
- 时间显示为 `2026-05-21T16:44:02`，没有本地化。

## 色彩与字体

- 分类标签颜色重复，未读消息没有独立强调。
- 正文、标题和时间字号接近，列表的扫描点落在标签而不是消息内容。

## 留白与节奏

- 卡片之间的间距均匀，但 tab 区和列表区没有明显分组。
- 消息正文长度不一，卡片高度变化大，列表节奏不稳定。

## 动效与交互反馈

- 静态截图无法验证动效；打开消息后应立刻切换未读态，删除/已读操作要有撤销入口。
- 新消息到达时的排序变化不应造成列表跳动。

## 与相邻页的一致性

- 与系统通知相比，两者的 tab、卡片和操作高度重复，差异只在数据范围。
- 与聊天页相比，消息类型和入口没有形成统一的“消息→会话/系统页”路径。

## 改造建议

- P0 必改：修正消息类型与标签映射，按订单、优惠、互动、系统分别使用不同字段和动作；时间统一格式化为本地时间。
- P1 建议：增加未读标记、消息摘要长度规则和空状态；区分 tab 区与列表区的背景层级。
- P2 可选：为已读、删除和新消息排序加入轻量反馈与撤销。
