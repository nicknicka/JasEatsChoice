# 通讯录（user/18-contacts）

- 截图：output/web-screenshots/user/18-contacts.png
- URL：/user/home/contacts
- 评审人：review-user

## 这页在讲什么

页面用通讯录头图、联系人列表和选中操作帮助用户发起聊天或群发消息。

## 主角 / 主动作

主角是联系人列表，主动作是选择联系人后发起消息；蓝色头像、选中行和过小的群发图标让操作路径不清晰。

## 层级与构图

- 头部橙色渐变区域面积很大，但只承载标题和说明，联系人列表被压到下方。
- 表头只显示 `#`，用户无法理解列的含义。
- 蓝色头像和蓝色选中行与暖橙主色冲突，群发图标点击目标过小。

## 色彩与字体

- 橙色头图、蓝色选中态和灰色文字形成多个强调层级。
- 联系人姓名与身份信息字号接近，选中行只靠整行底色区分。

## 留白与节奏

- 头图和表格之间的留白过大，列表行高偏紧，页面上下密度不均。
- 群发操作贴在表格右上角，与选择结果没有视觉关联。

## 动效与交互反馈

- 静态截图无法验证动效；勾选联系人后应显示已选数量和群发按钮状态。
- 选择、取消选择和发送完成需要即时反馈。

## 与相邻页的一致性

- 与聊天页相比，头像和会话入口没有使用同一套尺寸与状态。
- 与消息中心相比，通讯录的未读、在线状态和联系方式没有统一表达。

## 改造建议

- P0 必改：把表头改为明确的联系人字段；修复头像回退，把群发操作做成与选择状态绑定的工具栏。
- P1 建议：降低头图高度，统一选中态的暖色强调；调整行高和点击区域。
- P2 可选：为选择、群发和进入会话增加轻量动效与结果反馈。
