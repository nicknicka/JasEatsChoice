## 这页在讲什么

页面用统计卡、状态 tabs 和教程卡管理用户已发布、待审核、草稿和拒绝的教程。

## 主角 / 主动作

主角是教程状态列表，主动作是继续编辑或查看审核结果；五张统计卡和 tabs 重复表达同一组状态。

## 层级与构图

- 顶部五张统计卡与下方五枚状态 tabs 重复展示全部/草稿/待审核/已发布/已拒绝。
- 其中一张卡图片加载失败，直接显示 alt 文本“健康饮食心得”，破坏网格。
- 卡片使用文档/视频图标和状态标签，但同一行状态色黄色、绿色、红色缺少顺序规则。

## 色彩与字体

- 棕橙 hero 与蓝色渐变叠在一起，统计卡又加入绿勾、红叉和黄秒表，色彩数量过多。
- 教程标题、状态标签和时长字号接近，卡片第一扫描点不稳定。

## 留白与节奏

- 统计卡和 tabs 之间距离偏紧，tabs 到卡片网格之间的距离偏大。
- 卡片封面高度统一，但一张失败图造成明显空洞。

## 动效与交互反馈

- 静态截图无法验证动效；发布、撤回、编辑和审核状态变化需要原地更新。
- 失败图片或待审核状态需要明确的处理入口，而不是只显示静态标签。

## 与相邻页的一致性

- 与教程广场相比，卡片缺少评分和类型，新增了状态但却没有复用同一套字段。
- 与发布教程相比，草稿、审核和发布状态的颜色语义没有统一。

## 改造建议

- P0 必改：删除重复的统计卡或 tabs，只保留状态筛选；修复失败封面并提供统一的空封面样式。
- P1 建议：统一状态色与状态文字，把待审核和拒绝处理动作放到卡片主操作。
- P2 可选：为状态切换、重新提交和发布结果增加过渡。
