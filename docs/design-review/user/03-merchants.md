# 商家查找（user/03-merchants）

- 截图：output/web-screenshots/user/03-merchants.png
- URL：/user/home/merchants
- 评审人：review-user

## 这页在讲什么

页面用搜索筛选、商家头像和三列商家卡完成“找一家能下单的店”的任务。

## 主角 / 主动作

主角是商家卡，主动作是进入商家详情；搜索筛选是工具，不应和三列卡片争夺同一层级。

## 层级与构图

- 搜索与筛选控件横向铺满，占用高度接近一整张商家卡，列表首屏被压缩。
- 商家头像使用固定棕色背景，缺少真实品牌识别；卡内大块灰色图片区看起来像加载失败。
- 每张卡底部都放全宽棕色按钮，按钮重复度高，反而掩盖了商家名称和状态。

## 色彩与字体

- 棕色按钮和暖橙页面主色接近但没有统一层级，灰色图片区又像占位组件。
- 商家名称、评分、距离和按钮没有明确的字号阶梯，用户先看到按钮而不是商家。

## 留白与节奏

- 三列卡片的网格间距均匀，但图片区和文字区之间的空白过大。
- 搜索区与卡片网格之间只靠一段背景分隔，页面节奏从紧凑突然变松。

## 动效与交互反馈

- 搜索/筛选变化时缺少结果数量和加载状态；卡片悬停应只强化可点击区域，不应整体变色。
- 进入商家详情前，卡片需要保留最后一次浏览位置的反馈。

## 与相邻页的一致性

- 与商家详情相比，列表卡的颜色、头像和图片比例都没有直接继承。
- 与首页推荐卡相比，这里多了按钮却少了最重要的菜品/距离信息。

## 改造建议

- P0 必改：修复商家图片和头像的加载失败态；把商家名称、评分、距离、营业状态提到按钮之前，并统一卡片主按钮的颜色和尺寸。
- P1 建议：压缩搜索筛选高度，增加结果数量或筛选摘要；统一图片裁切和头像回退样式。
- P2 可选：为筛选变化、加载和进入商家详情增加轻量反馈。
