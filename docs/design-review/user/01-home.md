## 这页在讲什么

首页把天气问候、推荐菜品和今日热点入口聚合为“今天吃什么”的决策起点。

## 主角 / 主动作

主角应是推荐菜品，主动作是点开某道菜继续选餐；天气卡、标题区和底部热点条都在争夺首屏注意力。

## 层级与构图

- 四张推荐卡使用同一套菜品插画和同一种构图，用户第一眼无法靠图区分内容。
- 右上天气卡与主标题区并排，视觉重量接近，导致首屏没有明确入口。
- 底部整宽红色热点条比推荐卡更醒目，抢走主内容的收尾注意力。

## 色彩与字体

- 页面以暖橙和浅米色为主，但热点条使用高饱和红色，和推荐区的棕橙层级脱节。
- 菜名、热量、价格没有形成固定字号顺序，卡片之间只能靠文字长度区分。

## 留白与节奏

- 推荐区卡片间距稳定，但标题区与推荐区之间缺少统一的分组间距。
- 页面底部被红色热点条截断，留白节奏突然变紧。

## 动效与交互反馈

- 静态截图无法验证动效；推荐卡至少需要悬停抬升、收藏状态反馈和点击后的进入反馈。
- 热点条滚动或切换时应有可暂停、可点击的状态，不能只做装饰性跑马灯。

## 与相邻页的一致性

- 与“我的推荐”“商家查找”相比，卡片缺少商家、价格、状态等统一字段。
- 顶部搜索框、左侧导航和用户信息保持一致，但主内容区的卡片规范没有延续。

## 改造建议

- P0 必改：统一推荐卡的信息骨架：图片、菜名、商家、价格/热量、收藏状态；热点条改为与卡片同一套暖色 token，不再用全宽红条压过主内容。
- P1 建议：把天气卡降级为紧凑辅助信息，保证同一屏内推荐菜品是最大的一组视觉对象；统一卡片高度和图片裁切比例。
- P2 可选：为推荐卡增加悬停和键盘焦点态，并让热点条具备明确的打开反馈。
