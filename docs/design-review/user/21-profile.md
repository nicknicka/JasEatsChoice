# 用户中心（user/21-profile）

- 截图：output/web-screenshots/user/21-profile.png
- URL：/user/home/profile
- 评审人：review-user

## 这页在讲什么

页面以个人资料头部、指标卡和订单/钱包快捷入口汇聚用户资产与账户操作。

## 主角 / 主动作

主角是个人资料和账户快捷入口，主动作是进入订单、钱包或设置；下方多组浅色卡片争夺入口顺序。

## 层级与构图

- 暖色个人资料 hero 承担头像、昵称和操作按钮，是页面最强视觉区。
- 资料 pills、指标卡、订单/钱包模块逐层向下，模块之间缺少明确的任务排序。
- 浅蓝、浅绿、浅黄卡片并列，颜色没有对应业务语义。

## 色彩与字体

- 个人 hero 的暖橙和下方多彩卡片没有统一 token，用户无法通过颜色判断模块类型。
- 指标数字和模块标题字重接近，资产信息没有被突出。

## 留白与节奏

- hero 内部留白较松，下方卡片间距较紧，页面上下节奏不一致。
- 快捷入口的卡片高度和内容密度不统一，滚动时视觉断裂。

## 动效与交互反馈

- 静态截图无法验证动效；头像编辑、余额变化和模块进入都需要轻量反馈。
- 敏感账户操作应有二次确认或独立安全入口。

## 与相邻页的一致性

- 与设置页相比，个人资料区重复展示但在两页使用不同布局。
- 与钱包管理页相比，余额、充值和提现入口的字段与颜色没有统一。

## 改造建议

- P0 必改：统一个人中心快捷入口的顺序和颜色语义：订单、钱包、饮食记录、设置分别使用固定位置和同一套中性卡面。
- P1 建议：把指标卡合并成一条资产/行为摘要；让 hero 的主动作只保留编辑资料或设置入口。
- P2 可选：为头像编辑、模块进入和余额变化补充过渡。
