# 钱包安全设置（user/25-wallet-security）

- URL：/user/home/wallet-security

## 这页在讲什么

页面用安全等级、密码管理和交易设置帮助用户查看并调整钱包安全状态。

## 主角 / 主动作

主角是安全等级和当前风险项，主动作是修复或修改安全设置；蓝色链接和设置按钮与橙色安全等级 banner 分裂。

## 层级与构图

- 顶部橙色安全等级 banner 是强视觉区，下方“密码管理、钱包状态、交易设置”三组信息按列表排列。
- 安全等级的数值、等级文字和对应行动之间没有直接关联，用户不知道下一步先改哪项。
- 各组设置有链接、状态文本和按钮混排，行尾操作不统一。

## 色彩与字体

- 橙色安全等级、蓝色链接、蓝色设置按钮同时出现，颜色没有对应风险等级。
- 安全状态文字和辅助说明的字号过于接近，风险项不够醒目。

## 留白与节奏

- banner 下方三组内容间距均匀，但每组的状态与操作距离偏大。
- 页面底部留白较多，设置项不足时缺乏分组收束。

## 动效与交互反馈

- 静态截图无法验证动效；安全等级变化、密码修改和开关切换需要即时反馈。
- 高风险操作点击后应有二次确认和明确结果。

## 与相邻页的一致性

- 与支付密码设置相比，密码入口和表单跳转没有统一的步骤语义。
- 与设置页相比，安全项在列表结构、图标和主色上都没有复用。

## 改造建议

- P0 必改：让安全等级 banner 带上“当前最需要处理的风险项”与直达按钮；每项设置统一为“状态 + 一个动作”。
- P1 建议：把蓝色链接/按钮统一为页面主色或明确的风险色；提高风险项的对比度和字号。
- P2 可选：为等级变化、密码修改、开关切换和提交结果增加过渡与确认。
