## 这页在讲什么

页面用营养摘要、筛选操作和空状态提示用户开始添加今日食谱。

## 主角 / 主动作

主角是今日食谱列表或空状态，主动作是添加食谱；“添加食谱”和“从订单导入”权重过近，用户需要先做选择才能继续。

## 层级与构图

- 顶部营养数字条和筛选操作行连续出现，内容入口被压到中部。
- 中央空状态箱放在过大白色卡片里，视觉重心漂在页面中央。
- “添加食谱”和“从订单导入”并排且样式接近，没有说明推荐路径。

## 色彩与字体

- 数字条使用低对比绿色/灰色，主动作没有统一的橙棕色强调。
- 空状态插画、文案和按钮的层级较弱，页面看起来像未完成而不是可操作的空状态。

## 留白与节奏

- 空状态箱四周留白过大，页面中部空旷；顶部操作栏却相对紧凑。
- 营养摘要和筛选行之间没有清楚的分组边界。

## 动效与交互反馈

- 静态截图无法验证动效；从空状态进入添加或导入流程时，应有步骤反馈和返回路径。
- 营养数字更新时应显示变化，而不是保持静态统计。

## 与相邻页的一致性

- 与“我的食谱”相比，食谱条目、状态标签和批量操作没有共用结构。
- 与“饮食记录”相比，空状态的 CTA 风格和信息密度不一致。

## 改造建议

- P0 必改：把“添加食谱”设为主按钮，“从订单导入”降为次级入口；空状态只保留一个下一步和一个返回入口。
- P1 建议：压缩空状态卡高度，增加最近食谱或快捷模板，减少中央空白；统一营养摘要的数字样式。
- P2 可选：为添加、导入和数字更新补充过渡、loading 与成功反馈。
