# 我的推荐（user/02-recommend）

- 截图：output/web-screenshots/user/02-recommend.png
- URL：/user/home/recommend
- 评审人：review-user

## 这页在讲什么

页面用定位提示、推荐列表和进度条把用户导向可预约或可下单的菜品。

## 主角 / 主动作

主角是推荐列表中的菜品，主动作是查看菜品或进入下一步；顶部黄色定位提示和卡片里的百分比进度条权重过高。

## 层级与构图

- 顶部黄色提示条横跨内容区，但只承担定位说明，实际压住了列表起点。
- 缩略图使用高饱和渐变，英文文字被裁切，无法帮助识别菜品。
- 卡片中部留白比信息区更大，导致单卡高度被撑开，列表浏览密度下降。

## 色彩与字体

- 黄色提示、彩色缩略图和暖橙页面背景同时出现，缺少一个稳定的强调色。
- “8%”进度条没有标签，用户无法判断它代表匹配度、完成度还是库存。

## 留白与节奏

- 卡片内部的上下留白不一致，长标题和短标题会造成明显高度差。
- 筛选与列表之间没有独立的分隔节奏，首屏很快进入大块空白。

## 动效与交互反馈

- 静态截图无法验证切换动效；筛选条件变化时应显示加载或结果数量反馈。
- 进度条变化应有数值或文字说明，不能只让色块推进。

## 与相邻页的一致性

- 与首页相比，推荐卡增加了很多彩色元素，但没有沿用首页的卡片字段结构。
- 进入商家详情前的操作入口不明确，用户不知道自己是在看菜品还是看商家。

## 改造建议

- P0 必改：给顶部定位提示降级或吸附到工具栏；重做缩略图裁切规则，禁止裁掉关键文字；把百分比改成“匹配度 8%”或明确删除。
- P1 建议：压缩卡片中部空白，统一标题/描述/操作的垂直距离；让推荐列表使用一套主强调色。
- P2 可选：为筛选结果数量、进度变化和卡片进入状态补充轻量反馈。
