# 充值记录（admin/13-recharges）

- 截图：output/web-screenshots/admin/13-recharges.png
- URL：/admin/finance/recharges
- 评审人：review-admin

## 这页在讲什么
顶部四个充值口径（今日金额/笔数、本月金额/笔数），下方充值明细表回答"谁充了多少、什么渠道、成功没有"。

## 主角 / 主动作
- 主角是充值记录表，主动作是"查看单笔充值详情"。
- 行操作收敛为单个"详情"文字链接，动作最克制、最清晰，是全站列表里最好的处理之一。
- 缺少导出入口，同为财务的 12-提现审核 有导出，能力不对称。

## 层级与构图
- 概览是"纯数字居中"四卡，与 03/05/06/14/21 同源。
- 筛选区折成两行：第一行 关键词/充值方式/状态，第二行 日期范围 + 搜索 + 重置，右侧空。
- 表格"充值时间"列被右侧裁切，值显示为 "2026-05-20T1…"，时间读不全，是明显的列宽/溢出缺陷。

## 色彩与字体
- 充值金额（¥72、¥50…）红色粗体，红色对充值金额语义反向，且为衬线字形。
- 状态标签覆盖 失败（红）/ 成功（绿）/ 待支付（橙）/ 处理中（橙），"待支付"与"处理中"同为橙色，状态区分不足。

## 留白与节奏
- 表格行高约 36px，密度适合财务长表。
- 筛选卡第二行留白偏大。
- 概览—筛选—表格间距一致。

## 动效与交互反馈
- 表格行无 hover 高亮，财务长表横向读易串行。
- 充值状态变化无局部反馈与过渡。
- 无导出时的能力缺口宜在交互上明示。

## 与相邻页的一致性
- 概览卡与 03/05/06/14/21 同源，但与同属财务的 12-提现审核（浅色圆图标卡）不同源，同模块不一致。
- 金额红色、时间戳带 T 与 05/06/12/14 一致，跨页共性。
- "Total 0" 与 10 行数据矛盾，同 04/11。
