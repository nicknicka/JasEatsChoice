# 系统日志（admin/20-logs）

- 截图：output/web-screenshots/admin/20-logs.png
- URL：/admin/settings/logs
- 评审人：review-admin

## 这页在讲什么
筛选条 + 六类操作计数 + 一张日志表，回答"系统里发生过哪些操作、按类型分布如何"。

## 主角 / 主动作
- 主角是日志表，主动作是"按条件筛选后查看日志"。
- 但列表为空，主动作落空；页面上最重的视觉是六张操作统计卡，直接抢走了本应属于列表的注意力。
- 表头"刷新"按钮在标题行右侧，位置正确（不占卡片头部）。

## 层级与构图
- 筛选区是独立卡，头部"筛选条件"右带"收起 ^"，是唯一带折叠的筛选卡。
- 六张统计卡一行排开（总日志/登录/创建/更新/删除/查询），每张约 160px 宽，"图标 + 数字 + 标签"挤在窄卡里，标签小、易读性下降。
- 日志表表头"操作时…"被裁切（应为操作时间之类），右侧"操作"列并列，列宽溢出。
- 空表仍挂分页条（Total 0 / 10/page / 跳页），冗余。

## 色彩与字体
- 六张统计卡用六种实色图标块：紫/绿/蓝/橙/红/深灰，颜色多且饱和，是全站色块最杂的一处。
- "清理日志"红色实心按钮夹在搜索/重置之后，红色在该位置语义正确（危险），但位置紧跟重置易误点。
- 空状态 "No Data" 为英文。

## 留白与节奏
- 六张窄卡一行铺满，卡间距小，视觉拥挤。
- 筛选区行距尚可，字段两到三个一行。
- 表格区因无数据，下方大面积空白。

## 动效与交互反馈
- 统计卡无 hover，"收起/展开"筛选有基础过渡。
- 刷新无 loading 态。
- 空表无引导动效。

## 与相邻页的一致性
- 六卡实色图标块与 10/11/12（浅色圆图标）不同源，也与 01（渐变）、03/05/06（纯数字）、08（渐变填充）不同源，是本项目第六种统计卡形态。
- 英文空状态与 07-菜品审核 一致。
- "Total 0"、列裁切与 11/13 等问题同源。

## 改造建议
- P0 必改：六张统计卡并入全站统一概览卡组件，去掉六色实色图标，或统一为一套同源色。
- P0 必改：修"操作时…"列裁切；空数据时隐藏分页条。
- P0 必改：空状态改中文并给引导。
- P1 建议：把"清理日志"移出搜索/重置行，单独成危险动作区并加二次确认。
- P2 可选：窄屏下统计卡换行显示，避免六卡硬挤一行。
