- 评审人：review-admin

## 这页在讲什么
一页里给出提现待办量、趋势图和提现明细：顶部四个口径、中部趋势折线、底部筛选 + 提现列表。

## 主角 / 主动作
- 主角是底部提现列表（真正要处理的对象），主动作是逐条"通过 / 拒绝"。
- 但首屏高度几乎被概览卡 + 趋势图占满，列表被压到屏幕底部，主动作沉到看不见的位置，主次颠倒。
- 表头"自动刷新/导出"两个次级按钮并列，位置正确。

## 层级与构图
- 概览四卡"浅色圆图标 + 数字"，与 10/11 同源。
- 趋势图区占整幅宽、约三分之一屏高，但当前数据全为 0，折线贴底、右轴笔数范围 0~1，图形区大面积是空的。
- 筛选区：第一行 关键词/状态/提现方式/日期范围/搜索/重置，第二行 金额范围 + 应用。控件密度高，第二行只有一组金额范围，右侧空。
- 表格首行被视口裁切，只能看到一行半。

## 色彩与字体
- 金额（¥0.00、¥203.00、¥15.00）用衬线粗体，与正文不同族；提现金额红色，红色对金额无语义。
- 状态标签 待审核（橙）语义正确。
- 趋势图两轴分别为 绿（提现金额）/ 蓝（提现笔数），双色图例清楚。

## 留白与节奏
- 趋势图与列表之间挤在一起，首屏信息密度头重脚轻：上面空（图形区全空），下面挤（列表被裁）。
- 概览卡到趋势图、趋势图到筛选的间距一致。
- 折线图的空白与列表的拥挤形成强烈反差。

## 动效与交互反馈
- 趋势图无数据时无空态提示，直接画一条贴底的线。
- 自动刷新无开关状态、无上次刷新时间。
- 列表动作 查看/通过/拒绝 无行内结果反馈。

## 与相邻页的一致性
- 概览卡与 10/11 同源，与同属财务的 13-充值记录（纯数字卡）不同源，同一模块内不一致。
- 趋势图式页面与 21-数据统计 同类，但两页图表卡样式（表头分隔线、图例）未统一。
- 金额红色与 05/06/13/14 一致，跨页共性。

- P0 必改：趋势图补空态（"该周期暂无提现"），并修正右轴量纲。
