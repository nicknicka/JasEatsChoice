# 用户管理（admin/02-users）

- 截图：output/web-screenshots/admin/02-users.png
- URL：/admin/users
- 评审人：review-admin

## 这页在讲什么
一张筛选条加一张用户表，回答"平台上有哪些用户、各自什么状态、我该怎么处理"。

## 主角 / 主动作
- 主角是用户表格。
- 每行最高频的主动作应当是"查看用户"，但当前 查看/编辑/禁用/删除 四个文字动作同权重并列，删除（红色）与查看（蓝色）视觉重量接近，误触风险高。
- 建议主动作保留"查看"，编辑降为中权重，禁用/删除收进"更多"或二次确认入口。

## 层级与构图
- 筛选条独占一张卡并整幅留白，右侧约三分之二区域全空，筛选控件挤在左侧，卡内重心严重偏左。
- 表格"位置"列内容长度差异大：短的是"-"，长的是"上海 上海 中国"折两行、"广东省 佛山市三水区"折两行，列宽按最短内容定，长地址被挤压换行，行高参差。
- "用户ID"列是长数字（100000000000000005 等 18 位），独占一列且宽度吃紧，是拉宽表格的主因。
- 表头无背景区分、无固定，滚动后表头会混进数据行，长表尤其明显。

## 色彩与字体
- "导出Excel"是亮绿色实心按钮，是本页唯一绿色按钮，与主色蓝不属同一色系，视觉上被当成第二主色。
- 状态标签"已启用"用绿描边浅底，语义清晰，可保留。
- 操作列 删除 用纯红文字、其余用纯蓝文字，四个动作靠颜色区分，但同列四色文字密集，缺少分组停顿。

## 留白与节奏
- 筛选卡高度固定，控件下方与卡底之间留白较大，控件本身只占卡片上半部。
- 表格行高一致（约 52px），但地址换行的行会让该行明显偏高，破坏等距节奏。
- 头像列统一灰色占位圆，大小一致，尚可。

## 动效与交互反馈
- 筛选卡与表格无入场/加载过渡，切换搜索后内容是硬刷。
- 行没有任何 hover 高亮，鼠标移到某行没有定位提示，横向读长表容易串行。
- 操作文字无 hover 下划线或颜色加深，四个动作更像静态文字。

## 与相邻页的一致性
- 与 03-商家管理、04-商家审核、05-订单管理、06-菜品管理 同属"列表页"，但各自的列表动作形式不同（本页四个文字链接，04 是两个文字链接，08/09 是填充图标按钮，10 是下拉按钮）。
- 状态标签配色与 03/05/06 大体同源，但"已启用/营业中/已完成"的绿不完全同色。

## 改造建议
- P0 必改：把行操作收敛为"查看 + 更多"，禁用/删除进更多菜单并加重危险色与二次确认。
- P0 必改：统一"位置"列宽与溢出策略（单行省略号 + 悬浮完整地址），消除折行导致的参差行高。
- P1 建议：导出按钮改用与主色一致的次级/描边样式，或与"搜索/重置"同一视觉族。
- P1 建议：表头加浅底色或固定列头，长表滚动可辨。
- P2 可选：长用户ID列做等宽字体 + 首尾折叠展示，减少对列宽的侵占。
