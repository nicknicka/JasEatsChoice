## 主角 / 主动作
- 主角是下方两张趋势图，主动作是"选择统计周期后读趋势"。

## 层级与构图
- 概览四卡"标签 + 数字 + 绿色增长 +0"，与 03/05/06/13/14 同源，是正确复用。
