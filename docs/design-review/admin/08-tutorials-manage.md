## 这页在讲什么
一页搞定教程的统计、筛选与增删改：顶部四块状态统计、中间状态页签、下方教程列表。

## 主角 / 主动作
- 主角是教程列表，主动作是"新建/管理单条教程"。
- 表头右上"创建教程"是唯一主按钮，位置正确。
- 行内三个填充图标按钮（编辑/加精/删除）权重都很高，删除是最危险的动作却和编辑等大等色，主次失衡。

## 层级与构图
- 整页收在一张大白卡里，没有像其他页那样在卡外放"页面标题 + 副标题"，页面头部结构与其他页不一致。
- 顶部四块统计是整块高饱和渐变填充（紫/粉/红橙/黄），四块互相抢焦点，是页面最重的视觉区域，压过了真正的主角（列表）。
- 列表"ID"列过窄，长 ID（2057327777420861442）被折成四行，行高被撑到接近翻倍，是本页最刺眼的排版问题。
- 表格存在一列被裁切：难度与操作之间露出半个无法读全的列（应为某数值列），说明表格总宽溢出容器。

## 色彩与字体
- 四块渐变统计卡是典型的高饱和多色渐变，彼此无关联色，是"AI 味"重灾区，也不符合管理后台的克制基调。
- 操作区用三种填充色图标按钮（蓝=编辑、绿=加精、红=删除），比文字链接更重，颜色语义尚未对齐全站。

## 留白与节奏
- 大卡内：统计块到页签、页签到表格的间距尚可。
- 但因 ID 折行，表格行高参差，节奏被打乱。
- 统计块本身很高（约 108px），四块合起来占了首屏近三分之一高度，信息密度偏低。

## 动效与交互反馈
- 统计渐变块无 hover，页签切换有效果但列表切换无过渡。
- 填充图标按钮无 tooltip，图标含义（加精/删除）需靠猜。
- 删除无二次确认提示的视觉入口。

## 与相邻页的一致性
- 统计卡与 01/03/05/06/10/11/13/14/20/21 都不一致，是第五种统计卡形态，必须并入统一方案。
- 行操作图标按钮与 09-教程审核 一致，但与 02/03/04/05/06 的文字链接不一致。
- 页签式状态筛选在全站仅此页出现，可作为其他列表页状态筛选的参考。

## 改造建议
- P0 必改：统计卡去掉整块渐变，统一到全站概览卡组件。
- P0 必改："ID"列给足宽度单行展示，并修表格溢出导致的列裁切。
- P0 必改：删除动作与编辑拉开权重（危险色 + 二次确认），图标补 tooltip。
- P1 建议：页面头部补回卡外"标题 + 副标题"，与全站页面结构对齐。
- P2 可选：四块统计卡若必须保留颜色，只用一套同源色的深浅区分。
