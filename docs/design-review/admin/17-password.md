# 修改密码（admin/17-password）

- 截图：output/web-screenshots/admin/17-password.png
- URL：/admin/settings/password
- 评审人：review-admin

## 这页在讲什么
一张改密表单（当前/新/确认密码）+ 一个密码要求提示 + 一个安全提示卡，回答"怎么安全地改密码"。

## 主角 / 主动作
- 主角是改密表单，主动作是"修改密码"。
- 三个输入框全部必填（红星），修改密码（蓝）+ 重置（描边）主次清晰，位置在表单下方右缘，符合表单习惯。
- 页面整体任务是单动作，没有竞争性操作，主次成立。

## 层级与构图
- 卡外有"标题 + 副标题"，但两张内容卡都只占页面左半幅宽（约 600px），右半屏整片留空，页面重心明显偏左。
- 卡一 = 表单 + 内嵌灰色"密码要求"提示块；卡二 = "安全提示"标题（带锁图标）+ 分隔线 + 四条建议。
- 两张卡版式不同：卡一无标题直接上表单，卡二有带图标标题与分隔线，同页两种卡头做法。

## 色彩与字体
- "密码要求"灰色内嵌块与"安全提示"白卡都是中性色，无异常用色。
- 两条列表都用了蓝色小圆点/圆盘作为项目符号，与正文对比清楚。
- 未出现金额或日期字体问题。

## 留白与节奏
- 卡一内部：表单到按钮、按钮到"密码要求"块间距一致。
- 卡一与卡二之间垂直间距较大（约 26px），节奏尚可。
- 右半屏大留白是页面级问题（内容宽度只有一半）。

## 动效与交互反馈
- 密码强度无实时校验反馈（输入后没有强度条/即时校验）。
- 提交后结果需实测是否有成功提示与跳转。
- 输入框无聚焦强化的差异化提示（依赖默认态）。

## 与相邻页的一致性
- 与 16-个人信息 同为设置个人页，但 16 是全宽卡、本页是半宽卡，两页版式不统一。
- "安全提示"卡头（图标 + 分隔线）与 20-系统日志 卡头同源，但与 16 的表单卡不同。
- 页面头部结构（卡外标题）与 16 一致，正确。

## 改造建议
- P0 必改：统一设置域卡宽（16 与本页二选一），消除本页右半屏空置。
- P1 建议：新密码增加实时强度/规则校验反馈（对勾/提示随输入更新）。
- P1 建议：把"密码要求"从表单卡内嵌块提为与"安全提示"同级的独立提示卡，统一卡头做法。
- P2 可选：提交成功后给出明确的成功态与后续动作。
