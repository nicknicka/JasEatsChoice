# 公告管理（admin/11-announcements）

- 截图：output/web-screenshots/admin/11-announcements.png
- URL：/admin/announcements
- 评审人：review-admin

## 这页在讲什么
顶部四个公告口径（总数/已发布/草稿箱/今日新增），中间多条件筛选，下方公告表回答"有哪些公告、发给了谁、什么优先级"。

## 主角 / 主动作
- 主角是公告表，主动作是"发布/查看/编辑公告"。
- 表头右上"发布公告"主按钮清晰。
- 行操作是四个并列小图标按钮（眼睛/显示器/编辑/更多），图标含义不直观、无文字，四种动作同权重堆在一列，主次失衡且易误点。

## 层级与构图
- 概览四卡同 10-热点话题管理 的"浅色圆图标 + 数字"组件，方向一致。
- 筛选条件多（关键词/公告类型/优先级/状态/目标群体/创建时间），折成两行，构成尚清晰。
- 表格存在一列被裁切：目标群体与操作之间露出半个表头"阅…"，列宽溢出容器。
- 分页显示 "Total 0" 却列出 8 行，统计与内容矛盾。

## 色彩与字体
- 概览图标延续 10 的四色浅底（蓝/绿/红/橙），语义不强但克制，可接受。
- 优先级 普通（灰标签）、类型 系统公告（灰标签）——多个中性灰标签并列，区分度低。
- 公告内容单行省略号截断，处理正确。

## 留白与节奏
- 表格行高偏紧凑（约 36px），信息密度高。
- 筛选区两行占高较大，加上概览块，首屏能看到的表格行数有限。
- 操作列图标按钮紧凑排列，间距小，误点风险与视觉拥挤并存。

## 动效与交互反馈
- 行内四个图标按钮均无 tooltip，鼠标悬停不知各是什么动作。
- 表格行无 hover 高亮。
- "发布公告"跳转与筛选均无过渡反馈。

## 与相邻页的一致性
- 概览卡与 10/12 同源，与 01/03/08/20 不同源。
- 行操作用四个图标按钮，与 08/09 的少量图标按钮、02 的文字链接都不一致，是同类动作的又一种表达。
- "Total 0" 与行数矛盾同 04/13；列被裁切同 08。

## 改造建议
- P0 必改：修表格列裁切（表头"阅…"），保证所有列完整可读。
- P0 必改：修正分页 "Total N" 统计使其与实际记录数一致。
- P0 必改：操作列收敛动作数量，图标补 tooltip 或改为带文字的动作。
- P1 建议：多个灰色标签（优先级/类型）用更可区分的样式或文案。
- P2 可选：确认勾选列的批量操作能力是否接线，未接线不显示勾选列。
