# 权限管理（admin/19-permissions）

- 截图：output/web-screenshots/admin/19-permissions.png
- URL：/admin/settings/permissions
- 评审人：review-admin

## 这页在讲什么
一张权限树表，用缩进与展开箭头表达"菜单/接口"的父子关系，同时列出编码、路由、图标与描述。

## 主角 / 主动作
- 主角是权限树表，主动作是"编辑权限 / 添加子权限"。
- 行内 编辑 + 添加子权限 + 删除 三个文字链接，与树结构配合合理；"添加子权限"在父行上是高频动作，放中间位置正确。
- 顶部"新建权限 + 刷新"两个按钮浮在表格卡左上方，位置与 18 一致，但相比 08/10/11 的卡头右上仍不统一。

## 层级与构图
- 权限名称列用缩进 + 展开三角，父子层级清晰，是本期少见的"信息架构本身就能说话"的例子。
- 资源类型用 菜单（蓝）/ 接口（橙）两种标签区分，语义清楚。
- "路由路径"长值用省略号截断（/api/admin/merchants/*/a…），处理正确。
- "图标"列以纯文本展示图标名（User/Shop/Document/Food），对多数行是空值，信息价值低。

## 色彩与字体
- 两种资源类型标签（蓝/橙）是本页最有效的语义色，保留。
- 行操作用蓝/蓝/红，危险动作红，正确。
- 表格整体为中性色，克制，无多余彩色。

## 留白与节奏
- 表格行高紧凑（约 32px），信息密度高，适合权限树这种长表。
- 列多但互不挤压（本页未见前几页的列裁切），说明列宽分配合理。
- 顶部按钮行与表格卡之间间距一致。

## 动效与交互反馈
- 树节点展开/收起应有过渡（图标变化有限），折叠交互结果不明显。
- 行操作无 hover 反馈。
- 添加子权限、编辑跳转无结果提示。

## 与相邻页的一致性
- 与 18-角色管理 同域，两页顶部按钮都卡外左浮，做法一致（但都与全站卡头右上惯例不一致）。
- 信息密度、行高明显低于 02~06 的列表，属于"紧凑型"列表，与 10/11/13 的紧凑度更接近。
- 文字链接行操作与 18 及 02~06 一致，方向正确。

- P1 建议：树展开/收起补过渡与命中区域提示。
