# 教程审核（admin/09-tutorials-review）

- 截图：output/web-screenshots/admin/09-tutorials-review.png
- URL：/admin/tutorials/review
- 评审人：review-admin

## 这页在讲什么
一张待审教程队列表，逐行给出"看清楚这条内容再放行/驳回"的判断依据。

## 主角 / 主动作
- 主角是待审队列表，主动作是逐行"查看 / 通过"。
- 行内两个填充图标按钮（绿=查看、蓝=通过），动作含义靠图标猜，缺少文字或 tooltip，主动作不够明确。
- 表头右上"待审核"按钮带红色数字角标 11，但它本身不是操作按钮，更像状态徽标，放在按钮位会造成误解。

## 层级与构图
- 整页收在一张大白卡内，无卡外标题，与其他页头部结构不一致。
- "ID"列过窄，长 ID（2057327777420861442）折成四行，行高翻倍，是首屏最大排版问题。
- "类型"列用图标代替文字（橙文档=图文、红视频=视频），无文字标签，读不出类型。
- "关联信息"列出现 "qwen" 之类的裸值，与相邻空单元格并存，列语义不清。
- 行高因 ID 折行和内容差异忽高忽低，表格节奏不匀。

## 色彩与字体
- 来源标签 用户（绿描边）/ 商家（橙）区分合理。
- 操作图标按钮用填充绿/蓝，比文字链接重；颜色语义与全站未对齐。
- "qwen" 以斜体灰色出现，与正文不同族，像是溢出/调试字段。

## 留白与节奏
- 卡内表格是唯一内容，底部留白大，但属于数据量决定，可接受。
- 行高不齐是主要节奏问题，源于 ID 折行与单元格内容长短不一。

## 动效与交互反馈
- 通过/查看点击后无局部反馈（行是否消失、是否进入下一条），整表硬刷。
- 图标按钮无 hover 文案与 tooltip。
- "待审核"角标无变化动效。

## 与相邻页的一致性
- 与 08-教程管理 同域，但操作按钮的图标组合不同（本页 绿眼+蓝勾），风格未完全统一。
- ID 折行、行高不齐的问题与 08 相同。
- 图标按钮式行操作与 08 一致，但与 02~06 的文字链接不一致。

## 改造建议
- P0 必改："ID"列单行完整展示，消除折行带来的行高翻倍。
- P0 必改：操作按钮补文字或 tooltip，明确"查看/通过"含义，通过后给行内结果反馈。
- P1 建议："类型"列图标补文字标签；清理"关联信息"列异常值。
- P1 建议：把"待审核"从按钮位改为纯状态徽标，避免被当作操作。
- P2 可选：行操作统一为全站一致的形态（文字链接或统一图标按钮二选一）。
