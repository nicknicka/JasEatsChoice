# 角色管理（admin/18-roles）

- 截图：output/web-screenshots/admin/18-roles.png
- URL：/admin/settings/roles
- 评审人：review-admin

## 这页在讲什么
一张角色表，逐行给出角色名称、编码、权限数量与启停状态，回答"平台有哪些角色、各配了多少权限"。

## 主角 / 主动作
- 主角是角色表，主动作是"给角色分配权限 / 编辑角色"。
- 行内 分配权限 + 编辑（+ 删除）为文字链接，主次合理：分配权限是这里最常用的动作，放最前正确。
- 超级管理员行不显示"删除"，符合权限逻辑，是正确的一致性处理。

## 层级与构图
- "新建角色"按钮孤零零浮在表格卡左上方，与其他页把新增主按钮放进卡头右侧的做法不同，位置偏弱。
- "创建"列表头被裁成"创建"，值为 "2026…"，列宽溢出被右侧遮挡，时间列读不全。
- "权限数量"用灰色圆角小块承载数字（69/65/6/0），看起来像状态标签但其实只是计数，易误读。

## 色彩与字体
- 状态"启用"绿色标签统一，正确。
- 三个行操作用蓝/蓝/红，危险动作（删除）用红，语义正确。
- 无金额、无衬线数字问题。

## 留白与节奏
- 表格列多、行内文字长短不一（描述列折行），行高不齐。
- 卡外与卡内间距一致，节奏本身稳。
- 权限数量小块与相邻文本贴合偏紧。

## 动效与交互反馈
- "新建角色""分配权限"跳转无过渡与结果提示。
- 表格行无 hover 高亮。
- 删除无二次确认的视觉入口。

## 与相邻页的一致性
- 与 19-权限管理 同属权限域，但两页新增按钮都在卡外左浮，与 08/10/11 的卡头右上按钮不统一。
- 列裁切问题同 08/11/20。
- 行操作用文字链接，与 02/03/04/05/06/19 一致，方向正确。
