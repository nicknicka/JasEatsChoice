# 管理员控制台（admin/01-dashboard）

- 截图：output/web-screenshots/admin/01-dashboard.png
- URL：/admin/dashboard
- 评审人：review-admin

## 这页在讲什么
用一排运营数字（用户/商家/订单/收入）加一组快捷入口，把管理员的注意力从"今天平台什么状态"引到"去哪个模块处理"。

## 主角 / 主动作
- 主角是 5 个概览数字卡，主动作是"看哪块需要处理"。
- 但页面里同时存在三大块：概览卡、快捷操作、最近教程，三者视觉权重接近，默认视线落点是数字卡而非快捷操作。
- 快捷操作 4 个入口与概览卡同为卡片网格，没有主次；建议把与"待处理"相关的入口（教程审核）提到最高权重，其余降级为文字入口。

## 层级与构图
- 概览区 5 张卡排成 4+1：第一行 4 张、第二行单挂 1 张（今日新增用户），左侧与右侧留下大片空位，网格不闭合。要么补成 3+2 / 5 列一行，要么明确做 4 列主指标 + 次级指标条。
- 概览卡内"图标 / 数字 / 标签"三者水平排布，数字与标签间距偏近，标签紧贴数字下沿，读起来是"11\n用户总数"的堆叠，缺少基线对齐。
- 快捷操作 4 张卡内标题+副标题左对齐，但"教程审核"副标题折成两行、其余为一行，导致四张卡内部节奏不齐；副标题行数应统一为一行的短语。
- 最近教程表格处在首屏下沿，只露出表头与 No Data，页面主体其实没有可读内容。

## 色彩与字体
- 概览卡图标用四套不同渐变色（紫、粉、橙、青绿、彩虹浅色），颜色之间无对应关系，读不出语义；同一排彩色方块互相抢焦点。
- 数字（11 / 12 / 0 / ¥0.00）看起来是衬线字形，与中文无衬线正文混排，数字与标签不同族。
- 侧栏选中项是对比度很足的纯蓝，和内容区彩色图标块不是同一套色系。

## 留白与节奏
- 概览卡之间横向间距偏大（相邻卡之间空隙接近卡片内边距的两倍），五张卡被拉得很散。
- 概览区与快捷操作之间留白、快捷操作与最近教程之间留白不一致，纵向节奏不匀。
- 卡片内部：图标块贴左，数字组居中偏左，右侧留大量空白，单卡内水平重心偏左。

## 动效与交互反馈
- 概览卡、快捷操作卡均无 hover 反馈（背景/阴影/位移都不变），点击区域与非点击区域没有区分。
- 数字卡没有"数值变化"的过渡，刷新时数字会硬切。
- 快捷操作卡没有按压/进入反馈，用户点进去前没有任何可点提示。

## 与相邻页的一致性
- 概览数字卡与 03-商家管理、05-订单管理、06-菜品管理、13-充值记录、14-退款管理、21-数据统计 的概览卡不是同一种组件：本页是"渐变图标+数字"，那些页是"纯数字居中"，08-教程管理 又是整块渐变填充。
- 列表页的列表操作都在内容卡内，本页"最近教程"也复用表格，方向一致，可保留。

## 改造建议
- P0 必改：统一全站概览数字卡的组件形态（图标、数字、标签的相对位置、字号），本页不再单独用彩色渐变图标块。
- P0 必改：修 5 卡 4+1 的空网格，改为闭合的等宽网格或明确的"主指标 + 次级条"结构。
- P1 建议：数字改用与正文同族的无衬线字形，并加大数字与标签的行距。
- P1 建议：给概览卡与快捷操作卡补统一的 hover 反馈（同一套阴影/位移）。
- P2 可选：最近教程表格补空状态说明文案与一个"去教程管理"的次级动作。
