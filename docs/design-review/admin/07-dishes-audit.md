# 菜品审核（admin/07-dishes-audit）

- 截图：output/web-screenshots/admin/07-dishes-audit.png
- URL：/admin/dishes/audit
- 评审人：review-admin

## 这页在讲什么
顶部审核进度（待审核/今日已审核/今日已拒绝/本月审核总数），下方待审菜品表回答"有哪道菜等我审"。

## 主角 / 主动作
- 主角是待审菜品列表，主动作本应是逐行"通过 / 拒绝"。
- 但当前列表为空，整页没有可执行动作，主动作缺失，页面变成一张空表加空旷背景。

## 层级与构图
- 概览四卡等宽，构图正确。
- 空表状态只显示居中的英文 "No Data"，没有图标、没有说明、没有"当前无待审菜品"的中文文案与下一步入口。
- 空表下方仍挂着完整分页条（Total 0、10/page、跳页），在空数据下是无意义控件。
- 筛选区折成两行：第一行 关键词 + 审核状态 + 提交日期，第二行只有 搜索 + 重置，右侧全空，与 05-订单管理 同病。

## 色彩与字体
- 概览纯数字无色差，"待审核 0"看不出这是本页核心入口。
- 空状态文案 "No Data" 为英文，与全站中文界面不一致。

## 留白与节奏
- 页面主体从卡底到屏幕底部全是空白，内容高度远小于视口，页面下半屏完全空置。
- 概览—筛选—卡片三段间距一致，节奏本身没问题，"空洞"来自缺内容。

## 动效与交互反馈
- 空状态没有任何引导动效或占位插画。
- 无数据时不提供刷新入口的视觉强调，刷新按钮（若有）在表头也偏弱。

## 与相邻页的一致性
- 与 06-菜品管理 同域，但 06 概览四卡、筛选一行，本页筛选折两行，姊妹页不同构。
- 英文 "No Data" 空状态与 20-系统日志 一致，是跨页共性缺陷。
- 分页条在空数据下的冗余与 11-公告管理、13-充值记录 的 "Total 0" 问题同源。

## 改造建议
- P0 必改：空状态改为中文，并补图标/说明与"去菜品管理"或"刷新"的次级入口。
- P0 必改：空数据时隐藏或禁用分页条。
- P1 建议：筛选控件与按钮收敛为一两行，消除右侧空白。
- P1 建议：概览卡给"待审核"统一待办强调色。
- P2 可选：空状态与全站空状态统一成同一组件。
