# 热点话题管理（admin/10-topics）

- 截图：output/web-screenshots/admin/10-topics.png
- URL：/admin/topics
- 评审人：review-admin

## 这页在讲什么
顶部四个话题口径（总数/生效中/待审核/总点击量），中间筛选，下方话题表回答"哪些话题在跑、优先级与状态如何"。

## 主角 / 主动作
- 主角是话题表，主动作是逐条话题的"查看与调整"。
- 行操作统一收在一个"操作 ▾"下拉按钮里，避免了动作堆叠，是比 02 更克制的处理。
- 表头右上"新增热点"主按钮 + "导出"次级按钮，主次清晰。

## 层级与构图
- 概览四卡用"浅色圆图标 + 标签 + 大数字"（左图标右文字），构图与 11/12 同源，可归入同一组件。
- 筛选区包在一个浅灰内嵌块里，与其他列表页的独立白卡筛选不同，但结构清楚。
- 表格带勾选列，为批量操作预留，是新能力（其他列表页没有），需确认是否接线。
- "优先级"列并用升/降序箭头，排序入口可见，是加分项。

## 色彩与字体
- 四个概览卡图标分别用蓝/绿/红/橙的浅色圆底，颜色无强语义，但比 08 的高饱和渐变克制很多。
- "优先级"数字用橙/琥珀色，与"警告/待办"色系混用，语义不够单一。
- 状态标签 生效（绿）/ 未生效（灰）区分清楚。

## 留白与节奏
- 表格行高约 36px，比 02~06 的 52px 更紧凑，信息密度更高。
- 概览块到筛选块、筛选块到表格的纵向间距一致。
- 内嵌筛选块四周有内边距，视觉上像一张"卡中卡"，与独立筛选卡是两套做法。

## 动效与交互反馈
- "操作 ▾"下拉展开有基础过渡，"查询/重置"有按压态。
- 表格行无 hover 高亮，紧凑长表横向读易串行。
- 概览数字无变化过渡。

## 与相邻的一致性
- 概览卡形态与 11/12 一致，但和 01（渐变图标）、03/05/06（纯数字）、08（渐变填充）、20（纯色方块）不一致，全站仍是多套并存。
- "操作 ▾"下拉在全站独此一处，与 02 的文字链接、08/09 的图标按钮不一致。
- 生效时间已格式化为 "02-06 00:00"，而 03/05/06 仍是带 T 的原始时间戳，日期格式跨页不统一。

## 改造建议
- P0 必改：日期格式统一，与 03/05/06 的清单页对齐为同一格式。
- P1 建议：优先级数字避免使用与状态/警告同源的橙色，改用中性强调或与排序箭头同色。
- P1 建议：行操作下拉的样式在全站列表页统一（是否用下拉需与 02 的决策一致）。
- P2 可选：确认勾选列的批量能力是否已接线，未接线则移除，避免"看起来能选却不能批量"。
