# 系统设置（admin/15-settings）

- 截图：output/web-screenshots/admin/15-settings.png
- URL：/admin/settings
- 评审人：review-admin

## 这页在讲什么
一张设置卡，用页签分流"系统设置/通知设置/安全设置/AI 模型"，当前页签下是一小组站点开关与保存动作。

## 主角 / 主动作
- 主角是页签内的设置表单，主动作是"改完保存设置"。
- 保存按钮在最底部左对齐，是页面唯一的实心主按钮，位置合理。
- 页签是并列的四个平级入口，当前激活态（系统设置，蓝色下划线）清晰。

## 层级与构图
- 页面只有一张卡，卡内页签横贯整幅，表单区挂在页签下方。
- "基本设置"标题下有一条醒目的红色横线——这是唯一一处红色横线，与全站任何分隔线都不一致，看起来像残留的进度条或误配色。
- 表单标签右对齐、控件左对齐，标签列宽固定，说明"允许用户上传教程"等开关旁带灰色说明文字，信息层次可读。
- 卡片高度有限，内容结束后下方是大片空白卡片与空旷页面。

## 色彩与字体
- 开关（开启）为统一蓝色，与主色一致，正确。
- 唯一问题色是"基本设置"下的红横线，破坏配色克制。
- 文本层级（标签深色/说明浅灰）处理得当。

## 留白与节奏
- 卡内：页签到"基本设置"、标题到表单间距尚可。
- 表单最后一项到保存按钮间距一致。
- 卡片底到页面底留白过大，页面显得半空。

## 动效与交互反馈
- 开关切换有基础状态变化，保存后有成功提示（未在图内体现，需实测）。
- 页签切换无内容区过渡。
- 表单未做的改动无"未保存"提示，切换页签可能丢改动。

## 与相邻页的一致性
- 侧栏本项标签是"系统配置"，面包屑与页面标题是"系统设置"，命名不一致。
- 设置类页面共 5 个（15/16/17/18/19/20），本页是唯一用页签聚合设置的，其余是独立页或列表，结构不统一。
- 卡片头部带图标（⚙）的样式与 17-修改密码 的安全提示卡、20 的筛选卡头部同源度不一。

## 改造建议
- P0 必改：去掉"基本设置"下的红色横线，换成与全站一致的中性分隔样式。
- P0 必改：统一侧栏标签与页面标题命名（系统配置 / 系统设置 二选一）。
- P1 建议：切换页签时若表单有未保存改动给出提示或自动保留。
- P2 可选：给卡片底多余留白一个归属（内容补全或卡片高度收敛）。
