## 这页在讲什么
顶部四个商家数量口径（总数/营业中/待审核/已暂停），下方一张商家表回答"有哪些商家、审核与营业状态如何"。

## 主角 / 主动作
- 主角是商家表格，主动作是"查看商家 / 处理审核状态"。
- 概览四卡里的"待审核 8"是唯一带待办含义的数字，但它与其余三个中性数字卡同权重同色，看不出该先看它。
- 行内动作 查看 + 审核/状态 是并列两个文字链接，权重接近，可接受；建议把待审核行的动作名与状态标签颜色对齐，形成"橙=待办"的一致提示。

## 层级与构图
- 概览四卡等宽闭合，构图比 01-管理员控制台 干净，这是可复用的正确版式。
- "商家ID"列窄，seedm20260520_01 被拆成两行（seedm202605 / 20_01），把一条不可分割的标识切断了，是首屏最刺眼的排版问题。
- "注册时间"列展示原始时间戳 2026-05-20T15:46:05，列被拉宽以容纳，仍带 T 分隔。
- 筛选卡同 02-用户管理，控件居左、右侧大片留白。

## 色彩与字体
- 概览卡纯数字居中，无图标、无配色，语义仅靠文案，四个数字视觉上完全等价。
- 状态标签 营业中（绿）/ 待审核（橙）两色区分合理。
- 表格数字与金额无特殊处理，本页暂未出现衬线数字，字体相对统一。

## 留白与节奏
- 概览区到筛选区、筛选区到表格的纵向间距一致，节奏稳。
- 表格行高受"商家ID"折行影响，几乎每行都被撑高成两行高，等距感被破坏。
- 筛选卡自身高度富余，控件下方留白偏多。

## 动效与交互反馈
- 概览卡、表格行无 hover 反馈。
- 状态切换（审核动作）后没有局部更新或提示动效，整页硬刷。
- 搜索/重置按钮有基础按压态，但筛选过程无 loading 提示。

## 与相邻页的一致性
- 概览四卡与 05/06/13/14/21 的"纯数字居中"为同一类，方向正确，应作为全站概览卡的基准。
- 与 01-管理员控制台 的"渐变图标概览卡"、08-教程管理 的"整块渐变卡"不是同一组件，需在基准里二选一。
- 与 04-商家审核 同属商家域，但 04 把刷新按钮放进了内容卡表头，本页把搜索/重置放在独立筛选卡，交互位置不统一。

## 改造建议
- P0 必改：给"商家ID"列足够宽度或改用不折行的标识展示，"seedm20260520_01"必须单行完整。
- P0 必改：注册时间统一格式化为 "2026-05-20 15:46"，不再出现 ISO 的 T。
- P1 建议：概览卡给"待审核"一类待办数字一个统一的强调色（与状态标签橙同源），让待办可被一眼锁定。
- P1 建议：筛选控件与"搜索/重置"对齐方式在列表页统一（推荐与内容卡表头同宽左对齐）。
- P2 可选：概览四卡可加一处统一的图标或前缀，避免纯数字过于平淡。
