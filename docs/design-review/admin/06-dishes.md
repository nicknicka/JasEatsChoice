## 这页在讲什么
顶部菜品口径（总数/已上架/已下架/待审核），下方菜品表回答"有哪些菜、属于谁、什么状态"。

## 主角 / 主动作
- 主角是菜品表，主动作是"查看菜品 / 上下架"。
- 行内 查看 + 下架 两个动作，方向正确；"下架"用橙色文字，语义（停用）与颜色对得上，可保留。

## 层级与构图
- 概览四卡等宽，构图正确。
- 筛选区一行排下 关键词 + 菜品分类 + 状态 + 搜索 + 重置，比 05-订单管理 更紧凑，是更好的处理，建议作为列表页筛选的基准。
- "菜品ID"列过窄，seed_1779000 769631_1 被折成两行，切断了标识。
- "创建时间"展示原始时间戳 2025-11-22T11:35:20，带 T。

## 色彩与字体
- 价格（¥38、¥12…）红色粗体衬线，与 05-订单管理 金额同病：红色对价格无语义，衬线数字与正文不同族。
- 状态"已上架"绿色标签语义正确。
- 行内 查看（蓝）与 下架（橙）双色区分合理。

## 留白与节奏
- 表格行高被"菜品ID"两行折行撑高，等距感被破坏。
- 概览—筛选—表格三段间距一致，纵向节奏稳。
- 筛选卡内右侧留白比 05 少，利用更充分。

## 动效与交互反馈
- 下架属破坏性/停用动作，点击无确认、无结果反馈。
- 表格行无 hover 高亮。
- 上下架状态变化后整表硬刷，无局部动效。

## 与相邻页的一致性
- 与 05 同为"概览 + 筛选 + 列表"，筛选换行处理却是同一页族里的两种，应统一。
- 与 07-菜品审核 是同域姊妹页，但 07 概览是四卡、筛选折两行，与本页不完全同构。
- 价格红色与 05/12/13/14 一致，跨页共性缺陷。
