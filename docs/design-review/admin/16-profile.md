# 个人信息（admin/16-profile）

- 截图：output/web-screenshots/admin/16-profile.png
- URL：/admin/settings/profile
- 评审人：review-admin

## 这页在讲什么
分两块：上面可编辑的"基本信息"表单，下面只读的"角色信息"，回答"我是谁、我属于什么角色"。

## 主角 / 主动作
- 主角是"基本信息"表单，主动作是"保存修改"。
- 用户名（灰色只读）与真实姓名的差异靠输入框底色区分，可读；但只读项没有锁图标或说明，用户第一反应会尝试点它。
- 保存修改（蓝）+ 重置（描边）主次清晰。

## 层级与构图
- 卡外有"标题 + 副标题"，与 02~07 结构一致，比 15/17 的单卡结构更规范。
- "基本信息"表单字段横向拉满整卡宽（约 990px），手机号/邮箱这类短内容也被拉到同宽，输入框过长，视线横移成本高。
- "头像"是较大的灰底圆形占位（首字"系"），与"点击上传"按钮同排，处理合理。
- "角色信息"用带表头底色的两列只读网格（角色名称/角色代码/账号状态/创建时间），与上方表单是不同的版式。

## 色彩与字体
- 必填项红星、开关等无异常配色。
- 账号状态"正常"绿色标签清晰。
- 创建时间 2026-01-31T11:39:20 带 T，且为 ISO 原样输出。

## 留白与节奏
- 两张卡之间垂直间距较大（约 40px），与卡内字段间距相比略跳。
- 表单字段行距一致，纵向节奏稳。
- 输入框过长本身就是横向留白浪费（右侧一大段空输入框）。

## 动效与交互反馈
- 上传头像无预览/裁剪/上传中状态（图内不可见，需实测）。
- 保存/重置有基础按压态，保存结果需实测是否有 toast。
- 只读用户名无 hover 提示说明"不可改"。

## 与相邻页的一致性
- 与 17-修改密码 同为设置个人页，但 17 是窄卡居中偏左、本页是全宽卡，两页版式不统一。
- 日期格式带 T 与 03/04/05/06/12/13/14 一致，跨页共性。
- 页面头部结构（卡外标题）比 15/17 更规范，建议作为设置页基准。

## 改造建议
- P0 必改：创建时间格式化为 "2026-01-31 11:39"。
- P1 建议：收窄基本信息输入框到合理最大宽度（如 480~560px），减少横向空跑。
- P1 建议：只读用户名加锁图标或"用户名不可修改"说明。
- P2 可选：统一设置域各页的卡片宽度与头部结构。
