# 商户注册（public/04-merchant-register）

- 截图：output/web-screenshots/public/04-merchant-register.png
- URL：/merchant/register
- 评审人：review-public

## 这页在讲什么
一张独立的表单卡：绿色满屏底色上居中一张白色圆角卡片，卡片里用左对齐标签一路排到「注册」，收集商户入驻需要的一串资料。

## 主角 / 主动作
- 主角是表单卡片，主动作是「注册」按钮。
- 现状：主动作「注册」是 Element Plus 默认蓝的实心按钮，尺寸只有 x=590→642、y=687→710（约 52×23px），是画面里最弱的一块——既不占表单列宽、也没有明显权重，与整卡 563px 宽完全不成比例。
- 干扰动作：卡片左上蓝色「‹ 返回」链接（y≈238）与验证码行「刷新」蓝色链接，与「注册」用同一种蓝，主次被拉平，视线找不到落点。

## 层级与构图
- 卡片 x=438→1001（宽 563）、y=187→760（高 573），水平居中、重心略偏上，容器尺寸本身合理。
- 卡片内标题「商户注册」居中，但表单标签与输入框左对齐（输入框 x=591→968，宽 377px），标题轴与表单轴不一致，视线在中轴和左轴之间来回。
- 表单内部对齐成立：标签右对齐 + 红色必填星号，与输入框左缘对齐。
- 卡片顶部「返回」到标题之间有一条较大空带，节奏不匀。
- 「返回」语义上是退出一整页，放在卡片内左上角、权重偏低。

## 色彩与字体
- 与 01–03 完全不同的色系：满屏绿 (68,113,71) + 白卡 + Element 默认蓝按钮/链接 + 红色必填星号 + 验证码彩色数字（紫/青）。
- 标题「商户注册」是衬线字体（约 40px），与 01–03 的无衬线标题不一致。
- 同一画面出现绿、蓝、红、紫、青多种高饱和色，缺一条主色收敛线。

## 留白与节奏
- 卡片内表单行距约 57px，均匀但偏松。
- 标题到首行标签之间的空档大于行距，头部偏空；「返回」与标题之间又叠了一段空带，头部节奏不匀。
- 卡片外四周留白充足，是公共端四页里唯一带「容器感」的页面，这一点保留。

## 动效与交互反馈
- 静态截图无法验证动效；结构上缺：「注册」按钮 loading 与不可点态、字段校验与错误态、「刷新验证码」反馈、经营范围下拉的展开态、必填星号与错误提示的区分。
- 「注册」蓝色默认态看不出 hover 与按下态。

## 与相邻页的一致性
- 与 01/02/03 的暖橙体系、全宽语法、无衬线字体全部不一致，是公共端内部最大的断裂点：同为注册场景，02（用户注册）与 04（商户注册）用了两套完全不同的视觉语言。
- 卡片 + 左对齐标签 + Element 默认外观更像直接套用的后台表单模板，未接入公共端基调。

## 改造建议
- P0 必改：把 04 纳入公共端基调——底色、主色、按钮样式、标题字体与 01–03 对齐（暖色系 + 无衬线标题 + 同一主色按钮）。
- P0 必改：「注册」按钮提到与表单列同宽或明确的主按钮尺寸（至少占列宽、明显大于当前 52px），并补 loading/禁用态；「返回」「刷新」等链接降级为中性色，不与主按钮抢蓝。
- P1 建议：让标题与表单共用同一中轴，或明确标题左对齐，消除居中标题 + 左对齐表单的轴错位。
- P1 建议：配色收敛到「主色 + 中性灰 + 一个错误色」，去掉验证码彩色数字之外的额外高饱和色。
- P2 可选：收紧头部留白，使卡片内的节奏与行距一致。
