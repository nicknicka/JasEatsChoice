# 用户注册（public/02-register）

- 截图：output/web-screenshots/public/02-register.png
- URL：/register
- 评审人：review-public

## 这页在讲什么
创建账号的第一步：顶部用「创建账号」标题加一个两步进度条交代流程位置，下面填三项登录信息，用「下一步」推进到第二步。

## 主角 / 主动作
- 主角是「设置登录信息」这一步的表单，主动作是「下一步」。
- 现状：三个输入框与「下一步」按钮全部横跨 x=21→1418（约 97% 视口宽），「下一步」被拉成约 1400×41 的橙色带，权重靠面积而不是位置。
- 次要动作只有底部「立即登录」（y≈861），位置贴底，与主动作距离过远，无法构成清晰的「主—次」关系。

## 层级与构图
- 与 01 同样缺列宽约束，单列约 1400px 过宽。
- 进度条：两步圆点约 22px，居中于 x720，但只有第一步带文字「设置登录信息」，第二步是空圈无标签，用户无法从画面预知第二步内容。
- 页面切成三段：标题+进度条（y≈55–165）／表单（y≈213–398）／底部登录入口（y≈861），中间大段空白。
- 标题区与表单区之间没有卡片或分隔，表单直接铺在背景上。
- 表单左对齐到 x=21，标题与进度条居中对齐，两套基准混用。

## 色彩与字体
- 沿用暖色基调（背景近 (255,247,242)）；激活步骤圆点与「下一步」按钮用主色橙，未激活的第二步为灰白描边圆点，状态区分清楚。
- 标题「创建账号」约 24px 深色；占位与辅助文字 12–13px 偏小。
- 密码规则写在 placeholder「密码（6-32位）」，输入后即消失，规则无法持续可见。

## 留白与节奏
- 表单下方（y≈398）到底部登录入口（y≈861）约 460px 空白，重心全压在顶部，下方空洞。
- 表单内字段间距约 9–10px，与下方大空档反差过大。

## 动效与交互反馈
- 静态截图无法验证动效；结构上缺：步骤 1→2 的切换过渡、「下一步」按钮 loading 与不可点态、密码强度或实时校验反馈、字段失焦校验提示位。
- 进度条当前只表达「现在在第几步」，没有到下一步的过渡表现。

## 与相邻页的一致性
- 与 01/03 同一套暖色 + 全宽语法，批内自洽；进度条语法与 03 一致（都是「1 激活 + 2 空圈无标签」）。
- 与 04 绿底白卡蓝按钮割裂，公共端内部两套语言。

## 改造建议
- P0 必改：表单列设宽度上限（建议 360–420px）并居中，三个输入框与「下一步」统一列宽。
- P0 必改：给进度条第二步补文字标签（如「完成注册」），让两步内容在画面上可预期；02 与 03 同步补。
- P1 建议：底部「立即登录」收进同一列、紧跟表单，消除约 460px 空档。
- P1 建议：密码规则改为字段下方的常驻提示文字，不再只写在 placeholder。
- P2 可选：标题与表单共用同一中轴，统一对齐基准。
