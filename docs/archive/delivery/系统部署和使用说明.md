# 系统部署和使用说明

## 一、本地运行方式

### 1. 启动 MySQL 和 Redis

可以使用本机服务，也可以使用 Docker：

```bash
docker run --name jaseats-mysql -e MYSQL_ROOT_PASSWORD="$MYSQL_ROOT_PASSWORD" -e MYSQL_DATABASE=jia_shi_yi_xuan -p 3306:3306 -d mysql:8.0
docker run --name jaseats-redis -p 6379:6379 -d redis:7-alpine
```

### 2. 初始化数据库

在交付包根目录执行：

```bash
mysql -uroot -p"$MYSQL_ROOT_PASSWORD" jia_shi_yi_xuan < 03_database_scripts/full-database-backup.sql
```

如数据库已存在旧结构，需要先备份旧库，再根据 `03_database_scripts/migrations` 中脚本按文件名顺序补齐结构。

### 3. 启动后端

```bash
cd 01_source_code/JasEatsChoiceJava
mvn clean package -DskipTests
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

验证接口：

```bash
curl http://localhost:7777/api/actuator/health
```

返回 `UP` 表示后端启动成功。

### 4. 启动桌面端

```bash
cd 01_source_code/JasEatsChoiceFront
npm install
npm run dev
```

桌面端会自动打开 Electron 应用，默认连接 `http://localhost:7777/api`。

### 5. 启动小程序端

```bash
cd 01_source_code/JasEatsChoiceUniApp
npm install
npm run dev:mp-weixin
```

然后使用微信开发者工具导入生成的微信小程序构建目录。首次运行前需要在 `src/manifest.json` 和 `project.config.json` 中替换为自己的小程序 AppID。

## 二、Docker 开发部署

在交付包根目录执行：

```bash
cd 01_source_code/docker
docker compose -f docker-compose.dev.yml up -d --build
```

该方式会启动：

- MySQL：`localhost:3306`
- Redis：`localhost:6379`
- 后端：`localhost:7777`
- Nginx：`localhost:80`

注意：首次启动后仍需要导入数据库脚本。

## 三、生产部署参考

1. 在服务器安装 Docker 和 Docker Compose。
2. 修改 `01_source_code/docker/.env` 中的域名、数据库密码、Redis 密码、JWT 密钥、智谱 AI 密钥。
3. 修改 `01_source_code/docker/nginx/conf.d/prod.conf` 中的域名和证书路径。
4. 准备 HTTPS 证书，或按实际部署平台接入证书服务。
5. 执行：

```bash
cd 01_source_code/docker
docker compose up -d --build
```

6. 检查服务：

```bash
docker compose ps
curl http://localhost:7777/api/actuator/health
```

## 四、基础使用流程

### 用户端

1. 注册或登录用户账号。
2. 浏览首页推荐、商家列表和菜品详情。
3. 将菜品加入购物车并提交订单。
4. 在订单页查看订单状态。
5. 使用饮食记录、卡路里管理、收藏、AI 助手、聊天等功能。

### 商家端

1. 注册商家账号并完善店铺资料。
2. 配置菜单和菜品。
3. 接收并处理订单。
4. 查看经营统计、评价、消息和 AI 经营建议。

### 管理端

1. 使用管理员账号登录。
2. 进行用户管理、商家审核、菜品审核、订单与退款处理、财务和系统配置。

## 五、常见问题

- 后端连接数据库失败：检查 MySQL 是否启动、数据库名是否为 `jia_shi_yi_xuan`、账号密码是否和配置一致。
- 前端请求失败：检查后端是否已启动，确认 `VITE_API_BASE_URL` 指向 `http://localhost:7777/api`。
- 小程序无法请求本地接口：微信开发者工具中关闭域名校验，或配置合法域名；真机调试必须使用可访问的 HTTPS 域名。
- AI 功能不可用：检查 `ZHIPU_API_KEY` 是否已配置。
- 地图功能不可用：检查高德或腾讯地图 Key 是否已配置并开通对应服务。
