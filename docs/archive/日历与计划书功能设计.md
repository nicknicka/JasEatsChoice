# 佳食宜选 - 日历功能与计划书模块设计

> 产品功能设计：为用户提供日历管理和计划制定功能
> 创建时间：2026-03-22

---

## 🎯 一、功能定位

### 核心价值
```
✅ 帮助用户规划每日饮食
✅ 制定和执行饮食计划
✅ 查看历史订单记录
✅ 设置用餐提醒
✅ 追踪健康目标
```

### 目标用户
```
- 学生：规划每日三餐
- 上班族：提前订餐规划
- 健身人群：精确控制饮食
- 减脂/增肌人群：执行饮食计划
```

---

## 📅 二、日历功能

### 2.1 日历视图

**月视图：**
- 显示整月的饮食记录
- 每天显示：
  - 总卡路里摄入
  - 三餐记录
  - 订单标记
  - 运动记录
  - 体重记录
- 点击日期查看当天详情

**周视图：**
- 显示一周的饮食计划
- 每天显示：
  - 早餐/午餐/晚餐安排
  - 计划卡路里
  - 实际摄入
  - 完成度

**日视图：**
- 时间轴形式
- 显示：
  - 三餐时间
  - 加餐时间
  - 运动时间
  - 用药/补充剂时间
  - 提醒事项

---

### 2.2 饮食记录

**记录三餐：**
- 早餐记录
  - 时间：默认8:00
  - 内容：吃了什么
  - 卡路里：自动计算或手动输入
  - 照片：可选上传食物照片

- 午餐记录
  - 时间：默认12:00
  - 内容：吃了什么
  - 卡路里：自动计算或手动输入
  - 照片：可选上传食物照片

- 晚餐记录
  - 时间：默认18:00
  - 内容：吃了什么
  - 卡路里：自动计算或手动输入
  - 照片：可选上传食物照片

**加餐记录：**
- 上午加餐（10:00）
- 下午加餐（15:00）
- 夜宵（21:00）
- 记录内容、热量

**快捷记录：**
- 选择历史菜品
- 扫描菜品条形码
- AI识别食物照片
- 一键记录昨日菜单

---

### 2.3 订单历史

**日历中的订单标记：**
- 下单日期显示订单图标
- 显示订单数量
- 显示订单金额
- 点击查看详情

**订单详情：**
- 订单号
- 商家信息
- 菜品列表
- 配送信息
- 订单状态
- 用户评价

**快速下单：**
- 点击历史订单
- 一键再次下单
- 自动填充地址
- 自动选择优惠

---

### 2.4 健康数据

**体重记录：**
- 每日记录体重
- 生成体重曲线
- 目标体重对比
- BMI计算

**运动记录：**
- 运动类型（跑步、健身、步行等）
- 运动时长
- 消耗卡路里
- 训练内容

**身体指标：**
- 体脂率
- 肌肉量
- 血压
- 血糖
- 睡眠质量

## 📋 三、计划书模块

### 3.1 饮食计划

**周计划制定：**
- 选择目标（减脂/增肌/保持/健康）
- 设置目标卡路里
- 选择饮食偏好（低脂/低盐/素食等）
- 标注过敏源
- 设置预算范围

**AI生成计划：**
- 调用AI智能顾问Agent
- 自动生成7天饮食计划
- 包含三餐+加餐
- 符合营养需求
- 符合口味偏好
- 符合预算范围

**手动调整：**
- 拖拽调整餐次
- 替换菜品
- 调整份量
- 添加备注

**计划执行：**
- 每日打卡记录
- 实际vs计划对比
- 偏差分析
- 原因记录

---

### 3.2 订餐计划

**工作日订餐：**
- 设置工作日默认订餐时间
- 选择常吃商家
- 设置默认菜品
- 一键下单

**周末订餐：**
- 周末特别计划
- 家庭聚餐计划
- 朋友聚会订餐

**周期性订餐：**
- 每周固定套餐
- 月度订餐卡
- 自动续订

**订餐提醒：**
- 提前1天提醒
- 推荐菜品
- 优惠信息推送

---

### 3.3 运动计划

**计划制定：**
- 运动目标（减脂/增肌/保持健康）
- 每周运动次数
- 每次运动时长
- 运动类型选择

**AI生成计划：**
- 根据饮食计划生成
- 配套运动建议
- 考虑时间安排
- 难度递进

**执行记录：**
- 运动打卡
- 时长记录
- 感受记录
- 照片记录

---

### 3.4 购物清单

**自动生成：**
- 根据饮食计划生成

- 按类别分组

**清单管理：**
- 添加/删除物品
- 标注已购买
- 分享给家人
- 导出清单

**智能提醒：**
- 冰箱库存提醒
- 食材过期提醒
- 促销信息推送

---

### 3.5 健康目标

**目标设置：**

- 运动频率目标
- 饮食习惯目标

**目标追踪：**
- 每日进度更新
- 达成率统计
- 预计完成时间
- 偏差分析

**AI建议：**
- 根据进度给出建议

## 📱 八、用户使用流程

### 场景1：制定饮食计划

```
步骤1：进入"计划书"页面
        ↓
步骤2：点击"新建饮食计划"
        ↓
步骤3：设置目标（减脂、目标体重、每周运动3次）
        ↓
步骤4：选择偏好（不吃海鲜、喜欢清淡、预算30元/天）
        ↓
步骤5：点击"AI智能生成"
        ↓
步骤6：AI调用智能顾问Agent + 营养Agent + 推荐Agent
        ↓
步骤7：生成7天饮食计划
        ├─ 周一：燕麦粥 + 清蒸鱼 + 时蔬
        ├─ 周二：牛奶鸡蛋 + 鸡胸肉 + 沙拉
        └─ ...
        ↓
步骤8：手动调整（可选）
        ├─ 不喜欢的菜可以替换
        ├─ 可以调整份量
        └─ 可以添加备注
        ↓
步骤9：保存计划
        ↓
步骤10：开始执行，每日打卡记录
```

### 场景2：记录今日饮食

```
步骤1：打开日历
        ↓
步骤2：点击今天日期
        ↓
步骤3：查看今日计划
        ├─ 早餐：燕麦粥 + 鸡蛋
        ├─ 午餐：清蒸鲈鱼 + 米饭
        └─ 晚餐：鸡胸肉沙拉
        ↓
步骤4：点击"记录早餐"
        ├─ 方式1：从历史菜品选择
        ├─ 方式2：拍照AI识别
        ├─ 方式3：手动输入
        └─ 方式4：扫描订单
        ↓
步骤5：确认记录
        ├- 自动计算热量
        ├- 保存记录
        └- 更新今日进度
        ↓
步骤6：完成三餐记录后
        ├- 生成今日报告
        ├- 对比计划vs实际
        ├- 显示营养摄入
        └- 给出建议
```

### 场景3：查看历史订单

```
步骤1：打开日历
        ↓
步骤2：切换到月视图
        ↓
步骤3：看到某天有订单标记
        ├- 3月15日显示订单图标
        └- 显示订单数量：2单
        ↓
步骤4：点击该日期
        ↓
步骤5：查看订单详情
        ├- 午餐：宫保鸡丁套餐 ¥25
        └─ 晚餐：炒青菜套餐 ¥15
        ↓
步骤6：点击"再次下单"
        ├- 自动填充菜品
        ├- 自动填充地址
        ├- 自动选择优惠
        └- 确认下单
```

### 场景4：追踪健康目标

```
步骤1：进入"健康目标"
        ↓
步骤2：查看当前进度
        ├- 目标体重：60kg
        ├- 当前体重：65kg
        └- 进度：还有5kg
        ↓
步骤3：查看体重曲线
        ├- 显示历史记录
        ├- 显示趋势
        └- 显示预计达成时间
        ↓
步骤4：查看AI建议
        ├- 按当前进度
        ├- 需要再坚持2个月
        ├- 建议调整饮食
        └- 建议增加运动
        ↓
步骤5：调整计划
        ├- 生成新的饮食计划
        ├- 生成新的运动计划
        └- 继续执行
```
