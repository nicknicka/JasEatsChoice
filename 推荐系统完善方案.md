## 一、现状分析

### 1.1 已实现功能 ✅

#### 前端部分
- **个性化推荐**：从后端获取基于用户偏好的推荐
- **天气时间推荐**：根据温度、湿度和时段生成推荐
- **节日特色推荐**：根据当前节日/节气推荐传统美食
- **拒绝机制**：记录用户不感兴趣的菜品
- **多样性保证**：确保不同推荐类型的平衡

#### 后端部分
- **基础筛选**：饮食目标（低卡、高蛋白）、标签权重
- **推荐操作**：替换、筛选、拒绝记录
- **多维度过滤**：卡路里、价格、分类

### 1.2 存在的问题 ⚠️

| 问题类别 | 具体描述 | 影响 |
|---------|---------|------|
| **算法简单** | 仅使用标签权重匹配，缺少协同过滤、内容分析等算法 | 推荐准确度低 |
| **数据未利用** | 未使用订单历史、浏览行为、点击数据等 | 无法精准画像 |
| **前端Mock数据** | 天气时间推荐使用模拟数据 | 与实际菜品不匹配 |
| **缺少解释** | 无推荐理由、匹配度评分 | 用户信任度低 |
| **无实时学习** | 推荐结果不根据反馈动态调整 | 推荐效果无法优化 |
| **缺少评估** | 无A/B测试、效果监控 | 无法量化改进效果 |

### 4.3 核心算法实现

#### 4.3.1 协同过滤召回

**实现步骤：**
1. 基于用户-菜品交互矩阵计算用户相似度
2. 找到与目标用户最相似的K个用户
3. 推荐相似用户喜欢但目标用户未尝试的菜品

**代码框架：**
```java
@Service
public class CollaborativeFilterRecall implements RecallStrategy {

    @Override
    public List<Dish> recall(RecommendationRequest request, int count) {
        String userId = request.getUserId();

        // 1. 获取用户历史交互数据
        List<UserBehavior> userBehaviors = behaviorService.getUserBehaviors(userId);

        // 2. 计算用户相似度
        Map<String, Double> similarUsers = calculateUserSimilarity(userId, userBehaviors);

        // 3. 获取相似用户喜欢的菜品
        Set<String> userDishIds = userBehaviors.stream()
            .map(UserBehavior::getItemId)
            .collect(Collectors.toSet());

        List<Dish> candidateDishes = new ArrayList<>();
        for (Map.Entry<String, Double> entry : similarUsers.entrySet()) {
            String similarUserId = entry.getKey();
            Double similarity = entry.getValue();

            List<Dish> dishes = behaviorService.getUserLikedDishes(similarUserId);
            for (Dish dish : dishes) {
                if (!userDishIds.contains(dish.getId())) {
                    dish.setScore(dish.getScore() * similarity); // 加权
                    candidateDishes.add(dish);
                }
            }
        }

        // 4. 排序并返回Top-N
        return candidateDishes.stream()
            .sorted(Comparator.comparing(Dish::getScore).reversed())
            .limit(count)
            .collect(Collectors.toList());
    }

    /**
     * 计算用户相似度（使用余弦相似度）
     */
    private Map<String, Double> calculateUserSimilarity(String userId, List<UserBehavior> behaviors) {
        // 实现细节：
        // 1. 构建用户-菜品评分矩阵
        // 2. 计算目标用户与其他用户的余弦相似度
        // 3. 返回Top-K相似用户

        Map<String, Double> similarityMap = new HashMap<>();

        // 伪代码：
        // for each otherUser in allUsers:
        //     similarity = cosineSimilarity(userId, otherUser)
        //     similarityMap.put(otherUser, similarity)
        //
        // return topK(similarityMap, k=50)

        return similarityMap;
    }
}
```

**优化点：**
- 使用矩阵分解（SVD）降低计算复杂度
- 引入时间衰减：近期行为权重更高
- 缓存相似度计算结果，定期更新

#### 4.3.2 基于内容召回

**实现步骤：**
1. 提取用户偏好的特征（类别、口味、价格等）
2. 提取菜品特征
3. 计算特征匹配度

**代码框架：**
```java
@Service
public class ContentBasedRecall implements RecallStrategy {

    @Override
    public List<Dish> recall(RecommendationRequest request, int count) {
        String userId = request.getUserId();
        UserProfile profile = profileService.getUserProfile(userId);

        List<Dish> allDishes = dishService.list();
        List<DishFeature> features = featureService.getAllFeatures();

        // 计算每道菜与用户偏好的匹配度
        List<Dish> scoredDishes = new ArrayList<>();
        for (Dish dish : allDishes) {
            DishFeature feature = getFeature(dish.getId(), features);
            double score = calculateMatchScore(profile, feature);
            dish.setScore(score);
            scoredDishes.add(dish);
        }

        // 返回Top-N
        return scoredDishes.stream()
            .sorted(Comparator.comparing(Dish::getScore).reversed())
            .limit(count)
            .collect(Collectors.toList());
    }

    /**
     * 计算用户偏好与菜品特征的匹配分数
     */
    private double calculateMatchScore(UserProfile profile, DishFeature feature) {
        double totalScore = 0.0;
        double totalWeight = 0.0;

        // 1. 类别匹配 (权重: 0.3)
        Map<String, Double> prefTags = profile.getPreferenceTags();
        if (prefTags.containsKey(feature.getCategory())) {
            totalScore += prefTags.get(feature.getCategory()) * 0.3;
        }
        totalWeight += 0.3;

        // 2. 口味匹配 (权重: 0.25)
        Map<String, Double> flavorPref = profile.getFlavorPreference();
        Map<String, Double> flavorProfile = feature.getFlavorProfile();
        double flavorScore = calculateFlavorSimilarity(flavorPref, flavorProfile);
        totalScore += flavorScore * 0.25;
        totalWeight += 0.25;

        // 3. 价格匹配 (权重: 0.2)
        Map<String, Double> pricePref = profile.getPricePreference();
        double priceScore = calculatePriceScore(pricePref, dish.getPrice());
        totalScore += priceScore * 0.2;
        totalWeight += 0.2;

        // 4. 营养目标匹配 (权重: 0.15)
        Map<String, Double> nutritionGoals = profile.getNutritionGoals();
        double nutritionScore = calculateNutritionScore(nutritionGoals, feature.getNutritionInfo());
        totalScore += nutritionScore * 0.15;
        totalWeight += 0.15;

        // 5. 场景匹配 (权重: 0.1)
        List<String> scenarios = feature.getSuitableScenarios();
        double scenarioScore = scenarios.contains(currentScenario()) ? 1.0 : 0.5;
        totalScore += scenarioScore * 0.1;
        totalWeight += 0.1;

        return totalWeight > 0 ? totalScore / totalWeight : 0.0;
    }
}
```

public class WeightedRankStrategy implements RankStrategy {

    @Override
    public List<Dish> rank(List<Dish> candidates, RecommendationRequest request) {
        // 为每道菜计算最终得分
        for (Dish dish : candidates) {
            double finalScore = calculateFinalScore(dish, request);
            dish.setScore(finalScore);
        }

        // 排序
        return candidates.stream()
            .sorted(Comparator.comparing(Dish::getScore).reversed())
            .collect(Collectors.toList());
    }

    private double calculateFinalScore(Dish dish, RecommendationRequest request) {
        double score = 0.0;

        // 多因素加权
        score += dish.getRecallScore() * 0.4;        // 召回得分
        score += dish.getPopularityScore() * 0.2;    // 热度得分
        score += dish.getFreshnessScore() * 0.1;     // 新品得分
        score += getContextScore(dish, request) * 0.15; // 上下文得分
        score += getDiversityScore(dish, request) * 0.15; // 多样性得分

        return score;
    }

    /**
     * 计算上下文得分（时间、天气、位置）
     */
    private double getContextScore(Dish dish, RecommendationRequest request) {
        double score = 0.0;
        Map<String, Object> context = request.getContext();

        // 时间匹配
        String timePeriod = (String) context.get("timePeriod");
        if (dish.getTimePeriodTags().contains(timePeriod)) {
            score += 0.4;
        }

        // 天气匹配
        String weather = (String) context.get("weather");
        if (isWeatherSuitable(weather, dish.getTags())) {
            score += 0.4;
        }

        // 位置匹配（附近商家优先）
        if (context.containsKey("location")) {
            // 实现位置匹配逻辑
            score += 0.2;
        }

        return score;
    }
}

/**
 * 页面浏览时长跟踪
 */
export class PageViewTracker {
  constructor(itemType, itemId) {
    this.itemType = itemType
    this.itemId = itemId
    this.startTime = Date.now()
    this.isReported = false
  }

  // 手动结束并上报
  end() {
    if (this.isReported) return

    const duration = Math.floor((Date.now() - this.startTime) / 1000) // 秒
    if (duration > 3) { // 浏览超过3秒才记录
      trackBehavior(BEHAVIOR_TYPES.VIEW, this.itemType, this.itemId, { duration })
    }
    this.isReported = true
  }
}

   - 使用注意力机制突出推荐关键因素
   - 提供推荐调整入口（"多推荐点这类"）

5. **在线学习**
   - 根据实时反馈动态调整推荐策略
