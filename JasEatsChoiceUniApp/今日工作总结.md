## 💡 技术亮点

### 1. 组件化设计

**天气定位组件**：
- 封装的独立性组件
- 支持父子组件通信
- 自动获取位置和天气
- 支持手动刷新

**使用示例**：
```vue
<WeatherLocation ref="weatherRef" />
```

### 2. 全局样式系统

**设计Token体系**：
- 主题色、中性色、语义色
- 字体、间距、圆角、阴影
- 响应式断点
- 安全区域

**使用示例**：
```scss
.my-component {
  @include flex-center;
  @include text-ellipsis;
  padding: $spacing-md;
  color: $primary-color;
}
```

### 3. 购物车状态管理

**按商家分组**：
```javascript
carts: {
  'merchantId1': {
    merchant: {...},
    items: [...]
  }
}
```

**自动计算**：
- 总价 = 商品价 + 配送费 + 包装费
- 配送费 = 商家数 × 5
- 包装费 = 商品数 × 1

### 4. 订单状态流转

**8种订单状态**：
```
pending → paid → processing → delivering → completed
         ↓        ↓          ↓
      cancelled  refunding  refunded
```

每个状态都有对应的UI展示和操作按钮。

### 5. 搜索功能

**搜索建议**：
- 实时搜索建议
- 搜索历史记录
- 热门搜索推荐

**搜索结果**：
- 全局搜索（商家+菜品+食谱）
- 分类筛选Tab
- 结果数量显示
