# 模拟验证码使用指南

## 📝 说明

由于后端未实现真实的验证码发送功能（为了减少token消耗），前端已实现**模拟验证码**功能。

## 🔧 工作原理

1. **发送验证码**：
   - 点击"获取验证码"按钮
   - 系统自动生成6位随机数字验证码
   - 验证码存储在本地缓存中
   - 弹窗显示验证码（开发模式）

2. **验证码验证**：
   - 用户输入验证码
   - 系统比对本地缓存的验证码
   - 检查验证码是否过期（5分钟有效期）
   - 验证成功后清除缓存的验证码

## 📱 使用步骤

### 1. 输入手机号
```
请输入11位有效手机号，例如：13800138000
```

### 2. 获取验证码
- 点击"获取验证码"按钮
- 系统会弹出对话框显示验证码
- 示例弹窗内容：
  ```
  【开发模式】验证码: 123456
  有效期5分钟
  ```

### 3. 输入验证码
- 输入弹窗中显示的6位验证码
- 例如：123456

### 4. 点击登录
- 验证码正确即可登录成功

## ⚠️ 注意事项

1. **验证码有效期**：5分钟
2. **验证码格式**：6位纯数字
3. **验证码存储**：本地缓存，刷新页面会丢失
4. **手机号绑定**：验证码与手机号绑定，必须一致
5. **使用后清除**：验证成功后会自动清除缓存的验证码

## 🐛 调试信息

在控制台可以看到以下日志：

```
====== 模拟验证码 ======
手机号: 13800138000
验证码: 123456
======================
✅ 使用模拟验证码登录成功
```

## 🔍 常见问题

### Q: 提示"验证码不能为空"
A: 请先点击"获取验证码"按钮获取验证码

### Q: 提示"验证码已过期"
A: 验证码有效期5分钟，请重新获取

### Q: 提示"验证码错误"
A: 请输入弹窗中显示的正确验证码

### Q: 没有收到验证码弹窗
A: 检查控制台日志，验证码会打印在控制台

## 📋 测试用例

| 测试场景 | 预期结果 |
|---------|---------|
| 输入正确验证码 | 登录成功 |
| 输入错误验证码 | 提示"验证码错误" |
| 过期的验证码 | 提示"验证码已过期" |
| 未获取验证码直接登录 | 提示"验证码不能为空" |
| 手机号与验证码不匹配 | 提示"验证码错误" |
