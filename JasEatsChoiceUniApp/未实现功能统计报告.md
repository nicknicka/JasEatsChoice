  - [ ] 调用支付宝支付
  - [ ] 调用余额支付API
  - [ ] 轮询查询支付状态

**API需求：**
```
GET    /api/payment/order/{id}          - 获取订单支付信息
GET    /api/payment/coupons             - 获取可用优惠券
POST   /api/payment/create              - 创建支付订单
POST   /api/payment/wechat              - 微信支付
POST   /api/payment/alipay              - 支付宝支付
POST   /api/payment/balance             - 余额支付
GET    /api/payment/status/{id}         - 查询支付状态
```

**支付流程：**
```
1. 用户选择支付方式
2. 调用 /api/payment/create 创建支付订单
3. 根据支付方式调用对应支付接口
   - 微信：/api/payment/wechat
   - 支付宝：/api/payment/alipay
   - 余额：/api/payment/balance
4. 轮询 /api/payment/status/{id} 查询支付结果
5. 支付成功跳转到订单详情页
```
