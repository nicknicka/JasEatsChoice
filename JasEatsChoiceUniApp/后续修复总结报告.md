#### 修复内容

**文件**: `src/utils/request.js`

**修改前**:
```javascript
if (response.success === true || response.code === '200') {
  resolve(response.data !== undefined ? response.data : response)  // ❌ 只返回data
}
```

**修改后**:
```javascript
if (response.success === true || response.code === '200' || response.code === 200) {
  resolve(response)  // ✅ 返回完整response对象
}
```

**影响**: 所有使用`res.code === 200`的代码现在都能正常工作

### 4. 支付API模块更新

**文件**: `src/api/modules/payment.js`

**更新内容**: 修复`pollPaymentStatus`方法中的响应处理逻辑

**修改前**:
```javascript
const response = await paymentApi.getPaymentStatus(paymentNo)
if (response.code === 200) {  // ❌ response可能没有code字段
  const status = response.data.status
}
```

**修改后**:
```javascript
const response = await paymentApi.getPaymentStatus(paymentNo)
const code = response.code || response.statusCode
const data = response.data || response

if (code === 200 || code === '200') {  // ✅ 兼容多种格式
  const status = data.status
}
```
