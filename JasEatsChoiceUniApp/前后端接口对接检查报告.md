## 🔴 核心问题：响应处理逻辑不一致

### 问题描述

**request.js** 的响应处理逻辑与页面代码期望不匹配，导致**83处代码**存在潜在bug。

#### 当前实现（request.js 第86-90行）

```javascript
// 后端统一返回格式：{ success: boolean, code: string, message: string, data: any }
if (response && typeof response === 'object') {
  // 检查业务状态
  if (response.success === true || response.code === '200') {
    // ❌ 问题：直接返回data，丢失了code和message
    resolve(response.data !== undefined ? response.data : response)
  }
}
```

#### 后端返回格式（ResponseResult.java）

```java
public class ResponseResult<T> {
    private Boolean success;  // true/false
    private String code;      // "200"表示成功
    private String message;   // 提示信息
    private T data;          // 实际数据
}
```

#### 页面代码期望（83处）

```javascript
// ❌ 错误：期望得到完整response，但实际只得到data
const res = await paymentApi.createPayment(paymentData)
if (res.code === 200 && res.data) {  // res.code会是undefined！
  const { paymentNo, amount, status } = res.data
}
```

## 🔧 修复方案

### 方案1：修改request.js（推荐）

**修改 src/utils/request.js**：

```javascript
// 第86-103行，修改为：
if (response && typeof response === 'object') {
  // 检查业务状态
  if (response.success === true || response.code === '200') {
    // ✅ 返回完整response对象
    resolve(response)
  } else if (response.success === false) {
    // 业务失败
    const errorMsg = response.message || '请求失败'
    uni.showToast({
      title: errorMsg,
      icon: 'none',
      duration: 2000
    })
    reject({ message: errorMsg, code: response.code, response })
  } else {
    // 兼容旧格式或直接返回的数据
    resolve(response)
  }
}
```

**优点**：
- ✅ 只需修改1个文件
- ✅ 83处代码无需修改
- ✅ 保留code、message等元信息
- ✅ 符合当前代码习惯

**缺点**：
- ⚠️ 使用数据时需要多写`.data`

**使用示例**：
```javascript
const res = await paymentApi.createPayment(data)
if (res.code === 200) {
  const { paymentNo, amount } = res.data  // ✅ 正确
}
```

### 方案2：修改所有页面代码

修改83处代码，直接使用data：

```javascript
// ❌ 修改前
```

**优点**：
