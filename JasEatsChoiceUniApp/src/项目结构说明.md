## 文件命名规范

### 页面文件
- 使用小写字母和连字符
- 例如：`merchant-detail.vue`、`order-confirm.vue`

### 组件文件
- 使用大驼峰命名
- 例如：`DishCard.vue`、`OrderList.vue`

### 工具文件
- 使用小写字母和连字符
- 例如：`request.js`、`websocket.js`

### 组件命名
- 页面组件：放在views目录
- 公共组件：放在components目录

## API接口规范

### 接口调用示例
```javascript
import { userApi } from '@/api'

// 调用接口
const handleLogin = async () => {
  try {
    const res = await userApi.login({
      phone: '13800138000',
      password: '123456'
    })
    console.log('登录成功', res)
  } catch (error) {
    console.error('登录失败', error)
  }
}
```

## 开发建议

1. **组件化开发**：尽量复用组件，减少重复代码
2. **状态管理**：全局状态使用Pinia，局部状态使用ref/reactive
3. **API封装**：所有接口调用统一使用api模块
4. **错误处理**：统一使用try-catch捕获错误
5. **代码注释**：重要逻辑需要添加注释说明
