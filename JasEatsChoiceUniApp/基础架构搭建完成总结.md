### 4. Pinia状态管理配置

**已创建的Store模块**：

| 模块 | 文件路径 | 功能说明 |
|------|---------|---------|
| **index.js** | `store/index.js` | Pinia实例创建 |
| **user.js** | `store/modules/user.js` | 用户状态管理 |
| **cart.js** | `store/modules/cart.js` | 购物车状态管理 |
| **location.js** | `store/modules/location.js` | 位置状态管理 |

##### user.js - 用户状态
**State**：
- token - JWT Token
- userInfo - 用户信息
- role - 用户角色
- isLogin - 是否登录

**Getters**：
- isMerchant - 是否为商家
- isAdmin - 是否为管理员
- nickname - 用户昵称
- avatar - 用户头像
- memberLevel - 会员等级

**Actions**：
- setToken() - 设置Token
- setUserInfo() - 设置用户信息
- fetchUserInfo() - 获取用户信息
- login() - 登录
- register() - 注册
- wechatLogin() - 微信登录
- updateUserInfo() - 更新用户信息
- logout() - 退出登录
- checkLogin() - 检查登录状态

##### cart.js - 购物车状态
**State**：
- carts - 购物车列表（按商家分组）
- currentMerchantId - 当前选中的商家ID

**Getters**：
- totalCount - 购物车总数
- totalPrice - 购物车总价
- getCartByMerchant() - 获取指定商家的购物车
- currentCart - 当前商家的购物车

**Actions**：
- setCurrentMerchant() - 设置当前商家
- addToCart() - 添加到购物车
- updateQuantity() - 更新数量
- clearCart() - 清空购物车
- saveCarts() - 保存到本地存储
- loadCarts() - 从本地存储加载

##### location.js - 位置状态
**State**：
- currentLocation - 当前位置
- selectedCity - 选中的城市
- weather - 天气信息
- isLocationAuthorized - 是否已授权定位

**Getters**：
- locationText - 位置描述文本

**Actions**：
- setCurrentLocation() - 设置当前位置
- setSelectedCity() - 设置选中的城市
- setWeather() - 设置天气信息
- getCurrentPosition() - 获取当前位置
- chooseLocation() - 选择位置

## 💡 使用指南

### 1. 安装依赖

```bash
cd /Users/nickxiao/JasEatsChoice/JasEatsChoiceUniApp
npm install
```

### 2. 运行项目

```bash
# 微信小程序开发
npm run dev:mp-weixin

# H5开发
npm run dev:h5
```

### 3. 使用API模块

```javascript
import { userApi, dishApi, orderApi } from '@/api'

// 调用接口
const userInfo = await userApi.getUserInfo()
const dishList = await dishApi.getList({ page: 1, size: 10 })
```

### 4. 使用状态管理

```javascript
import { useUserStore, useCartStore } from '@/store'

// 使用用户状态
const userStore = useUserStore()
const userInfo = userStore.userInfo
await userStore.login(data)

// 使用购物车状态
const cartStore = useCartStore()
cartStore.addToCart(item)
```

### 5. 使用工具类

```javascript
import { router, permission, storage } from '@/utils'

// 路由跳转
router.toDishDetail(dishId)

// 权限请求
const hasPermission = await permission.requestLocation()

// 本地存储
storage.set('key', value)
const data = storage.get('key')
```
