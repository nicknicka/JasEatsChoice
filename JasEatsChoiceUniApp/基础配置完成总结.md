## 🔧 配置说明

### 应用生命周期

**onLaunch**（应用启动）：
- 检查登录状态（读取token，获取用户信息）
- 获取系统信息（状态栏高度、平台信息）
- 初始化配置

**onShow**（应用显示）：
- 刷新用户信息（如果已登录）

**onHide**（应用隐藏）：
- 仅记录日志

### 登录状态管理

**流程**：
1. 启动时读取本地token
2. 如果存在token，设置到store
3. 调用获取用户信息接口
4. 如果token过期，自动清理并退出登录

**代码**：
```javascript
const checkLoginStatus = () => {
  const token = uni.getStorageSync('token')
  if (token) {
    userStore.setToken(token)
    userStore.fetchUserInfo().catch(err => {
      userStore.logout() // Token过期，自动清理
    })
  }
}
```
