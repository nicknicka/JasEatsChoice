## 📊 功能流程图

### 购物流程

```
首页/商家详情/菜品详情
    ↓
加入购物车
    ↓
购物车页面
    ↓
选择商品 → 结算
    ↓
订单确认页面
    ↓
选择地址、时间、优惠券、支付方式 → 提交订单
    ↓
订单详情页面
    ↓
支付/取消订单/确认收货/评价
```

### 订单状态流转

```
待支付 (pending)
    ↓ 支付
已支付 (paid)
    ↓ 商家接单
处理中 (processing)
    ↓ 骑手取餐
配送中 (delivering)
    ↓ 确认收货
已完成 (completed)
    ↓ 评价
结束

每个状态都可取消 → 已取消 (cancelled)
支付后可退款 → 退款中 (refunding) → 已退款 (refunded)
```

### 1. 购物车数量修改

```javascript
const increaseQuantity = (merchantId, dishId) => {
  const group = cartList.value.find(g => g.merchantId === merchantId)
  if (group) {
    const item = group.items.find(i => i.dish.id === dishId)
    if (item) {
      item.quantity++
      // 同步更新store
      cartStore.updateQuantity(merchantId, dishId, item.quantity)
    }
  }
}
```

### 2. 购物车全选逻辑

```javascript
const handleSelectAll = (e) => {
  const checked = e.detail.value.length > 0
  cartList.value.forEach(group => {
    group.selected = checked
    group.items.forEach(item => {
      item.selected = checked
    })
  })
}
```

### 3. 价格计算

```javascript
const totalPrice = computed(() => {
  let total = 0
  cartList.value.forEach(group => {
    group.items.forEach(item => {
      if (item.selected) {
        total += item.dish.price * item.quantity
      }
    })
  })
  return total.toFixed(2)
})
```

## ✨ 代码亮点

### 1. 购物车分组计算

```javascript
// 按商家分组显示
const cartList = computed(() => {
  const carts = cartStore.carts
  return Object.keys(carts).map(merchantId => {
    const merchantData = carts[merchantId]
    return {
      merchantId,
      merchant: merchantData.merchant,
      selected: false,
      editing: false,
      items: merchantData.items
    }
  })
})
```

### 2. 智能价格计算

```javascript
// 配送费：按商家计算
const totalDeliveryFee = computed(() => {
  let fee = 0
  cartList.value.forEach(group => {
    const hasSelected = group.items.some(item => item.selected)
    if (hasSelected) {
      fee += 5
    }
  })
  return fee.toFixed(2)
})

// 包装费：按数量计算
const totalPackingFee = computed(() => {
  let fee = 0
  cartList.value.forEach(group => {
    group.items.forEach(item => {
      if (item.selected) {
        fee += item.quantity * 1
      }
    })
  })
  return fee.toFixed(2)
})
```
