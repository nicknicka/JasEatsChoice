## 路由设计

### 设计原则

1. **角色分离**：用户端和商家端完全分离，通过不同入口进入
2. **分包加载**：按照功能模块分包，优化包体积
3. **TabBar导航**：主要功能通过底部TabBar快速切换
4. **层级扁平**：避免页面层级过深，最多3层
5. **权限控制**：商家页面需要商家权限才能访问

### 动态TabBar切换

由于UniApp不支持多套TabBar，需要通过代码动态切换。

#### 实现思路

1. **判断用户角色**
```javascript
// 在App.vue的onLaunch中
const userRole = uni.getStorageSync('userRole') // 'user' | 'merchant' | 'admin'

// 根据角色跳转不同首页
if (userRole === 'merchant') {
  uni.switchTab({
    url: '/pages-merchant/home/index'
  })
} else {
  uni.switchTab({
    url: '/pages-user/home/index'
  })
}
```

2. **自定义TabBar组件**
```javascript
// components/CustomTabBar.vue
<template>
  <view class="tabbar">
    <view
      v-for="(item, index) in tabList"
      :key="index"
      @click="switchTab(item)"
    >
      <image :src="current === index ? item.selectedIcon : item.icon" />
      <text>{{ item.text }}</text>
    </view>
  </view>
</template>

<script setup>
import { computed } from 'vue'

const userRole = computed(() => store.getters.userRole)

const userTabs = [
  { pagePath: '/pages-user/home/index', icon: '...', selectedIcon: '...', text: '首页' },
  // ...
]

const merchantTabs = [
  { pagePath: '/pages-merchant/home/index', icon: '...', selectedIcon: '...', text: '首页' },
  // ...
]

const tabList = computed(() => {
  return userRole.value === 'merchant' ? merchantTabs : userTabs
})

const switchTab = (item) => {
  uni.switchTab({ url: item.pagePath })
}
</script>
```

3. **在pages.json中配置自定义TabBar**
```json
{
  "tabBar": {
    "custom": true,
    "list": [
      {
        "pagePath": "pages-user/home/index",
        "text": "首页"
      }
      // ... 其他tab
    ]
  }
}
```

### 路由跳转规范

#### 1. 跳转方法选择

| 方法 | 使用场景 | 说明 |
|------|----------|------|
| `uni.switchTab()` | 跳转TabBar页面 | 不带参数，关闭其他非TabBar页面 |
| `uni.navigateTo()` | 跳转非TabBar页面 | 保留当前页面，可返回 |
| `uni.redirectTo()` | 跳转非TabBar页面 | 关闭当前页面，不可返回 |
| `uni.reLaunch()` | 重启应用 | 关闭所有页面，打开新页面 |
| `uni.navigateBack()` | 返回上一页 | 可返回多级 `delta: 2` |

#### 2. 路由封装

**建议创建路由工具类**：
```javascript

  if (!token) {
    uni.reLaunch({
      url: '/pages/login/index'
    })
    return
  }

  // 获取用户信息
  userStore.fetchUserInfo().then(() => {
    // 根据角色跳转
    const role = userStore.role
    if (role === 'merchant') {
      uni.switchTab({
        url: '/pages-merchant/home/index'
      })
    } else if (role === 'admin') {
      uni.navigateTo({
        url: '/pages-admin/dashboard/index'
      })
    } else {
      uni.switchTab({
        url: '/pages-user/home/index'
      })
    }
  })
})
```

### 1.4 WebSocket封装

```javascript
// utils/websocket.js
class WebSocketClient {
  constructor(url) {
    this.url = url
    this.ws = null
    this.reconnectTimer = null
    this.heartbeatTimer = null
    this.listeners = {}
  }

  connect() {
    this.ws = uni.connectSocket({
      url: this.url,
      header: {
        'Authorization': uni.getStorageSync('token')
      }
    })

    this.ws.onOpen(() => {
      console.log('WebSocket连接成功')
      this.startHeartbeat()
    })

    this.ws.onMessage((res) => {
      const data = JSON.parse(res.data)
      this.emit(data.type, data)
    })

    this.ws.onClose(() => {
      console.log('WebSocket连接关闭')
      this.reconnect()
    })

    this.ws.onError(() => {
      console.error('WebSocket连接错误')
      this.reconnect()
    })
  }

  on(event, callback) {
    if (!this.listeners[event]) {
      this.listeners[event] = []
    }
    this.listeners[event].push(callback)
  }

  emit(event, data) {
    if (this.listeners[event]) {
      this.listeners[event].forEach(callback => callback(data))
    }
  }

  send(data) {
    this.ws.send({
      data: JSON.stringify(data)
    })
  }

  startHeartbeat() {
    this.heartbeatTimer = setInterval(() => {
      this.send({ type: 'ping' })
    }, 30000)
  }

  reconnect() {
    if (this.reconnectTimer) return
    this.reconnectTimer = setTimeout(() => {
      this.connect()
      this.reconnectTimer = null
    }, 3000)
  }

  close() {
    clearInterval(this.heartbeatTimer)
    this.ws.close()
  }
}

export default WebSocketClient
```
