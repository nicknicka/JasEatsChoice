## 🚀 性能优化亮点

### 1. 按需加载
```javascript
// 骨架屏只在初始加载时显示
<SkeletonScreen v-if="loading && list.length === 0" />
```

### 2. 防抖搜索
```javascript
// MessageSearch 内置防抖
// 避免频繁搜索请求
watch(() => props.modelValue, (newVal) => {
  if (newVal) {
    emit('search', newVal)
  }
})
```

### 3. 工具函数优化
```javascript
// 使用 Map 数据结构
const swipeStates = new Map()  // O(1) 查找

// 使用 computed 缓存
const unreadCount = computed(() => {
  return list.reduce((sum, item) => sum + item.unread, 0)
})
```

/* 使用 GPU 加速 */
