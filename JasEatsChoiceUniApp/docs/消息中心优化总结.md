## ⚡ 性能优化

### 动画性能
1. **使用 transform 和 opacity**
   - 避免触发 layout 和 paint
   - 启用 GPU 加速

2. **交错动画**
   ```css
   @for $i from 1 through 20 {
     &:nth-child(#{$i}) {
       animation-delay: #{$i * 0.03}s;
     }
   }
   ```

3. **合理的动画时长**
   - 快速交互：0.2-0.3s
   - 标准动画：0.3-0.4s
   - 长动画：0.5-0.6s

### 内存优化
1. **条件渲染**
   - 使用 `v-if` 而非 `v-show` 隐藏组件
   - 减少 DOM 节点数量

2. **事件防抖**
   - 切换Tab时延迟刷新
   - 避免频繁API调用

## 📝 注意事项

1. **动画性能**
   - 避免使用 `width`、`height` 等属性
   - 优先使用 `transform` 和 `opacity`

2. **兼容性**
   - 测试不同平台（小程序、H5、App）
   - 注意CSS属性前缀

3. **用户体验**
   - 动画不要过长（<0.5s）
   - 提供即时反馈
   - 避免过度动画
