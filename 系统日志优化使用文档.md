# 系统日志优化使用文档

## 概述

本次系统日志优化主要提供了以下功能：

1. **敏感信息自动脱敏** - 保护密码、手机号等敏感信息
2. **便捷的日志记录工具类** - 简化日志记录代码
3. **异步日志处理** - 提升性能，不影响业务逻辑
4. **自动提取请求信息** - IP、浏览器、操作系统等

## 已创建的文件

### 1. 敏感信息脱敏工具类

**文件路径：** `JasEatsChoiceJava/src/main/java/com/xx/jaseatschoicejava/util/SensitiveDataMasker.java`

**功能：**
- 对 JSON 字符串中的敏感字段进行脱敏
- 支持多种敏感数据类型：密码、手机号、身份证、邮箱、银行卡等
- 可自定义敏感字段列表

**使用示例：**
```java
// 脱敏手机号
String maskedPhone = SensitiveDataMasker.maskPhone("13812345678");
// 结果：138****5678

// 脱敏身份证
String maskedIdCard = SensitiveDataMasker.maskIdCard("110101199001011234");
// 结果：110101********1234

// 脱敏 JSON 字符串
String json = "{\"username\":\"admin\",\"password\":\"123456\",\"phone\":\"13812345678\"}";
String maskedJson = SensitiveDataMasker.maskSensitiveData(json, null);
// 结果：{"username":"admin","password":"******","phone":"138****5678"}
```

### 2. 系统日志辅助类

**文件路径：** `JasEatsChoiceJava/src/main/java/com/xx/jaseatschoicejava/util/SystemLogHelper.java`

**功能：**
- 提供便捷的静态方法记录日志
- 自动脱敏敏感信息
- 自动提取请求信息（IP、浏览器、OS）
- 异步保存日志，不影响业务性能

**常用方法：**

```java
// 1. 记录登录日志
SystemLogHelper.logLogin(adminId, adminName, ip, "SUCCESS");

// 2. 记录登出日志
SystemLogHelper.logLogout(adminId, adminName);

// 3. 记录创建操作
SystemLogHelper.logCreate("用户管理", "创建用户：" + userDTO.getName(),
                         adminId, adminName, userDTO);

// 4. 记录更新操作
SystemLogHelper.logUpdate("角色管理", "更新角色：" + roleDTO.getRoleName(),
                         adminId, adminName, roleDTO);

// 5. 记录删除操作
SystemLogHelper.logDelete("公告管理", "删除公告：" + announcementId,
                         adminId, adminName, null);

// 6. 记录异常
SystemLogHelper.logError("订单管理", "处理订单失败", adminId, adminName, exception);

// 7. 完整参数记录
SystemLogHelper.logOperation(
    "模块名称",           // module
    "CREATE",            // operationType
    "操作描述",           // description
    adminId,             // operatorId
    adminName,           // operatorName
    "ADMIN",             // operatorType
    "方法名",             // method
    paramsObject,        // params
    resultObject,        // result
    100L,                // executeTime
    "SUCCESS",           // status
    null                 // errorMessage
);
```

## 使用示例

### 在 Controller 中使用

```java
@RestController
@RequestMapping("/admin/users")
public class UserController {

    // 创建用户
    @PostMapping("")
    public ResponseEntity<Map<String, Object>> createUser(
            @RequestBody UserDTO userDTO) {

        Long adminId = AdminContext.getAdminId();
        String adminName = AdminContext.getAdminUsername();

        try {
            // 业务逻辑
            User user = userService.createUser(userDTO);

            // 记录日志
            SystemLogHelper.logCreate(
                "用户管理",
                "创建用户：" + user.getName(),
                adminId,
                adminName,
                userDTO
            );

            return ResponseEntity.ok(Map.of("success", true, "data", user));
        } catch (Exception e) {
            // 记录异常日志
            SystemLogHelper.logError(
                "用户管理",
                "创建用户失败：" + userDTO.getName(),
                adminId,
                adminName,
                e
            );
            throw e;
        }
    }

    // 更新用户
    @PutMapping("/{userId}")
    public ResponseEntity<Map<String, Object>> updateUser(
            @PathVariable Long userId,
            @RequestBody UserDTO userDTO) {

        Long adminId = AdminContext.getAdminId();
        String adminName = AdminContext.getAdminUsername();

        User user = userService.updateUser(userId, userDTO);

        // 记录日志
        SystemLogHelper.logUpdate(
            "用户管理",
            "更新用户信息：" + user.getName(),
            adminId,
            adminName,
            userDTO
        );

        return ResponseEntity.ok(Map.of("success", true, "data", user));
    }

    // 删除用户
    @DeleteMapping("/{userId}")
    public ResponseEntity<Map<String, Object>> deleteUser(@PathVariable Long userId) {

        Long adminId = AdminContext.getAdminId();
        String adminName = AdminContext.getAdminUsername();

        User user = userService.getUserById(userId);
        userService.deleteUser(userId);

        // 记录日志
        SystemLogHelper.logDelete(
            "用户管理",
            "删除用户：" + user.getName(),
            adminId,
            adminName,
            Map.of("userId", userId, "userName", user.getName())
        );

        return ResponseEntity.ok(Map.of("success", true));
    }
}
```

### 在登录时使用

```java
@RestController
@RequestMapping("/admin")
public class AdminController {

    @PostMapping("/login")
    public ResponseEntity<Map<String, Object>> login(
            @RequestBody LoginRequest loginRequest,
            HttpServletRequest request) {

        try {
            // 验证登录
            Admin admin = adminService.login(loginRequest.getUsername(),
                                           loginRequest.getPassword());

            // 记录登录成功日志
            SystemLogHelper.logLogin(
                admin.getAdminId(),
                admin.getAdminName(),
                getClientIP(request),
                "SUCCESS"
            );

            return ResponseEntity.ok(Map.of(
                "success", true,
                "token", generateToken(admin)
            ));

        } catch (Exception e) {
            // 记录登录失败日志
            SystemLogHelper.logLogin(
                null,
                loginRequest.getUsername(),
                getClientIP(request),
                "FAILED"
            );
            throw e;
        }
    }
}
```

## 最佳实践

### 1. 何时记录日志

**建议记录的操作：**
- ✅ 登录/登出
- ✅ 创建、更新、删除操作
- ✅ 权限变更
- ✅ 敏感数据查询
- ✅ 批量操作
- ✅ 系统配置修改

**不建议记录的操作：**
- ❌ 简单的查询操作
- ❌ 高频的统计数据获取
- ❌ 健康检查

### 2. 描述信息规范

## 注意事项

1. **日志异步保存**：日志保存是异步的，可能在方法返回后才保存成功
2. **异常处理**：日志记录失败不会影响业务逻辑
3. **性能考虑**：避免在高频循环中记录日志
4. **敏感信息**：系统会自动脱敏常见敏感字段，自定义字段请在调用时指定
